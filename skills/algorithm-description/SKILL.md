# Algorithm Description

Use this skill to explain algorithms from code or design notes.

## Workflow
- Read the relevant code path before writing the description.
- Separate objective, inputs, outputs, state variables, and update rules.
- Describe the algorithm at the right abstraction level for a paper; avoid line-by-line code narration.
- Include pseudocode when it improves reproducibility.
- State time, memory, and important implementation assumptions when they can be inferred safely.
- Mark uncertain details instead of guessing.

## Output Preferences
- Use concise academic prose for method sections.
- Use numbered pseudocode for algorithms.
- Link variables in prose to the notation used in equations or code.
