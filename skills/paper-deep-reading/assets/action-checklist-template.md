# ACTION 动作清单模板（v2 表格版）

> 精读完成后交给写作 Agent 的唯一合法格式。
> 落盘：`session/ACTION_Research Agent_{论文简称}_{YYYY-MM-DD}.md`
> 无结构的"建议看看 §2"一律退回。

## 单篇模板

```markdown
# ACTION: {论文简称} 精读动作清单

> 日期：YYYY-MM-DD | 产出 Agent：研究 Agent | 精读笔记：`reading_notes/{slug}.md`
> 影响章节：§2 / §4 / §5 / §6

## 精读笔记路径
`reading_notes/{slug}.md`

## 影响正文动作清单

| # | 位置 | 当前写法 | 精读发现 | 建议修改 | 优先级 | 原因 |
|---|------|---------|---------|---------|--------|------|
| 1 | §2.x {小节标题}，L{行号} | > 引用当前正文原句 | {事实偏差/遗漏/过强claim} | > 修改后的句子 | 必须/可选/不建议 | `reading_notes/{slug}.md` L{xx} |
| 2 | §4.x {小节标题}，L{行号} | ... | ... | ... | ... | ... |
| 3 | §5.x {小节标题}，L{行号} | ... | ... | ... | ... | ... |

## 红线检查
- [ ] 是否涉及"端到端可微"claim？
- [ ] 是否涉及"首个"表述？
- [ ] 是否把"我们抽象出的机制"误写成"对方论文原文贡献"？
- [ ] 是否与当前正文术语/结构口径冲突？

## 写作 Agent 接收确认
- [ ] 行号已 grep 确认
- [ ] 修改已附 diff 片段磁盘证据
- [ ] 红线检查全通过
```

## 字段定义（全部必填）

| 字段 | 说明 |
|---|---|
| **位置** | `§章节号 小节标题，L行号`。连续行用 `L12-18`，跨节用 `§2.3 L45 / §5.1 L210` |
| **当前写法** | 引用正文原句（`>` 引用块），不允许意译，`grep` 必须能命中 |
| **精读发现** | 只允许五类：事实偏差 / 遗漏 / 过强 claim / 命名冲突 / 引用错位 |
| **建议修改** | 修改后的完整句子（`>` 引用块），不允许"略""微调" |
| **优先级** | `必须`=不改会被审稿人抓；`可选`=改了更好；`不建议`=思路但不成熟 |
| **原因** | 精读笔记行号（`reading_notes/xxx.md L88`）或全文行号。不接受"直觉""感觉" |

## 批量模板

```markdown
# 批量精读动作清单（{YYYY-MM-DD}）

## 本轮升级的论文
| 论文 | 笔记路径 | 升级内容 |
|---|---|---|
| {简称} | `reading_notes/{slug}.md` | 速读→精读 |

## 影响正文汇总表
| 正文位置 | 涉及论文 | 当前问题 | 优先级 | 详见 |
|---|---|---|---|---|
| §2.3 L{xx} | {简称} | 描述不忠实原文 | 必须 | 下方 §2 清单 |

## §2 Related Work 详细清单
（每条按单篇 6 列格式）

## §4 Method / §5 Experiments / §6 Discussion
（同上，无影响写"无"）
```

## 写作 Agent 侧执行规则（供对齐）

1. 只接收表格格式；缺字段（位置/发现/修改）直接退回
2. `必须` → 立即改，改完在行尾加 `✅ 已改 L{新行号}`
3. `可选` → 自主判断，未改要写理由
4. `不建议` → 默认不改，记入 lessons 备查
5. 改前 `grep -n "原句关键词"` 确认行号（合并稿迭代会漂移）
6. 改后附 diff 片段作为磁盘证据
