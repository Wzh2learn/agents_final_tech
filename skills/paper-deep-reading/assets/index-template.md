# Reading Notes INDEX 模板

> INDEX 是**查找表**，不是阅读清单。
> 每篇一行，够判断"要不要看全文笔记"即可；全文笔记单独成文件，INDEX 只放指针。
> 按**研究方向**分组，不按时间排序。

## 模板

```markdown
# Reading Notes Index

> Papers: ~N | Directions: M | Last updated: YYYY-MM-DD
> 用途：写作 Agent / 研究 Agent 快速定位相关论文

## Overview

| 方向 | 篇数 | 覆盖度 | 主要竞品 |
|------|------|--------|----------|
| A. {方向1} | N | 100% | {论文 X 🔴} |
| B. {方向2} | M | 80% | {论文 Y 🟡} |

## A. {方向1}（N 篇）

> {一句话说明这个方向在研究什么}

| # | 论文 | 威胁 | 笔记文件 | 深度 | 关系 | 一句话结论 |
|---|------|------|----------|------|------|-----------|
| A1 | {Title (Venue Year)} | 🟢 | [link]({slug}.md) | deep-read | {与我们的关系} | {核心结论} |
| A2 | ... | 🟡 | ... | skim | ... | ... |

## B. {方向2}（M 篇）
...
```

## 威胁等级

| 标记 | 含义 | 动作 |
|---|---|---|
| 🔴 | 直接竞品，同赛道/同叙事 | Related Work 必须正面讨论，准备 rebuttal |
| 🟡 | 间接，同方向不同维度 | 引用并说明正交性 |
| 🟢 | 低威胁 / 互补 / 不竞争 | 按需引用，可用来支撑我们的 claim |

## 维护规则

1. **新论文立刻加行**（哪怕还没读，标 `unread`）
2. **读完立刻补一句话结论**（强制自己收敛）
3. **威胁等级是相对我们项目而言**（同一篇对不同项目可以是 🔴 或 🟢）
4. **每季度复评威胁等级**（新论文会把旧的 🟢 抬成 🟡）
5. **方向分组优先于时间排序**（读者关心"我这块有什么"，不是"这个月出了什么"）
