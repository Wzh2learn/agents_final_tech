### 2.2 预注册预测（实验型任务必填, 2026-08-25 合并自 GOAL_CARD_TEMPLATE Rule 4）

推导门失配 = 工件/实现不一致（查实现）; 经验预测失配 = 世界告诉了你新东西（入 findings）。
两者混报 = 把一致性检查包装成预测成功（或反之）, 审计无法分辨信息量来源。

## 8. 执行节奏纪律 (全局规则, 2026-08-25 用户批准)

- 主线程禁用 >5min 阻塞 sleep; 一切里程碑等待 = GB10 cron one-shot + 文件工件 + 结 turn。
  watcher session / sleep 链模式作废 (理由: 等待不是工作, 工件才是; 三害 = 阻塞插不进话 /
  上下文压缩 / ssh 长连接脆弱)。先例: 池xGUC 修复窗 (2026-08-25 凌晨) 门禁转 cron 工件。
- 收集与判定分离: 数据收集保留夜间 cron (机器时间, 流量干净); 一切需用户拍板的判定移至白天——
  主线程每日上午产出《判定一页纸》(分段数据 + 选项 + 推荐 + 红线核对), 用户白天圈选。
  任务卡不得把人类决策排在 22:00 后; 夜间窗口只执行已批准的确定性动作。
- cron one-shot 三件套: 跑完自删条目 (先例: b4_checkpoint) + abort 分支写死在脚本里
  (失败自动回滚, 不依赖主线程在线判断) + 工件路径在任务卡中显式声明。
- **UTF-8 字节截断必须字符安全（2026-08-25 E1b 钉死）**: `head -c N` 截中文/LLM 文本必配 `| iconv -f utf-8 -t utf-8 -c`;
  判定类工件读取默认 errors="replace" + 第二数据源（dispatch_log 等）兜底。
  案例: 08-25 gate=UNKNOWN——position 657 "资产市[值]"字符腰斩 → rd() 吞 UnicodeDecodeError 返回空串。回归用例 = 当晚 PASS。
- **cron 闸语义（2026-08-25 E1a 固化）**: 闸不达标 = 改期（至多 N 次）, **禁止 SKIP**;
  改期耗尽 = BLOCKED 标记 + 台账, 仍不静默。工具: scripts/graph/cron_gate_helper.sh。
  案例: 08-25 01:50 W4 闸撞 W3 eval 收尾（01:05→01:51）, SKIP 致 W5 连环 abort。
- **pending 卡交接必须 cron one-shot 触发（2026-08-25 E1c 固化）**: 入账"稍后执行"类任务卡
  必须同批安装触发 cron（或显式用户唤醒约定）; 禁止依赖"硬停后会话仍活"。
- **watcher 双实证 = 常备派发前置检查（A4w 落地, 2026-09-10; 不再逐窗重写）**: 任何任务卡只要安装
  cron/one-shot 观察器, 派发前必须跑 `scripts/graph/dispatch_precheck.sh` 并把输出**逐字入卡**作为证据。
  两项实证缺一不派发:
  ① **执行位实证** —— `--watcher <path>` 给出 mode + sha + `bash -n` 结果（无执行位 / 语法坏 / 0 字节 = FAIL）;
     同时用 `--cron-line '<cron 原文>'` 核验调用姿势: cron 直呼无执行位的路径 = F-0907-1 的复现条件, 判 FAIL;
     无重定向 = 静默失败连日志都不留, 亦 FAIL。
  ② **首次 tick 实证** —— `--tick-marker <path>`（可加 `--max-tick-age-min N`）要求观察器**真的跑过一次**
     并留下非空工件; 未提供该项即按「缺一不派发」处理。
  理由 = F-0907-1「挂了 crontab ≠ 观察器在跑」: 该次静默失败的成因是「脚本无执行位 + crontab 直呼路径」两条
  同时成立, 每次失败都无人看见。**本条只把取证动作常备化, 不改变 §8 既有的 sleep 禁令与三件套。**
  先例 = D4 卡 BG-7（该窗的双实证由 BG-7 自身承载, 本条是其 generalize 版本）。
- **窗口时段规则（2026-08-31 用户裁定明确化）**: 端点窗（任何 :8004/:8006/:8007 等模型服务调用）= 仅白天错峰,
  夜间零调用; 零端点窗（纯确定性计算/本地资产加载, 运行时断言零模型调用）= 不限时段。
  卡内必须显式声明窗口类型（端点窗/零端点窗）, 时段注记按本条销账或改期。
  案例: 08-25 晨间序列卡入账后零执行（会话未活, 无人触发）。与 sleep 禁令同源: 里程碑等待=工件化。
