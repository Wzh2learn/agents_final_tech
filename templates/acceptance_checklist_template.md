# 验收清单模板（声明 → 验证命令 → 实测值 三列）

> 模板版本 2026-08-22（夜间 graph engineering loop T2 产物）。原则: **声称必须带证据**——每一个"全绿 / 对齐 / 未动 / 在位 / PASS"类声明, 必须配一条可复跑的验证命令与一份实测值; 三列不齐 = 验收不过。本模板是"声明-实况对账审计"（2026-08-21 审计主题）的常态化落地。

## 用法

1. 把汇报中的所有声明逐条列出（含"pytest 全绿""三方对齐""冻结件未动""配置未改"）;
2. 每条声明配一条可复跑的验证命令;
3. 实测值列只粘贴真实输出摘录或实测数字, 不许转述、不许外推;
4. 配不出命令的声明降级为"未验证声明", 单列并明示——不得混入已验证声明。

## 模板

| # | 声明 | 验证命令 | 实测值 |
|---|------|----------|--------|
| 1 | <声明> | `<命令>` | <真实输出摘录 / 实测数字> |
