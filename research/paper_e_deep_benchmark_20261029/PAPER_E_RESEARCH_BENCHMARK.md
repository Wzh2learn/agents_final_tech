## A formal observation bound, presented as background

Let X be a set of possible executions, O: X→Y the evidence exposed to a detector, and H: X→{0,1} a fixed, independently defined target label under a specified contract. There exists a deterministic detector D: Y→{0,1} satisfying D(O(x)) = H(x) for every x if and only if H is constant on every fiber O⁻¹(y). Proof: equal O forces equal D outputs (necessity); if labels are constant, define D(y) as that label on the image of O (sufficiency). This is a straightforward finite observation/identifiability fact, not a claim of novel theory. It does not guarantee that any available algorithm can learn D, that H can be observed, or that the target contract captures real harm.

For a labelled finite panel with equal weights and 0–1 loss, a detector using only O has at least ∑y min(n(y,0), n(y,1)) errors. Abstention, unequal costs, randomized policies, stochastic observations and distribution shift require distinct formulations. `observability_fixture.py` exhaustively checks a **hand-constructed** six-world example: coarse minimum 2/6, enriched minimum 0/6. Its enriched observations were constructed from the target distinctions, so it is an illustrative mathematical check, not independent evidence, an Agent experiment or a learned method.

Important: Paper E's 13 unseen OCR-like changes do not have independently verified H=1; they cannot establish harmful observational collisions. The FinQA exercise deliberately does not recompute downstream results. A real test needs independently available, noncircular reference outcomes and compatible observation surfaces.

## Prospective Agent extension: qualified design, not a result

Question: under the same local model and tasks, which incorrect/unsafe final-output conclusions remain indistinguishable under final-answer-only evidence, and when does a bounded additional trace actually distinguish them? Treat an Agent as harness + model + tools + environment. Candidate controls: same OpenCode+Qwen tasks, final output only versus a predeclared non-secret trace schema versus deterministic execution oracle; an exact-match/always-accept comparator; same model and task inputs. A second harness or model only after compatibility and task semantics have been frozen. Preserve actual read/tool actions and final outputs, not generated summaries as ground truth. Include both independently adjudicated failure collisions and successful correct pairs; a trace may itself be incomplete, misleading or sensitive. Freeze datasets/source clusters, define H with independent behavioral checks, and quantify false accept/reject/abstain, total requests, wall time and token/tool costs. No claim that additional trace universally improves outcomes. TraceTrial-Bench and existing metamorphic Agent research must be compared as direct near neighbours.
