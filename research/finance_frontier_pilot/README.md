# 强基座零训练诊断

第一批对同一题分别运行自由推理和可执行 DSL。使用 `ODA-Fin-RL-8B` BF16 固定版本 `948c22ea48f9bf93e5747f4211657fcad9cb0295`，两臂均经 OpenCode 1.18.3。固定题干、报告输入与生成设置。27B FP8 在同一 DSL 合同下对首答错题独立作答。旧 Risk/Value 权重只读出分，首答同时作为两个状态，供分布迁移下比较。

- FinQA 官方 test 抽 200 题，114 道单步、86 道多步。与官方 TRAIN 表内容重复的 15 题排除。TAT-QA 官方 dev 抽 200 道算术题，来自 147 个表上下文，排除旧 C3 确认的 64 个表上下文。抽样以固定哈希排序，确认表只核对事先记录的成员标识。
- `M_strict` 两臂同用官方答案计分，DSL 可执行率另报。`M_norm` 是限定倍数下用参考答案复算的诊断。`M_rule` 在 TAT-QA DSL 臂使用已有公开尺度规则，其余沿用原答案。统计逐题救回与错改。自由臂剩余错误包含未能提取最终答案的情况。
- 表示分差包含输出截断、答案提取、显示精度和程序执行的影响。倍率归一的命中量与自由臂的剩余失分分别作为诊断指标，单独核对错误类型与覆盖率。
- 来源复核从可执行程序回映公开坐标。同值歧义未唯一消除时不传入白名单。报告错误检测 AUC、27B 能恢复的错题 AUC，以及两者的覆盖数和共同样本对照。

## 同预算对标准备

- CAR 按论文适配。每题计入一次五类诊断，使用官方训练集拟合遗漏率并校准恢复与错改。门控后用相近校准题的错误亚型选检查，再按公开证据指针作有界修订。 [CAR 方法与附录](https://arxiv.org/html/2611.05166v1#S4)
- BudgetVerify 按论文适配。保留首答、局部复查、独立解答后再比较三个固定动作。在官方训练集取得三个动作的成败与实付成本，再训练分档路由器。 [BudgetVerify 方法](https://arxiv.org/html/2609.33052v1#S3)
- Cascade Routing 复用作者代码。在官方训练集上以同版 8B、27B 和 DeepSeek 的真实匹配结果拟合质量、费用与协方差。作者路由可选择起始模型和跳过级别，固定从 8B 开始的级联另列。无 token logprobs 的模型端使用已记录的公开执行与回答一致性特征，并标明特征适配。 [Cascade Routing 作者实现](https://github.com/eth-sri/cascade-routing/tree/9da6cf7da39c42148eae0178635e9211e5b67742)

共享相同设置的首答、证据和评分。探针的 27B 独立重解只覆盖首答错题。端到端比较另行记录正确首答上的保持和错改，以及本地生成、核验和教师的实际 tokens 与墙时。

`benchmark_panels.py` 固定官方 TRAIN 中独立来源的拟合与校准面板，各数据集预备 96/48 个来源。FinQA 从以往证实与封存组分离的 153 个 TRAIN 来源取样。按题号、报告、公司年份和表内容排除与官方评测的重叠，独立保存公开题面和答案。完整评测索引的既有暴露标记仅用于分组报告。
