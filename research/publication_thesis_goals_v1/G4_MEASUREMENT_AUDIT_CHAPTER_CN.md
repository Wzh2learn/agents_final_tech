# 第3章 智能体任务评测的测量有效性审计

## 3.1 研究问题与本章边界

长流程文档智能系统通常按照“文档解析、表格抽取、模式映射、数值核对、答案生成”的顺序组织。现有评价往往只报告最终答案正确率或单一综合分数，但这种分数无法区分以下情况：缺陷根本没有进入观测面；缺陷已经被中间检查点看到，却没有被最终判定规则消费；缺陷虽然改变了中间状态，却在既定等价关系下不影响最终结果；或者指标数值变化了，但基准所支持的定性判断并未改变。因此，本章不研究某个分层评分器是否普遍优于扁平评分器，而是审计一个更基础的问题：**评测所报告的分数、可见错误和实际结论之间究竟具有什么关系？**

本章的证据来自两个相互独立、但共享测量问题的案例。案例一是一个冻结的分阶段文档评测器，使用公开 TAT-QA 表格派生语料和受控表头扰动，考察评测结构是否能够观察、检测并解释缺陷。FinQA 程序扰动只作为案例一内部的边界探针，用于检查扰动对象与检测规则是否绑定到同一因果更新对象，不计为第三个案例。案例二是 FinRank 证据排序基准的来源知情实现审计，考察平局策略、来源身份构造和复现环境如何影响绝对分数与基准结论。两项研究分别回答“评测是否看见了什么”和“评分合同改变了什么”，并不推导通用智能体理论。

本章形成三项可写入学位论文的基础结论。第一，可见性、检测和危害性是不同测量对象，必须分开报告。第二，分值敏感性与决策稳定性不能互相替代，绝对分数变化不等于基准结论反转。第三，复现结论必须绑定指标层级、数值容差和运行环境，不能把部分指标精确复现扩展为完整基准复现。后续章节拟研究的变化任务正确性验证和证据驱动重验证属于候选贡献，不能反向改写本章已经冻结的两案例结论。

## 3.2 六个测量构念及其关系

本章统一使用以下六个构念。

1. **可见性（visibility）**：某个指定观测评分面是否观察到受控变化。
2. **检测（detection）**：判定规则是否消费了该观察，并在既定阈值下触发。
3. **危害性（harmfulness）**：变化是否破坏既定等价关系下的结果、事实或决策。危害性依赖等价合同，不是可见性的同义词。
4. **分值敏感性（score sensitivity）**：评分、平局或归一化合同改变时，绝对指标移动多少。
5. **决策稳定性（decision stability）**：合同变化后，基准支持的定性判断或排序是否保持。
6. **复现差距（reproduction gap）**：独立执行结果与发布值在明确环境和容差下不一致。它描述现象，不在证据不足时直接指定原因。

这组定义的目的不是建立新的因果理论，而是防止把不同对象合并为一个“错误率”。例如，一个缺陷可能在检查点上可见，但最终协议没有消费该证据；也可能完全不可见，却仍按等价合同无害。类似地，绝对随机负例准确率可以对平局策略敏感，而“困难负例比随机负例更难”的方向保持不变。若把这些情况都写成“基准失效”或“方法有效”，就会把测量合同问题误读为模型能力问题。

## 3.3 案例一：分阶段文档评测器的审计设计

### 3.3.1 证据工具与受控扰动

案例一使用两棵检查点树组成证据森林，共十二个叶子。叶子接收 `[0,10]` 分值：可合同化属性使用确定性检查，语义属性使用固定语义裁判的 `0-5` 分并映射到 `[0,10]`。缺失证据具有显式表示，解析树记为零，问答树使用中性五分。节点分值按照子节点权重进行局部归一化后自底向上聚合。只有当至少 90% 的叶子超过阈值且所有关键叶子不低于七分时，系统才判为稳定。

语料包含九十五个注入载体表格和一百一十八个合成扰动，扰动分为别名变体、日期变体、混合语言、OCR-like、前缀噪声和单位后缀六类。OCR-like 族包含十三个单 token、小写、Levenshtein 距离为一的替换，列值本身不发生变化。实验改变注入种子、可见性阈值、匹配算法和分值归一化方式。语义裁判与确定性证据分开报告，不以模型判断替代已经存在的合同。

案例一的观察面和检测面必须分开。检查点可见性使用冻结证据面进行统计；协议检测则由各自的判定谓词决定。二者不是同一组计数的分区，因此不能把“九十六个可见注入”和协议级检测率直接排列成互斥结果。

### 3.3.2 分值结构与可识别性

在只有一个响应叶子发生变化的构造中，未取整的扁平分和分层分是正仿射变换，并保持相同排序。因此，两种协议在该构造中的决策具有结构等价性。原始检测数量差异来自阈值放置，而不是已经证明的协议判别力差异。另一方面，清洁对照面板按构造全为零，无法唯一识别实际部署工作点；这属于校准支持集退化，不是对所有匹配 FPR 比较的普遍不可识别性结论。

为检查层级结构是否真正携带阶段信息，实验另设受控多叶构造。每个阶段合同只扰动一种操作：映射阶段修改表头 token，检索阶段删除所需来源块，数值阶段破坏一个操作数。响应谓词直接来自阶段合同。全十二叶向量、固定三个直接叶子的 codebook、非直接叶子和单一任意响应标量分别评分。该构造必须被解释为显式仪器化实验，而不是自然失败定位。

### 3.3.3 FinQA 边界探针

FinQA 探针冻结了30个 report clusters 上的89行程序扰动，并验证逐行运行时绑定与完整 trace map。扰动写入操作符或参数字段，但下游结果字段没有从扰动后的程序语义重新生成。因此，检测谓词即使定义完整，也无法对该扰动产生因果响应。正式结果类别是 `SECOND_FLOW_MIXED`，科学解释限定为 `MEASUREMENT_OBJECT_MISMATCH`：扰动对象和检测对象没有绑定到同一因果更新链。该结果不是“协议失明”的证据，也不是检测能力的零估计。

## 3.4 案例一的审计结果

### 3.4.1 缺陷族决定可见性

检查点层面共有 `96/118` 个注入可见，但总体比例掩盖了明显的描述性族间差异。OCR-like 族在五个阈值下均为 `0/13`，涉及十一个表格集群；其他族在主设置下可见率为 0.81 到 1.00。若把注入暂时视为独立单位，`0/13` 的精确二项 95% 区间为 `[0,24.71%]`；若按不同表格事件计算，`0/11` 的区间为 `[0,28.49%]`。后者不是注入层面的聚类置信区间，不能混用。

OCR-like 族在四个编辑距离匹配配置下仍保持不可见，但完整族排序并不稳定：改变分值归一化会在日期变体族中产生五个类别翻转，而从贪心匹配切换到全局匹配不产生翻转。因此，“存在一个在冻结评分面未被观察的族”在已测匹配族内稳定，但完整排序具有协议依赖性。

危害性仍然需要独立等价合同。已有单一语义裁判按照“读者能否恢复同一指称”的表上下文合同，把十三个 OCR-like 扰动都判为指称等价。这支持“良性吸收”是合理替代解释，但该裁判不是独立人工真值，也不能把未响应自动升级成有害假阴性。本章只报告观察边界，不报告普遍危害率。

### 3.4.2 三个注入种子的重复性与分析单位

三个注入种子下，扁平协议的表格检测率分别为 `75/95 = 0.7895`、`76/97 = 0.7835` 和 `68/90 = 0.7556`。按表格运行加权的描述性点估计为 `219/282 = 0.7766`。但是，这二百八十二个表格运行只映射到一百一十九个唯一来源表格 UID：二十九个 UID 只出现一次，十七个出现两次，七十三个在三个种子中都出现。

因此，跨种子不确定性按来源表格 UID 聚类。两万次 UID cluster bootstrap 的 95% 区间为 `[0.7117,0.8364]`。若对每个来源 UID 等权，估计为 `0.7535`，区间为 `[0.6835,0.8207]`。三个种子的范围为 0.0339；依次去掉一个种子后的表格运行率为 0.7701、0.7730 和 0.7865。由于只有三个种子，本章不估计未来种子总体区间，只报告种子范围和 leave-one-seed-out 敏感性。历史上的朴素表格运行区间 `[0.7270,0.8227]` 保留在日期化重分析记录中，但不再作为来源表格不确定性。

该重分析是冻结确定性材料上的事后复核。它没有修改原始注入、检查点、语义裁判或分值结果，也不把三个种子解释为未来注入分布的随机样本。

### 3.4.3 分层结构的收益边界

原始层级检测差距不能直接解释为层级协议更优，因为不同协议采用不同判定落点。在单响应叶构造中，扁平和分层分正仿射等价且排序相同；阈值差异解释了原始计数差异。真正的多叶阶段分离来自显式阶段对齐仪器：完整响应向量与三个直接叶子的 codebook 都达到完全分离，而非直接叶只保留部分阶段信息。它们能把映射与检索/数值区分开，但不能把检索与数值彼此分开。

因此，本章不主张层级结构自行产生自然故障定位。可成立的结论更窄：当响应谓词直接写自阶段合同时，仪器可以携带可分离签名；层级组织本身是否提供增量信息，仍需独立变化的自然任务和非对齐对照。

### 3.4.4 测量对象错位

FinQA 探针中，操作符和参数扰动可见，但检测规则读取的下游结果字段没有被扰动程序重新计算。因而，检测计数虽然可复现，却不能估计检测能力。这说明一个容易被忽略的设计要求：扰动、状态更新、证据读取和判定谓词必须绑定到同一因果更新对象。它是设计约束，不是已经验证的普适定律。

## 3.5 案例二：FinRank 证据排序审计

FinRank 是一个来源敏感的金融证据排序基准，包含人工问题、参考答案、gold passages 和精选困难负例，覆盖二十二家公司。审计只使用公开 JSONL、代码、split/random seed 和结果文件，重新执行 TF-IDF 与 BM25；神经基线和答案生成不在范围内。

审计在读取逐对结果前固定研究问题、平局指标和重要性阈值。V1 使用 ties-positive、strict-win 和 half-credit 三种逐对策略，并固定 1.0 个百分点的逐对值或困难度差距移动阈值，以及 0.5 个百分点的全局平局顺序移动阈值。V1 的来源身份规则错误地使用 raw exact identity；后续 canonical trimmed `text_sha1` 修正是明确的事后 V2，不重新命名为盲发现。

### 3.5.1 分值敏感性不等于决策反转

两个确定性评分矩阵都存在精确平局。TF-IDF 有九十一对困难对和一百三十五对随机对平局；BM25 分别有八十三和一百二十五对。把 ties-positive 改成 strict-win 后，随机负例准确率在 TF-IDF 和 BM25 上分别移动 1.084 和 1.029 个百分点，超过预注册的 1.0 阈值。这是分值敏感性。

与此同时，困难负例与随机负例的差距只移动 0.359 和 0.343 个百分点，并在 strict-win 和 half-credit 下保持方向。TF-IDF 的三种平局策略差距为 14.179、13.820 和 14.000 个百分点，BM25 为 13.009、12.666 和 12.838 个百分点。因此，基准支持的窄定性判断在测试合同下保持稳定。分值敏感性和决策稳定性必须分别报告。

### 3.5.2 来源身份与复现边界

V1 的 preregistered raw-exact 结果 `293/220` 保持原样。canonical trimmed `text_sha1` 的事后 V2 结果显示：305 条记录中，有 442 个跨记录重叠困难负例；元数据过滤会丢失 33 条记录的 gold，其中 2 条全部 gold 丢失。上述 `442/305` 和 `33/2` 只能标注为错误身份规则应用后的事后更正，不能升级成独立发现的原 benchmark 漏洞。

复现检查也必须按指标分层。在声明环境中，记录内和逐对指标精确复现；全局和元数据过滤指标分别最多漂移 0.19 和 0.16 个百分点。缺少原始完整 score matrices 或锁定传递环境时，本章不把漂移归因于某个确定实现错误，只保留“复现差距原因未解释”。

## 3.6 跨案例解释修正

| 常见解释 | 审计证据 | 修订解释 |
|---|---|---|
| 分数差距更大，说明某评测器更能排序缺陷 | 单响应叶构造中扁平与分层分正仿射/排序等价，原始差距来自阈值放置 | 比较协议前先报告分值代数与阈值可识别性 |
| 永不触发的族就是有害盲区 | OCR-like 在冻结面 `0/13` 不可见，但已有裁判按不同等价合同判为等价 | 未响应只证明观察边界；危害性需独立等价合同 |
| 完美阶段定位证明层级评测发现阶段 | 直接阶段叶与全向量一致，非直接叶仅部分分离 | 收益来自显式阶段仪器，不是层级结构自身 |
| 绝对指标变化意味着基准决策改变 | 平局策略移动绝对准确率约 1.03-1.08 点，但困难度差距只移动 0.34-0.36 点且方向不变 | 分值敏感性与决策稳定性分开报告 |
| 确定性重跑就等于完整复现 | 记录内和逐对指标精确，而全局与元数据指标仍有漂移 | 复现声明必须给出环境、容差与指标范围 |

这张表的外部用途是改变审计顺序：先固定测量对象和等价合同，再讨论阈值、评分和模型比较。否则，即使最终分数一致，也可能只是回退路径、阈值设置或身份规则掩盖了没有完成的目标变化。

## 3.7 与相邻工作的关系

元评测、构造有效性、故障注入、变异测试、oracle 设计和过程级评价都与本章相关。ACES 等 challenge set 研究指标能否区分真实错误与可接受变体；construct-validity 工作要求指标测量其声明构念；故障注入和变异测试使用受控错误检查测试或指标敏感性；过程级评价关注中间行为而不只最终成功。本章的增量不是重新定义这些领域，而是把“没有检测到”拆成观察面不可见、判定规则未消费、危害性等价、评分合同敏感、决策稳定和复现差距，并在两个实际评测构造中分别报告。

NIST Cybersecurity Framework 和 ITIL (Version 5) 只提供风险管理、服务变化和持续改进的背景。它们不验证本章的测量方法，也不把案例结果转换为标准符合性结论。

## 3.8 局限与结论

本章证据仍有限。案例一使用一个公开表格语料上的合成扰动，不覆盖自然失败分布或跨领域迁移；危害性依赖等价合同；三个注入种子只是敏感性运行。多叶阶段定位来自合同派生响应谓词，不能证明层级结构在自然任务上具有涌现定位能力。FinQA 的替代解释还包括 scorer 不可移植、阈值不迁移和语料偏移，本章没有排除它们。案例二只覆盖 TF-IDF 与 BM25，不含神经排序或答案生成；其身份修正是事后 V2，残余全局复现差距仍未解释。

因此，本章最稳健的贡献是一个受限的两案例测量审计：它展示如何把可见性、检测、合同相对危害、分值敏感性、决策稳定性和复现差距放入同一报告面，并给出一套尚待外部验证的六步审查顺序。它不主张通用有效性理论、普适检测器排名或已经验证的通用方法。下一章将从“任务是否被正确测量”转向“任务要求的变化是否真正完成”，但必须使用独立行为参考和结构/消费证据，不能把本章的测量反例直接当作新算法有效性的证明。
