# Author, Artifact And Submission Checklist

## Author Block

- [ ] Applicant is first author.
- [ ] BUPT is the first listed affiliation.
- [ ] Full author order and corresponding-author details approved.
- [ ] Anonymous manuscript contains no author names, affiliations or
      identity-revealing repository links. The AI-use acknowledgment is
      permitted only in the venue-approved form.

## Scientific Package

- [x] Canonical manuscript is the only active source.
- [x] Exactly two counted cases; FinQA remains nested in Case 1.
- [x] FinRank `442/305` and `33/2` remain labelled post-hoc v2 corrections.
- [x] Injection-seed point estimate retained; clustered and UID-equal
      intervals reported.
- [x] Limitations and unresolved reproduction gap are explicit.
- [ ] Final independent reviewer pass completed after venue adaptation.

## Artifact And Data

- [ ] Owner approves an anonymized repository or artifact URL/DOI.
- [ ] Public release package contains scripts, manifests, frozen results and
      licenses but excludes credentials, private data and internal-only AI
      review records.
- [ ] Existing public GitHub history is described honestly; no attempt is made
      to fabricate non-public status by deleting history.
- [ ] FinRank CC BY-NC 4.0 and TAT-QA source terms are recorded in the
      artifact README.

## Venue And Presentation

- [x] Primary ICAART and backup IEEE Access are selected; SN Computer Science
      is tertiary.
- [x] Current PDF is double-blind and checked for 12-page ICAART layout; final upload
      must recheck the live ICAART system/template.
- [ ] AI-use disclosure matches venue requirements.
- [ ] Registration and travel budget approved.
- [ ] If remote presentation is needed, Owner confirms whether it satisfies
      the school's recognition requirement.
- [ ] Final submission, copyright and payment explicitly approved by Owner.

## Recognition Evidence To Retain

For ICAART: final proceedings paper, ISBN/SCITEPRESS record, conference
program, presentation certificate or equivalent evidence that the paper was
actually presented. Online publication alone is not enough if presentation
did not occur.

For a journal: Owner-confirmed formal publication credential and the exact
online/issue publication evidence accepted by the school.
