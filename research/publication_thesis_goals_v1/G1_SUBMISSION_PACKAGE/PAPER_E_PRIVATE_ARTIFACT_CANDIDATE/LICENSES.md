# Licenses And Release Boundary

## Source Data

- TAT-QA dataset: CC BY 4.0 according to the official dataset README captured in
  the source audit. The TAT-QA repository code is MIT; dataset and code terms are
  separate.
- FinRank repository and released data package: CC BY-NC 4.0 according to the
  pinned repository record used by the audit.

## Candidate Contents

The source repository has no repository-wide `LICENSE` file at the audited
revision. Therefore no license is asserted for the newly written reproduction
scripts in this candidate. Before public release, the Owner must choose a code
license and confirm that the selected venue permits the proposed supplement.

No private data, credentials, model keys or internal review transcripts are
included. Public release and DOI creation are not authorized by this candidate
package.
