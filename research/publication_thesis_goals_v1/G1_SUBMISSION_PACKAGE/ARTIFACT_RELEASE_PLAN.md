# Artifact Release Plan

Status: `DRAFT_NO_PUBLIC_RELEASE`

## Intended Artifact

- anonymized manuscript source and bibliography;
- bound figure sources and hashes;
- deterministic audit scripts and frozen configuration;
- FinRank preregistration, v1 raw application and post-hoc v2 correction;
- source manifests and reproduction instructions;
- no private data, credentials, raw model keys or unreviewed intermediate
  repositories.

## Release Gates

1. Patent status confirmed.
2. Repository license and third-party data terms checked.
3. Author list and affiliation disclosure approved.
4. Venue supplementary-material and double-blind rules checked.
5. Anonymous archive tested from a clean environment.
6. Persistent DOI or venue-supported artifact link created.

The current public Git history must not be hidden or rewritten to imply that the
work was never public. The anonymous review artifact can be a separate,
restricted package with a redaction map.

## Candidate Evidence

For IEEE Access, supplemental code/data can be submitted for review and later
participate in the reproducibility initiative. For ICAART, the live venue rules
must determine whether artifacts are anonymous supplementary material or a
post-review link.
