# Feedback And Delivery Continuation Spec

Goal: repair the P0 semantic-contract and policy-scoring defects, run a
same-candidate feedback intervention, then use evidence to decide whether a
true ordinary-checkpoint continuation experiment and final delivery
confirmation are justified, while preparing Paper E for submission.

Done when:

- constant-role classification rejects non-average ratios, counts explicit
  year ranges correctly, and treats already-correct structural constants as
  idempotent;
- multi-row table headers preserve visible period/unit/role bindings with
  explicit conflict and unresolved states;
- repair policies score their own selected candidate/action/cost and rerun the
  full visible semantic contract after repair;
- P0 impact analysis distinguishes unaffected historical results, affected
  replay results and unresolved cases;
- Experiment A compares original, ordinary retry, execution feedback and
  localization feedback on the same frozen natural candidates with matched
  one-call budgets and full-denominator transition metrics;
- Experiment B runs only if qualified supervision exists, using O/R/E from the
  same ordinary checkpoint with matched updates and verifiable adapter hashes;
- Experiment C compares original, ordinary retry, transparent check and the
  development-selected one-shot repair on frozen outputs;
- Paper E has a concrete ICAART versus SN Computer Science recommendation and
  a complete owner-action page;
- affected tests, JSON/hash checks, docs lint, Git synchronization and resource
  accounting pass.

Never touch:

- production services, production Memory, credentials, `:5050`, frozen hash
  manifests, frozen raw responses or historical score files;
- hidden reference answers as deployment policy features or candidate
  selectors.

Stop if:

- more than eight files outside the continuation package, existing research
  runners/tests and Paper E package change;
- an existing passing affected test starts failing;
- source-role separation or supervision qualification cannot be established
  without relabelling seen data as confirmation;
- external submission, payment, authorship or publication would be required
  without Owner authorization.
