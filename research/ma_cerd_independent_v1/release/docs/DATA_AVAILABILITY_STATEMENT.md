# Data Availability Statement

The complete anonymized 1,000-record MA-CERD Gold benchmark, data dictionary, JSON Schema, family-level split manifest, reference evaluation and validation scripts, and SHA-256 manifest are prepared for public release on Zenodo as version 1.0.0. The Zenodo concept DOI for the dataset series is **10.5281/zenodo.21946187** and becomes registered when the first version is published.

The dataset, metadata, schema, and documentation are licensed under **CC BY 4.0**. The Python scripts under `scripts/` are licensed under the **Apache License 2.0**. Identity-bearing reviewer records, signatures, private correspondence, raw free-text responses, and restricted provenance remain under controlled access. The O3 evidence is deterministic simulator-only shadow-mode output and does not establish physical, operational, or deployment validity.
