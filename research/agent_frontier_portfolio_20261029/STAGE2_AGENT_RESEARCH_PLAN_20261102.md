# 第二阶段：真实反馈如何改变 Agent 决策

> 2026-11-11。Goal暂停；吸收8ab61632快照的专家建议。inquiry：最小实验；本轮仅规划。

## 目标与裁决

面向IJCNN 2027和硕士研究，探索Agent如何利用真实反馈调整行动与经验，适应任务、工具或环境变化。复用GB10＋OpenCode＋本地模型；Paper E独立等导师反馈。

**主攻候选FCDR：**将反馈绑定到它实际支持/否定的决策前提和公开状态，选择重新取证、局部调整或重规划，检验真实任务收益。尚无已验证新方法；CCER降为工具组件，ECCE只按需辅助，不并开研究线。

**关键假设：**A，存在已送达反馈被漏用或越范围误用的可干预节点；B，作用范围与前提更新优于普通反馈恢复/简单规则；C，收益在独立任务上超过形成与干预成本。先检验A，再用实际干预检验B/C。

原型前补齐前提匹配和下一行动规则，针对[最近邻](IJCNN_RELATED_WORK_REFRESH_20261030.md)写可反证预测；不要求先证明普遍理论。研究执行须用户恢复Goal。

## 恢复后的执行顺序

1. **短批尸检（最多48小时）。**抽Matplotlib/SymPy/Astropy少量节点，核对动作→反馈→送达→下一动作→结果，交付干预点或无节点结论。ALF作范围规则对照，Sphinx按需查送达。原地记录，不扩建事件库或填满时限。
2. **最小机制。**定义反馈作用域、前提匹配与行动选择，先不训练。用当时公开信息，退出后评分不作在线输入，自写测试只作局部证据，hash变化不全量作废反馈。查具体最近邻后尽快做原型。
3. **递进对照。**固定模型/OpenCode，先比普通反馈恢复、简单状态/版本规则，再补无经验、完整历史、同预算重试及适用近邻。匹配初始状态/公开信息/权限/预算，随机顺序并记录seed；以真实分支执行检验B。
4. **扩样与去留。**约一周开发后判定；两个项目有信号再扩未曝光任务、重复和消融，按方差定确认规模。保留历史强基线及全成本，可靠监督出现后按需训练；无残差及时换机制/问题。

### 明确停止条件

- 无适用在线反馈、无可改变节点：停止当前FCDR版本；不反复加prompt或资格分支。
- 规则/普通恢复同效更省，或只改动作却无成功/成本收益：停止或修订机制。
- 收益来自额外信息/尝试/权限，或独立任务不复现：收窄或换题，不包装为方法增量。

每批报告假设变化、基线增量、全成本及下一动作。主指标为成功与成本折中，另记反馈采纳/越界及适用的源回归。形成/执行/训练/研发分账，缓存分列、未知不填零；开发/确认及评分参考隔离。工程服务当前实验，重大转向可请专家。运行/投稿按[入口](../../docs/research/LOOP_D_RESEARCH_PROMPT.md)授权。
