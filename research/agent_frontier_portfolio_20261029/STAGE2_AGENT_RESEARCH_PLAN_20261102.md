# 第二阶段：反馈条件化的可复用纠正技能学习

> 2026-11-12。Goal active；用户已确认FCCL主线及校内API总额度1000M。inquiry：first-principles → minimal-experiment；依据最新专家全文及独立复核调整，不再以主动审计为论文主线。

## 研究问题与第一条技能

**问题：**Agent能否从真实纠正成败中，学到“同类反馈在什么执行条件下应采用哪一种纠正片段”，并在新任务中提高成功率或降低同等成功的全成本？FCCL为工作名，方法有效性和独立增量均待实验。

**第一条技能：接口纠正时保留已满足的功能约束。**根据调用关系/反馈修复绑定或结果适配，检查后决定退出/继续。Astropy旧A5删操作数破坏回归仅作开发动机，不把手写禁令当学习。

**表示：**输入x=(h,f,e,q)，分别为决策前公开历史、实际在线反馈、可见环境/接口绑定、当前已有检查证据。隐藏评分、参考补丁、未来动作不进入x。技能ω=(I,π,β,V)含适用条件、可执行纠正策略、退出条件与公开验收；经典option表示本身不主张新颖性。

**旧参考：**[原型](corrective_skill_policy.py)配对偏好/布尔效果转移未超过强基线；文字卡片/自由绑定路线停止，见[实跑](results/FCCL_FORMATION.md#transfer-v1)。

**学习靶标：**Pθ(x)输出程序、绑定b、前提I与退出β，条件可在程序内部。实际完整程序后果约束候选，反馈修订受反例否定的绑定/分支。Getafix/CEGIS/CIPO/SkillRevise是参照，不单独算创新。

**旧面板：**[结构参照](results/FCCL_FORMATION.md#program-learning-v2)已够用；[固定谓词分类](results/FCCL_FORMATION.md#relation-learning-v1)与Find-S同效。停止对应选择器、表示变体与分类层；这些不是独立迁移证据。

**当前新证据：**[两源开发](results/FCCL_FORMATION.md#counterexample-dev-v1)已执行47次校内请求。21171最小幂表达式不再报错但未满足精确格式；16792复现数组类型丢失，基础Agent/普通形成均未修改生产文件；紧凑诊断响应未知。不据此否定学习机制，也不继续同题提示。

**下一可执行候选：**输入公开执行对照/AST，对齐入参角色σ，逆向提取成功路径片段τ，生成条件I和可调用程序。更新V←{ω∈V:无已完成执行反例}；未知留待验，不算通过，候选分歧回普通纠正。[四态见证](results/FCCL_FORMATION.md#donor-role-v1)已补齐作用范围/别名，并暴露IndexedBase归一化。下一直接实现学习器、生成并原生重放完整候选，禁止D填目标补丁；先实现，不再重复源题提示/资格。静态供体穷举、CodePhage/ReGAL与普通反馈为参照，独立增量由新任务检验。

**监督与退出：**完整程序及续行结果产生监督；多种修法有效则保留多解，不造唯一负例。共同失败不造正例，9/10也不算整题成功。强基线共享源程序、AST/栈线索、反馈和总预算，各组程序由同一入口实际调用，再交共同Agent续做。静态程序已够用则不训练选择器；留出不调参，不在测试现场免费试遍候选。
