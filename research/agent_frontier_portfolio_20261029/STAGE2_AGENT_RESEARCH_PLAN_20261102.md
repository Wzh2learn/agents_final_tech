# 第二阶段：反馈条件化的可复用纠正技能学习

> 2026-11-12。Goal active；用户已确认FCCL主线及校内API总额度1000M。inquiry：first-principles → minimal-experiment；依据最新专家全文及独立复核调整，不再以主动审计为论文主线。

## 研究问题与第一条技能

**问题：**Agent能否从真实纠正成败中，学到“同类反馈在什么执行条件下应采用哪一种纠正片段”，并在新任务中提高成功率或降低同等成功的全成本？FCCL为工作名，方法有效性和独立增量均待实验。

**第一条技能：修复调用/返回契约时保留已满足的功能约束。**代码报接口、返回结构或参数错误时，不能仅靠删除操作数、绕过分支消除报错；应依据当前调用关系与已获得的反馈，选择适当的调用绑定修复或结果适配修复，再执行检查并决定退出/继续。Astropy旧A5中删除第二操作数破坏回归，是开发动机而非新方法结果；不把一句手写禁令当学习。

**表示：**输入x=(h,f,e,q)，分别为决策前公开历史、实际在线反馈、可见环境/接口绑定、当前已有检查证据。隐藏评分、参考补丁、未来动作不进入x。技能ω=(I,π,β,V)含适用条件、可执行纠正策略、退出条件与公开验收；经典option表示本身不主张新颖性。

**候选学习规则v0（[轻量原型](corrective_skill_policy.py)已实现，真实收益待验证）：**
1. 从真实失败→纠正轨迹提取片段、公开条件和实际工具步骤。生成/绑定具体文件与参数的成本计入形成；不能只输出INSPECT/PATCH等标签。
2. 开发期在相同公开起点比较两个完整片段，随后共用同一续行策略和资源帽；以最终原生成功、回归和总成本形成条件偏好。共同失败不造正例；同成功而成本不同只记成本偏好，不归因第一步。
3. 保留正、负及无差异证据，更新条件化片段评分gθ(x,ω)。首版可用轻量配对逻辑模型：L=−Σw·log σ(gθ(x,ω+)−gθ(x,ω−))，θ按该损失更新；特征须包含反馈×可见接口条件×片段类型交互。仅在训练来源拟合/选择特征，留出不再调参。
4. 部署只依据x选择并绑定一个片段，执行后依据新公开反馈继续或退出；未知条件回到普通纠正，不在测试现场免费跑遍各候选。历史结果更新训练库与当前部署策略须分开记录。

**下一学习靶标：纠正步骤的条件适用与组合。**现有参考仅对人工族与类别条件评分，不读片段内部步骤；`propose`保留同族备选，未见条件组合仍回退。下一候选须从实际执行学习步骤对公开行为的作用及依赖，依据反馈、已通过行为与接口绑定，输出保留/补做/撤销的具体工具步骤和退出条件。SymPy来源四子集公开检查2/4/3/5，Astropy组合3/3而单项0/3、2/3，提供步骤效应实例；不把条件组合或常规配对损失当新理论。独立来源必须需要不同纠正，固定幂等全量或简单查表同效更省则停。

## 最近邻与可判别差异

本轮重读一手方法页，未复现原法：
- [Agent-R](https://arxiv.org/html/2501.11425v1)：MCTS连接错误/正确前缀并迭代训练纠正轨迹；不能声称首次从失败接续学习。
- [STeP](https://arxiv.org/html/2505.20023v1)：教师反思轨迹及错误部分mask；不能把纠正SFT当增量。
- [SkillRevise](https://arxiv.org/html/2606.01139v4)：可执行锚点、保留约束、重执行及效用门；不能说它只改文本。需验证条件策略是否超过其匹配适配版。
- [AdaMEM](https://arxiv.org/html/2606.05684v1)：动态策略记忆及动作改变筛选；需用真实执行片段的后果证明价值，而非仅动作不同。
- [SkillApt](https://arxiv.org/html/2609.26863v3)与[CIPO](https://arxiv.org/html/2610.04991v1)已覆盖条件效用/同前缀分支；必须面对其强基线，不把配对或路由改名为创新。详表见[近邻](IJCNN_RELATED_WORK_REFRESH_20261030.md)。
