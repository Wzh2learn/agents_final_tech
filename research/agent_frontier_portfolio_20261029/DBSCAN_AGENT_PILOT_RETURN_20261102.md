# DBSCAN 合同变化：真实 Agent 经验复用开发试验

2026-11-02。状态：`SINGLE_FAMILY_DEVELOPMENT_WITH_REAL_SOURCE_TRANSFER`。本试验回答：在同一科学计算工作流中，目标合同改变后，Agent 是否能阅读并适配实际源程序；无历史 Agent 和针对可见变化的简单规则表现如何？结果不是官方 benchmark 成绩，也不是跨来源确认。

## 设计与结果

根据[计划](archive/plans/DBSCAN_AGENT_PILOT_PLAN_20261102.md)，源任务的 DBSCAN 使用加权欧氏距离，目标任务使用加权切比雪夫距离；专家匹配仍为标准欧氏距离。两任务来自同一个公开来源族、共享数据和测试实现，研究者此前已阅读公开参考；模型训练集是否包含该任务未知。

| 条件 | 结果 | 请求 | 报告总 token | 墙时 |
|---|---|---:|---:|---:|
| 源任务，无历史 | 原测试 8/8；20/20 参考参数点匹配 | 17 | 274,459 | 367.879 s |
| 目标任务，无历史 | 原测试 8/8；18/18 参考参数点匹配 | 7 | 68,451 | 225.293 s |
| 目标任务，真实源说明和程序 | 原测试 8/8；18/18 参考参数点匹配 | 9 | 141,485 | 226.690 s |
| 目标任务，人工识别变化并修改源程序距离配置 | 原测试 8/8；18/18 参考参数点匹配 | 0 | 0 | 85.107 s 求解 + 0.666 s 验证 |

前三项是分别运行一次的 Qwen3.6-35B-A3B / OpenCode 轨迹，均有独立输出和隔离后的测试；模型服务标识来自运行配置，本地实际权重哈希未独立核验。第四项是事先写明的**人工辅助、案例专用透明规则**，不是自主学习，墙时不包含人工分析及准备，不能将 85 秒直接当成端到端人工成本。目标无历史、源历史及透明规则输出文件的 SHA-256 均为 `a20dc0c452dc2ce12ea6284205b43afa3ded58d3f83ada73eb58c3da934bdcf8`，表示本次结果文件字节相同，不表示三个程序相同。

源历史组有一次显式 `read` 旧任务说明和一次显式 `read` 旧程序；其实际目标程序保留了大部分源工作流，把 DBSCAN 改为 `metric='chebyshev'`，仍以标准欧氏距离匹配专家。它是一个**真实读取并适配源程序**的开发观察，而不是仅将经验文件放在上下文中。目标无历史和历史组均取得同样正确输出，本次历史组请求更多、报告总 token 更高，墙时相近；两个条件各只有一次运行，模型服务缓存未重置，不能据此给出总体效率差、统计显著性或经验普遍无效的结论。

作为事后错误迁移对照，直接拿源任务结果与目标参考比较：目标 18 个参考参数点中 `0/18` 与对应目标值匹配；源输出的 20 行中，9 行与相同目标参考参数的值不匹配，另有 11 行不在目标发布的参考前沿内，后者未另行重算、标为 `UNRESOLVED`。这是人工构造的陈旧输出，不是某次 Agent 实际选择了错误方案。原测试曾被额外矛盾行骗过，因此另按冻结脚本检查参数网格、重复、冲突与参考覆盖；它仍是相对于发布参考的检查，不是独立人工金标准。

## 数据、资源与可追溯性

原数据含志愿者标识等无关列；Agent 只挂载四列投影。两份参考程序分别完成 847 组搜索、输出逐字节匹配发布参考、原测试各 `8 passed`；详见[试验卡](archive/plans/DBSCAN_AGENT_PILOT_PLAN_20261102.md)。当前 Python 3.12 / scikit-learn 1.9 与上游所列环境不同；数据许可仍待核查，源数据及投影只在 GB10 内部使用。检查初期曾将少量原始样本行读入本会话工具输出；未发送给研究 Agent 或公开，后续只保留必要摘要。

三条 Agent 轨迹共 **33 次 POST**，无拒绝；其 `step_finish` 汇总报告 **484,395 token**，其中输入 `138,815`、缓存读取 `323,119`、输出 `22,461`。这是模型服务报告的 token 口径，包含缓存读取，不是付费账单；源任务的获取成本应在评估可摊销收益时单独纳入。工具运行、适配参考和透明对照均未调用模型；本批训练、judge、付费 API 与生产 Memory 写回均为 0。并未合并或修正历史独立账本。

可复算的[聚合结果](dbscan_pilot_summary_20261102.json)记录每次 raw、receipt、intervention、测试日志和输出 hash；[汇总脚本](summarize_dbscan_pilot_20261102.py)从 GB10 保留的原始收据和输出重建，原始路径为 `/home/testuser/wzh/research_evidence/agent_learning_20261030/dbscan_agent_pilot_20261102/`，透明规则回执位于相邻 `dbscan_metric_control_20261102/`。引用的原始参考、数据和完整轨迹未纳入 Git。

## 科研判断与下一步

这个案例证明现有基础设施能运行真实的“旧任务程序—新合同适配”链条；不能证明经验方法优于直接执行或简单修改。更重要的研究空间是：在**多种变化类型和不同来源**中，什么条件下真实经验能节约总成本或纠正无历史 Agent 的失败，以及何时历史带来负迁移。后续保留无历史、完整原始历史、普通总结、透明规则及已有近邻方法；同时探索可自动形成、检查和修订经验的模型方法，比较实际任务完成、错误行动、来源成本与适用边界。任务选择、数据分离、强基线与阶段安排见[第二阶段研究计划](STAGE2_AGENT_RESEARCH_PLAN_20261102.md)。
