# IJCNN 2027：Agent 经验学习与技能适配研究执行路线

2026-10-30；这是**可调整的执行路线，不是既有创新或录用保证**。[官网](https://ijcnn.org/2027/)当前列出常规论文 2027-01-31 截稿、03-15 通知、06-14 至 18 开会；具体规则临投稿复核。与 Paper E 分开研究和写作，前者以 Agent 的学习/迁移方法与运行结果为中心，后者是有边界的测量审计。

2026-10-31 执行进展：[PDF/Excel 任务](PDF_EXCEL_TRANSFER_RETURN_20261031.md)已取得带经验 Agent 的可执行成功，但无经验输出经不使用参考的无损格式转换后与其相同，事后确定性基线也通过。这个结果缩小了当前任务中的可识别经验空间，不缩小研究方向：后续应寻找既有真实反馈、又有经验适用与不适用场景的独立工作流，并将格式、事实与行动分开评价。

同日的 [SkillLearnBench 反馈合同资格检查](FINANCIAL_FEEDBACK_CONTRACT_FINDING_20261031.md)提供下一候选：公开金融任务的参考实现有类别字符串拼接，两个已暴露问题的发布参考与运行时列表一致，分开字符串的反事实被原断言拒绝。它可支撑受控的“任务规则与反馈冲突”探索，不是自然题唯一真实答案或学习方法；后续必须加入其他来源、无冲突/不可判断控制和强简单规则。

同日 [受控 Agent 对照](FEEDBACK_CONFLICT_AGENT_PILOT_RETURN_20261031.md)显示：无历史、普通历史和两类反馈等五种目标条件均答对，确定性程序也答对。它没有提供方法增益；下一阶段应转向经验确实影响行动、需要从实际反馈形成持久记录的多来源任务，不再重复相同面板的提示。

同日 [企业检索反馈资格检查](ENTERPRISE_FEEDBACK_QUALIFICATION_20261031.md)发现原检查器在六个同族变体上接受漏题、明显无关项和负数 token 的特权构造输出。后续可以把该检查器作为不完整的真实反馈来源，但需要另设独立任务完成与真实成本检查；缺失的 q2 语义参考不能凭空补成 gold。这是开发资产，不是跨族方法结果。

新增 [依赖审计的条件变化候选](DEPENDENCY_SCOPE_SHIFT_QUALIFICATION_20261031.md)：同一依赖文件在高危、全等级和 CVSS > 8 三个自然任务合同下，发布参考交叉套用全部失败；另补出原测试忽略同包同版本多条漏洞的风险。资格阶段尚未进行真实 Agent 学习；其后续结果见下一段。

该候选的[真实 Agent 连续执行与重复](DEPENDENCY_SCOPE_REPEAT_RETURN_20261031.md)和[扩大预算的事后复测](DEPENDENCY_SCOPE_BUDGET_SENSITIVITY_RETURN_20261031.md)现已完成：生成经验组和普通历史组都曾交付目标身份，两者均出现改写工作副本元数据。该单任务现象没有证明生成经验优于普通历史；下一步寻找跨来源、不同工作流及经验可信性机制，保留确定性工具作为基线。

2026-11-01 的[跨项目开发结果](DEPENDENCY_CROSS_PROJECT_RETURN_20261101.md)进一步呈现正确输出与不可信过程同时存在：React 项目普通历史和生成 skill 均覆盖四条目标，但生成 skill 改写时间元数据；Node 的空输出无法揭示它沿用的 HIGH/CRITICAL 过滤风险。该结果来自两个已看过的项目、一个工作流，仍不是独立方法确认。优先探索经验局部验证与修订，同时寻找其他工作流和训练/确认来源隔离。

针对该具体风险，已完成[来源可见验证与人工局部修订](SKILL_VERIFICATION_RETURN_20261101.md)：两个已暴露项目的输出仍与冻结快照一致，未发现留存的时间修改；另一个旧严重程度过滤仍然存在。人工修订不是自学习或通用方法；随后须换不同工作流及来源，并对照近邻和普通历史。

## 核心问题和可检验机制

Agent 完成旧任务后能保留经验，但旧经验可能仅对某种标识格式、工具版本、对象或故障语义有效。探索：**Agent 能否从执行和反馈中学习经验适用条件，在新任务中选择性使用、修订或不使用经验，同时提高最终完成质量并控制成本？**

候选不止一种实现：

- **可解释条件与验证**：从成功和失败轨迹中提取经验正文、预期对象/操作、可观察前提和反例；根据当前证据选择调用或回退，再用可部署验证约束经验更新。先测透明规则，再研究模型能否超越规则。
- **学习型选择器**：只有在可执行任务产生足够且来源隔离的反事实监督后，用相同底座小模型/小规模 LoRA 或轻量神经选择器学习“使用哪条经验、继续取证或不使用”。训练标签来自开发任务上多策略的独立结果差异，不把冻结测试参考或 oracle 信息喂给选择器。普通 SFT、规则、随机/固定策略与原始轨迹检索均为必备竞争对照。
- **实际经验更新**：执行者在固定初始模型和相同预算下，从一组任务的成功及失败、可见反馈生成或修订经验；迁移阶段冻结经验库，在新任务或新版本评估。一次人工整理提示的效果只能是开发诊断，不等于自学习。

这些机制均有紧密近邻，不能以“经验适用条件、噪声反馈或技能迁移”为新颖性本身。Skill-V 已做适用过滤与非回归，SkillShift 已做环境变化下选择，SkillEvolBench 已对比原轨迹和生成技能，RSE-Bench 已扰动学习反馈；见[近邻表](IJCNN_RELATED_WORK_REFRESH_20261030.md)。**可能的差异是假设，而不是已证实空白**：细粒度可执行对象与语义冲突能否帮助形成比整条经验更可迁移、成本更低的选择和更新；需与这些方法的公开实现或明确标注的等价近似比较，并说明不可复现部分。

## 分阶段执行

1. **2026-11-01 至 11-08：来源与执行资格。** 从 [SkillsBench 的现有真实轨迹](CROSS_TASK_TRANSFER_RETURN_20261030.md)及许可明确的其他公开来源建立多个有可执行结果的任务族，核对环境版本、数据许可、训练/验证/确认族与参考可得性；实际检查 [SkillEvolBench 源码资格](SKILLEVOLBENCH_SOURCE_QUALIFICATION_20261030.md)及 SkillShift 的 ARM 限制。优先选择成功例、失败例、可迁移例和不适用例均存在的工作流。对人工语义无法确认的记录保留 `UNRESOLVED`。
2. **11-09 至 11-22：开发验证。** 先选 3–5 个工作流族运行固定模型的无历史、原始历史、原生 skill、固定规则和同预算重试；采集可见环境反馈和实际动作链。然后在相同训练来源上开发条件抽取和候选选择器。此阶段可根据结果自主扩大/缩减模型尝试，不把同一数据的 prompt 调整当独立确认。
3. **11-23 至 12-14：来源隔离确认。** 冻结任务族划分、方法、模型和评价合同，优先跨不同来源或工具版本，评估学习阶段以外的任务；用可执行参考与少量人工抽审核实真实完成、错误行动和不必要拒绝。报告族级配对差及区间，同时记录经验生成、检索、校验和修复的总 token、次数及墙时。首轮目标为足以覆盖不同机制的约 20–30 个未见族；数量是工作目标，不可将拆分同一家族包装为独立样本。
4. **12-15 至 2027-01-10：方法完善。** 若有稳健残差，选择最有前景的推理或学习型机制，补训练预算匹配、不同种子、成功/失败反馈及受干扰记忆消融；若缺乏可执行监督，继续做非训练方式和新来源，而不是编造标签。对负面或混合结果做归因并允许更换候选。
5. **01-11 至 01-24：论文与复核。** 若已有足够证据，形成问题—方法—强基线—多源结果—局限的 IJCNN 独立论文初稿，使用官网要求的模板，核对 6 页及可能的超页规则、参考文献、匿名和 AI 披露。方法未达可辩护标准时，继续研究并选择后续窗口，而不是凭既有开发数据硬投。

## 必须能回答的问题

- 经验是否由实际前序运行和可见反馈产生？有无无经验、原始轨迹、普通总结、任务专属 skill 和等信息透明规则？
- 能否复现学习/选择带来的行为变化，同时排除任务说明泄漏、隐藏参考进入提示、身份/分段错配和不可比预算？
- 在新来源或新任务族中，最终正确完成率、风险、拒绝、迁移收益与总成本如何？是否保留旧任务能力？统计单位是来源/工作流族，而不是相似行数。
- 若简单方案追平，能否解释哪些经验适用、哪些反馈误导、为何，而不是强行声称神经方法有效？反之，若出现稳健增益，应进一步增加公开基准、重复和负向控制。

保留所有请求、重试、无输出和上限拒绝；模型调用与训练只在隔离研究环境执行，预算按新阶段记账并根据测得资源动态调整。结果和代码存于项目可追踪路径，大型第三方数据/模型与原始轨迹按许可证和 hash 单独保存。
