# 第二篇：反馈、记忆和技能进化的近邻核查

2026-10-30，基于公开摘要和页面元数据的针对性检索，**不是系统综述或论文全文复现**。目标是给下一步方法实验设置强参照，而不是根据标题宣称研究空白。

| 近邻 | 已覆盖的机制和证据（依作者摘要） | 对我们的约束与可借鉴实验 |
|---|---|---|
| [Skill-V](https://arxiv.org/abs/2610.11781)，2026-10 预印本 | 已把 skill 视为可证伪、可版本化合同；使用环境结果更新边界、历史回放检查非回归、过滤不适用技能，在 ALFWorld/WebShop 测试。 | **不能声称首创**技能适用条件、合同修订或历史非回归。比较其具体可用观察、回放成本、模型和规则过滤。 |
| [SkillShift-Bench](https://aclanthology.org/2026.emnlp-main.1952/)，EMNLP 2026 | 三个自托管 Web 系统、情境/感知/执行变化，并提供可执行性与测试时适配方法，报告成功率和交互成本。 | 不能把“环境变化下技能失效和适配”作为新问题；进一步核查源码和模型调用后，选择可比较的自然变化或反馈信任维度。 |
| [CFOE: Self-Evolving Agents Can Repair Failures but Struggle to Generalize](https://arxiv.org/abs/2610.22984)，2026-10 预印本 | 已研究只从失败学习，指出已见任务修复与未见任务迁移的差距，并分析误解失败及外部 verifier。 | 我们的单任务修复结果不构成新理论；须以真正未见任务/来源评估已有经验是否可迁移，包含成功轨迹、失败轨迹及无反馈对照。 |
| [Self-Authored Verification Is Unreliable](https://arxiv.org/abs/2607.24300)，2026-07 预印本 | 研究自写测试与部署表现的偏差；其 SEAL 用 Agent 不可见的固定审计和历史回滚减少退化。 | 不能只提出“用隐藏测试和回滚”；对照可见测试、外部审计、成本、不可见标签可得性以及不同参考缺陷。 |
| [EvoClawBench](https://arxiv.org/abs/2607.09711)，2026-06 预印本 | 比较无技能、任务前生成技能与任务后从轨迹总结技能，并计入创建成本；跨 coding、data、office 等任务。 | 不能只比较有没有生成 skill；可借其可执行工作流和 authoring 成本口径，核查环境和训练来源再决定能否复现。 |
| [ContinualSkillBench](https://arxiv.org/abs/2608.03874)，v3 2026-10 | 比较顺序上下文和技能维护，发现部分设置中保留历史/反馈与显式 skill 平均效果接近。 | 必须包含普通历史、普通反馈、直接重试等同预算控制，不能只与无历史比较。金融流与已有项目来源重合，不作未见确认。 |
| [CoEvoSkills](https://arxiv.org/abs/2604.01687)，COLM 接收预印本 | 已在 SkillsBench 上联合迭代 skill 生成器与不读取 gold 的代理 verifier。 | 同一 SkillsBench 上“无 gold、反馈驱动 skill”已有先例；若使用该数据须考虑复现近邻与其他来源数据。 |
| [SkillEvo](https://arxiv.org/abs/2608.13120)，2026-08 预印本 | 多轮用户模拟生成反馈并维护技能，利用治理处理退化和膨胀。 | 不能仅以“反馈可信/多轮/修订回归”作为创新；需识别更具体可观测条件和不同信息、预算比较。 |

## 可执行候选：反馈与经验的适用性，而非又一个技能库

探索问题：在真实工具任务**有限反馈、反馈可能不完整或有错、经验可迁移范围变化**时，能否依据运行中可见证据选择“直接执行、重试、验证、复用旧经验或暂缓更新”，减少后续回合的错误而不丢失已具备能力？目前只是研究假设；Skill-V、SEAL、SkillEvo 与 SkillShift 可能已覆盖关键机制，必须全文比对其做法后才能判断独立性。

建议的可证伪实验采用连续任务序列，先分来源/版本，保留失败与成功实例。每轮同时记录任务成功与任务级回归、安全拒绝、经验是否被使用、反馈标签与工具轨迹、上下文及实验总成本。需同时比较：无历史、完整历史、固定窗口/检索、原任务 skill、普通 retry、SEAL 式固定外部验证/回滚、Skill-V 式适用过滤与历史回放，额外给同等可见信息的透明规则；我们的候选必须在独立序列或未见版本上，超越相应最强质量—成本基线或解释可复现的机制差异。不可把校准样本的模型自评当人工 gold；隐藏 reference 仅用于事后独立测量，非所有基线都默认可用。

**本项目已有可信起点**：[dialogue 研究](DIALOGUE_PILOT_RETURN_20261030.md)暴露 verifier 假阳性/误拒及同起点修复；[prefix 研究](PREFIX_FEEDBACK_RETURN_20261030.md)显示公开完整 skill 是强基线；[invoice 研究](INVOICE_AGENT_RETURN_20261030.md)中具体诊断有效，但一个给定相同诊断的确定性规则同样完全通过。它们支撑设计问题，不单独证明任何方法的普遍优势。下一步应优先从真实连续或环境变化基准中建立 2–3 个来源隔离的可运行序列，并根据实测调整训练或推理预算。相关论文所述结果是其作者报告，非本项目复现。
