# 地震与板块任务：真实 Agent 经验迁移开发记录

2026-11-03。目标是观察 Agent 能否把一次真实地理计算的经验用于板块变化后的任务，并核查结果与评测合同。这里得到一个有价值的候选机制和一组实际运行轨迹；尚未建立方法收益或跨来源结论。

## 任务与对照

在 SkillLearnBench 固定提交 `726e1f79b96b0cb3d729d0e55a1c847e0b5353ae` 的 `earthquake-plate-calculation` 工作流中，源任务 T1 寻找太平洋板块内距离板块边界最远的地震，目标 T3 改为非洲板块。两题共用同一批地震与板块数据，属于**同源开发**；另一道 T2 的题面和输出字段不一致，未纳入。研究者此前已读过目标题与参考，目标测试和答案始终未提供给运行中的 Agent，结束后才在独立容器加载检查。

GB10 使用 OpenCode、本地 Qwen3.6-35B-A3B-Q4_K_M 和隔离容器，依赖、镜像、数据与目标合同在各目标臂一致；各臂历史内容和提示有所不同。先完成源任务，再由真实源轨迹及仅含测试名称和状态的反馈生成一次 skill；该输入没有包含源运行的上下文溢出错误，不能称为完整反馈。目标初次比较无历史、可选源历史和可选 skill。可选源历史没有被读取，观察后追加要求读取历史或 skill 的诊断臂；这两臂是事后开发，并非预先冻结的确认实验。

## 结果

上游原测试共 8 个字段。下列 `距离` 是目标事件的输出值；上游距离预期与独立地理计算使用不同合同，不能把原测试通过率直接等同于物理正确率。

| 实际运行 | 原测试 | Agent 退出码 | 目标距离 km | 历史读取 | 模型 POST |
| --- | ---: | ---: | ---: | --- | ---: |
| 源 T1：无历史 | 5/8 | 1 | 3551.98 | 不适用 | 20 |
| 目标 T3：无历史 | 7/8 | 1 | 1828.00 | 无 | 14 |
| 目标 T3：可选源历史 | 7/8 | 0 | 1828.00 | 没有读取文件 | 11 |
| 目标 T3：可选生成 skill | 7/8 | 0 | **1826.09** | 读取一次 | 15 |
| 目标 T3：要求读源历史 | 7/8 | 0 | 1828.00 | 读取一次 | 10 |
| 目标 T3：要求读生成 skill | 6/8 | 1 | 60.00 | 读取三次 | 15 |

五次目标运行均选中了与上游参考相同的事件及坐标；这只说明选择与上游一致，并未独立证明全体地震上的最远事件。读取情况由实际完成的 `read` 工具事件核对，不能将“文件可见”当作“已读取”。源臂、目标无历史及要求读 skill 的臂有 `ContextOverflowError`；它们仍留下了可解析输出，但退出异常必须与测试字段分开报告。

源 skill 建议用 WGS84 测地距离和边界线采样。可选 skill 的目标运行实际读取了该文件，并使用 `pyproj.Geod` 和非洲板块条件。为检查同一目标事件的距离，事后把 AF 边界相邻顶点按 WGS84 最短测地线连接，在每段上以不超过 10 米间距取样。利用三角不等式界定并留出 10 微米数值余量，计算得到该事件到所选边界的最小距离约位于 **[1826.08893959, 1826.09393962] km**；该区间保留两位小数均为 **1826.09 km**。数值余量不是对 `pyproj` 的形式化误差认证。这是明确边界解释下对**已选事件**的距离校验，不是对全球最远事件、其他几何解释或上游官方答案的独立认证。

这是一条值得继续研究的正向轨迹：读取源 skill 的一次运行给出了与测地距离校验一致的值；无历史和两条历史运行给出 1828.00 km。然而每臂只有一次，信息和交互不同，不能断言是 skill 导致改进。要求读取同一 skill 的另一次运行给出 60.00 km、发生上下文溢出，提醒我们还需要解决稳定性与执行反馈问题。skill 中还出现错误的 `Point.contains(polygon)` 方向建议；一次独立 Shapely 反例证实这一点，但成功轨迹实际使用的是正确的 `polygon.contains(point)`，不能归因该建议导致了错误。

## 评测合同发现

T1 与 T3 的发布参考程序逐字节相同，均针对太平洋：参考程序 T1 `8/8`，用于 T3 时 `1/8`；仅透明替换板块名称与边界代码后 T3 `8/8`。这是参考程序迁移问题，不是 Agent 自主发现。目标任务未明确固定距离投影：同一透明适配分别使用 EPSG:4087、6933、8857 时，选中相同事件，距离分别为 1894.53、1751.08、1746.65 km；仅 EPSG:4087 匹配原测试。原测试因此适合判断是否复现其具体参考值，不能单独证明其他结果的地理含义错误。
