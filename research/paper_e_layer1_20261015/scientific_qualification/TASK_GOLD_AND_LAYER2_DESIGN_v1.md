## 0. 先裁决测量对象

| 范围 | 参考真值 | 被测对象 | 能回答的问题 | 不能回答的问题 |
|---|---|---|---|---|
| a) 列绑定恢复 | 来源列 `col/original` | 冻结绑定规则 | 规则是否仍把注入表头绑回目标列 | 真实任务答案是否改变 |
| b) 真实任务正确性 | 固定任务 + 参考答案 + 证据单元 + 容许变化 + 错误判定 | 被测检查系统 | 扰动是否改变具体任务结果或引用关系 | 不能由绑定规则自洽推出 |

**裁决：推荐 b。**  
只有在 b 的 reference gold 可操作、可人工核验、可报告分歧时，Layer-2 才有意义。  
若现有材料无法支持 b，必须输出 `TASK_GOLD_NOT_VALIDATED` 并列出缺口；**不得把 a 改名为 b**，也不得用 v4 的 E/H/U 直接充当 b。

## 1. reference gold 从哪里来

硬性禁止：

- 不能由 v4 的 norm + Levenshtein 最近邻规则生成。
- 不能直接采用 Layer-2 第三臂核验器的输出作为 gold。
- 不能把同一模型/同一归一化路径的多次运行当独立 gold。

允许来源：

- 独立原始证据：来源表、注入表、原始任务问题与官方答案、可核验的 derivation / 单元格证据。
- 人工裁决：两名独立标注者，先看任务与原始证据，再给 E/H/U；不一致时第三人仲裁或保留 U。
- 程序只负责：格式检查、来源可追溯性、算术复算、行/列定位。程序不能靠自洽证明语义正确。

必须记录：

- 裁决依据（引用到具体问题、单元格、单位、时期）。
- 分歧处理流程与仲裁记录。
- 人工投入（人数、小时、每 case 时间）。
- gold 的 U 与系统主动弃权必须分开计数。

## 2. 小规模诊断标注方案（先做资格核验，不做确认实验）

诊断类别（待选择、待实例化；不得虚构已有案例或结果）：

1. 候选仅一列：词法上唯一绑定，但仍需确认任务答案是否改变。
2. 词法接近但含义可能改变：例如同义但单位、时期或指代不同的列名。
3. 词法差异大但含义可能保持：例如缩写、别名、语言混合、OCR-like 拼写。
4. 周期 / 单位 / 目标列歧义：同一列名在不同期间或不同单位下语义不同，或多列共同构成答案。

标注规则：

- 隐藏 checker 结果与 v4 标签；标注者只看任务、原始证据、注入后表。
- 两名独立标注者；不一致保留 U 或第三人仲裁。
- 公开的 59 个 held-out case 只能作为开发 / 诊断材料，不能重新称为未见确认集。
- 诊断样本建议先取 12-24 个 case，覆盖上述四类；样本量作为设计选择，不写死为 59。

## 3. Layer-2 三臂设计（仅在 task gold 合格后）

三臂：

- A：当前检查方式。
- B：增加同源检查（共享归一化 / 表示 / judge 来源）。
- C：增加独立路径的任务核验（不共享原判断路径）。

共同评价 gold：三臂必须使用同一套独立 task-level reference gold。

输入权限：

- A/B/C 各自只能使用其运行所需输入。
- 禁止把仅用于评分的参考答案、注入来源信息或 gold 标签泄漏给 C。
- C 的输入若与 A/B 共享了归一化、证据或表示，必须显式记录“共享路径”证据。

每臂必须定义决策函数：

- 报警：什么信号触发 alarm。
- 接受：什么条件判定 legal / correct。
- 弃权：什么条件 abstain。
- 无显式决策定义时，不能把 `visible_frozen` 之类的内部状态当作报警。

预算：

- 三臂使用相同核验预算；
- 同时报告实际总成本；
- gold 建立的人工成本单独报告，不混入任一臂优势。

## 4. 指标与分母

| 指标 | 公式 | 分母说明 |
|---|---|---|
| 有害错误漏检率 | n(gold=H 且 system=accept/no-alarm) / n(gold=H) | 只在 gold 判定的 H 上算 |
| 合法变化误报率 | n(gold=E 且 system=alarm) / n(gold=E) | 只在 gold 判定的 E 上算 |
| gold 无法判定比例 | n(gold=U) / N | 度量测量设计本身的不确定性 |
| 系统弃权比例 | n(system=abstain) / N | 与 gold U 分开 |
| 核验成本 | 每 case 成本、总成本、人工分钟数 | 三臂相同预算，报告实际消耗 |

聚类与确认集：

- 聚类单位：table / source document。
- 未来确认集必须按 table 或 source document 隔离。
- 不把已公开条目重新称为未见测试。
- 样本量依据拟检验差异、基线错误率与聚类结构规划，不直接沿用 59。

## 5. 哪些结果支持或否定论文贡献

支持：

- task gold 合格，且 C 相对 A/B 降低有害漏检或合法误报；
- 增益在相同预算内，且成本可报告；
- 共享路径证据能解释差异，并排除竞争解释。

合法否定：

- C 无优势；
- C 有优势但不抵成本；
- task gold 无法成立；
- 差异来自任务定义或聚类，而非共享路径。

机制归因：

- 想归因于“共享路径”，必须提供路径共享证据（共享归一化、共享表示、共享证据来源）和竞争解释排除；
- 三臂性能不同本身不能自动证明机制。
