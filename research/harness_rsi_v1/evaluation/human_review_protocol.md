# 人类评审与独立盲评协议

状态：DRAFT；评审者、锚点和冻结规则待 T10。

1. 引用、数字、泄漏、停止状态先过事实硬门，文风不能补偿。
2. T10 建立独立人类锚点，模型与人类的通过/不通过一致率建议 >=80%；该值待裁决，不是已达成结果。
3. 封存资料只由评测身份访问，提案器只见开发轨迹。已在本对话解读的事故不能充当未见题。
4. 旧版/候选使用相同资料、模型、长度和预算；隐藏版本、随机顺序；评审原始产物。
5. 按 rubric 每维 0–3 给出片段、证据和理由。没有依据的数字评分无效。
6. 两次重复不是两个独立问题；重复偏好冲突建议记 tie/review，在看结果前冻结聚合规则。
7. 强模型独立评审；用户/导师保留研究价值、创新、识别假设、投稿和学位裁决。评审 skill 与模型配置冻结，候选不可改。
8. 最终 review 绑定被审产物与资料包哈希；未有人类裁决 => PENDING_HUMAN_REVIEW。

首层预留约 1–2 小时校准/评审，实际另记。分歧不强行凑多数；同一模型换顺序复评不称两个独立专家。有限盲评只支持限定工作流表现，不保证论文录用、不构成大论文新实验。不修改现役论文和冻结结果。
