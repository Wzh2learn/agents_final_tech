# Pilot Preparation Goal

Complete model-free pilot prerequisites without changing the frozen collection bundle.

## Done when

1. All 16 future tasks are audited for chronological period order and unit consistency.
2. Unambiguous inversions are corrected in a new manifest version with visible task, operand order, and reference updated consistently.
3. Ambiguous or incompatible tasks remain unresolved and block pilot; reserve tasks are not substituted.
4. R/C content and the 160-slot five-arm order are frozen in a draft pilot protocol without using future answers.
5. Experience qualification and U/E context generation interfaces are prepared but do not fabricate entries before collection.

## Never touch

- The collection bundle, its manifest, prompts, model/runtime, raw runs, frozen source split, or prior reports.
- No model requests, pilot execution, training, memory write-back, source switch, or reserve substitution.

## Stop if

- Any future task cannot be uniquely interpreted after the full 16-task audit.
- Correcting a task would require changing scientific semantics beyond chronological late/early alignment.
