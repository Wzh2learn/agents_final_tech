## INFERENCE：纠正负责人自己的过强门

上一版要求残差在always-expand之后仍然存在，混合了“相同候选集合的证据覆盖”和“固定答案质量下的总成本”。若全部候选本来包含标注gold，任何子集的纯覆盖都不能超过全量。这一门可用于否定“还有检索召回上限”，不能独自否定选择性取证的成本必要性。

正确问题是：在相同完整答案质量/错误交付风险容差下，能否减少端到端成本，或在匹配成本下改善答案。字符数不能直接作在线token/延迟；非劣也不能用“不显著”证明。若全量上下文本来便宜且有效、简单规则已在共同前沿，则继续no-go。

“需要新来源”在本轮是未满足条件的提案，不是已有证据证明唯一解。先利用当前ordinary自然错误作信息损失定位；需要泛化确认或自然场景规模时再引入未曝光来源。四个旧构造role题不能替代当前模型自然失效全景。
