要求：

1. 支持 OpenAI-compatible API；

## 3. RAG 任务

### Task R1：文档上传

要求：

1. 支持 docx/pdf/txt/md/xlsx；
2. 保存文件元信息；
3. 返回 document_id；
4. 记录上传日志。

### Task R2：文档解析与切分

要求：

1. 可编辑文本直接抽取；
2. PDF 先文本抽取；
3. Excel 保留 sheet 和行列信息；
4. chunk 带 metadata；
5. 支持 chunk_id、document_id、section_title、page_no。

### Task R3：向量入库与检索

要求：

1. 支持 embedding；
2. 支持向量检索；
3. 返回来源 chunk；
4. 预留 BM25、Hybrid、Rerank。

### Task R4：M2 规则问答

要求：

1. 输入用户问题；
2. 输入角色；
3. 检索相关规则片段；
4. 组装 Prompt；
5. 返回答案；
6. 返回来源；
7. 记录日志；
8. 生成评估结果。

## 4. M1 规则抽取任务

### Task M1-1：规则抽取 Prompt

要求：

1. 从文档 chunk 中抽取规则；
2. 输出 JSON；
3. 包含规则名称、条件、动作、来源；
4. 不确定时标记 need_human_review。

### Task M1-2：Pydantic 校验

要求：

1. LLM 输出必须经过 Pydantic 校验；
2. 校验失败需要保存错误；
3. 支持人工审核修正。

### Task M1-3：规则审核接口

接口：

- `POST /api/rules/review`
- `GET /api/rules/{rule_id}`
- `GET /api/documents/{document_id}/rules`
