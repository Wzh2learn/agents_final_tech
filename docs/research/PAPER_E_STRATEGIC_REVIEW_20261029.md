## 2026-10-29 质量判断：研究价值与投稿层级

CCF A/B/C 是会议或期刊目录分类，不是给单篇手稿打分的客观标尺。以下是科研负责人基于当前证据及近邻摘要/部分原文的**主观预审**，不是 CCF 官方评价、录用概率或完整同行审稿。当前 v6 仍为内部稿，具体会议短稿尚未完成。

现有材料有一条真实而有用的经验主线：在固定评测合同与观察范围内，分数变化不必导致比较结论变化，点估计排序也不自动提供统计支持。单叶正比例关系、FinRank 分数/结论分离、BEIR 查询层/总体层差异是可复算的正向观察，而不是全部负结果。但许多通用 validity 主张已有工作；自建与事后分析、缺少独立人工标注及真实读者决策，限制了其作为通用审计方法的主张。更强近邻如 [AgentSuite/COBA](https://proceedings.mlr.press/v306/suh26a.html) 的作者报告 6 个 agent benchmark 与专家判断对照及未见基准适配，本稿当前不能按其证据规模与泛化主张相提并论；两者对象亦不同，不能把规模差等同质量分数。

实际投稿定位：**聚焦领域的实证短文、workshop 或一般正规会议/期刊值得尝试；主题契合的 CCF C 类会议可作为探索性挑战，但不能保证其达到或必然达不到某一会议门槛**。与典型高竞争综合性 A/B 主会相比，当前稿件在问题独立性、外部验证和对决策的直接证据方面有明显差距；即便增加模型也不能自动补齐。若要尝试更高竞争轨道，先做独立真实任务、明确事前方案、强基线、跨源验证及独立统计/人工评审，并用目标 venue 的近年论文判断。近期目标是明确定位并实际投稿，不应把追求 A/B 或新的普适理论设为毕业前提。

## 2. 一句话主张与证据

**可审阅的论文主张：评测数字只有和观测对象、判定规则、参考答案及比较问题一起解释，才能判断分数变化是否意味着结论变化；本文在三个受限评测对象中给出可重现的具体例子。** 这是经验性的评测审计，不宣称已发明通用审计理论、改善真实用户决策，或证明 Agent 具有某种普遍能力。

| 想回答的问题 | 最有价值的现有结果 | 能用它说什么 |
|---|---|---|
| 数字不同一定代表评测能力不同吗？ | 第一案例仅一个叶节点响应时，两种聚合是约 0.375 的正比例缩放；未匹配操作点的表级检出为 75/95 与 20/95。 | 排序保持一致而阈值下检出不同；这是可解释的正向发现，范围限于该构造。 |
| 规则改变了分数，比较结论一定改变吗？ | FinRank 两种平局合同使部分绝对分数变化超过 1 个百分点，hard/random 差距方向保持。 | 区分分数敏感性与决策稳定性；不声称实际用户因此改变决策。 |
| 有名次就足以声称系统有严格优劣吗？ | 自建五个词法运行的每数据集 10 对比较，经指定的符号翻转检验和 Holm 校正，SciFact 为 2 对、NFCorpus 为 1 对得到支持。 | 对具体比较给出统计支持而不是把点估计排序当确定事实；未显著不表示相等，且检验依赖假设。 |
| 审计能提供什么实际提醒？ | NFCorpus 一种平局处理使 25.7% 查询的 top-10 成员集合变化，但均值 nDCG 仅变化约 0.00005；作者早期实现的分级相关性和 MAP 分母错误经官方 trec_eval 对照修正。 | 同时检查查询层与汇总层，复核指标合同；早期错误是本项目自身实现错误，不能写成社区普遍错误。 |
| 有多可靠？ | 简单的尊重精确平局基线也通过重复与退化控制；FinRank 的部分检查 source-informed、事后进行；BGE 和 Agent 小样本为事后探索。 | 明确收益是限定条件下的解释与证据支持度，不宣称审计全面胜过简单方法。 |

第一案例的 13 个 OCR-like 注入未被观察到，不构成有害漏检或确定无害的证明；单一模型语义判断不是人工金标准。FinQA 89 行探针未重算下游字段，其零检出不是一般失败率。阶段定位结果来自显式插桩，不可写成自然 Agent 的因果归因能力。

## 3. 对标文献：质量、差异和可借鉴的写法

这是一组针对原文和重点章节的对标，不是穷尽式系统综述；不同论文任务和样本不能直接比较分数，也不能据此预测录用率。

| 参考工作 | 实际研究与质量参照 | Paper E 的差异和差距 | 应借鉴的叙事 |
|---|---|---|---|
| [Ross et al., What makes a good metric?](https://arxiv.org/html/2412.13989) | 用多项指标、灵敏度分析与输入消融检查图文一致性度量。 | 我们有一叶响应的精确代数条件和可复核的规则变化；覆盖的模型和独立任务更有限。 | 先说明指标应该满足什么，再用针对性的反例、对照和消融回答，不按实验发生顺序堆结果。 |
| [Bean et al., Measuring what Matters](https://arxiv.org/html/2511.04703) | 对大量 LLM 基准做构念效度与专家编码审查，提出检查建议。 | 通用的测量效度与清单思路已有先例；我们的可发表增量应是具体合同如何改变或保留可支持解释，而不是“首次提出清单”。 | 用“现象—任务—指标—主张”串起每个案例，让读者看到审计前后解释。 |
| [AgentSuite / COBA, ICML 2026](https://proceedings.mlr.press/v306/suh26a.html) | 分解 Agent 基准组件，在六个基准上与专家判断比较并测试未见基准。 | 与我们非常接近，其基准数量、独立参考和泛化验证明显更强；现有四次 Agent 调用不足以对标其系统规模。 | 明确被审计对象、问题类别、参考来源及适用范围；不要声称我们的四次运行证明新的通用 Agent 审计法。 |
| [Chen, oracle-integrity preprint](https://arxiv.org/html/2610.16067v2) | 检查评测 oracle 故障与配置依赖，并展示特定基准中修正前后的结果变化。 | 其直接实用的前后结果比我们当前“解释应如何变化”更强；我们的不同点是同时展示契约变化下结论稳定和观测不足。 | 让每张结果表回答明确问题，清晰展示原判断、证据、修订判断与局限。 |
| [Trial by Trace, preprint](https://arxiv.org/html/2610.32285) | 分析多任务、多模型和 harness 场景中执行轨迹与测量可靠性。 | 已有 trace/harness 近邻；我们的 trace 样本极小，不能以“使用真实 Agent”单独宣称新颖。 | 定义观测边界和轨迹能证明什么，同时列出轨迹未能证明的行为。 |

**当前质量判断**：论文有可复核的实证材料和清楚的问题，适合打磨成范围明确的评测/复现论文；但还不是与上述大规模强基准论文相同证据等级，也不是已验证的普适新方法。近期重点是减少正文割裂、补齐最相关文献比较、选对审稿范围、完成一个真正自洽的目标模板，而不是重复增加同质模型调用。对较宽泛的 AI/神经网络会议，相关性和真实 Agent 覆盖仍是风险，是否合适需以当届官方征稿为准。
