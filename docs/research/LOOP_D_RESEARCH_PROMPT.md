## 4. 第一动作：一次性修正实验前提，不再修补旧候选

D先在现役STATE/THREADS、学位现役正文及一份附注中接纳或以直接证据反驳以下问题，不改历史raw/报告/分数：

1. **有效父模型**：给出active adapter、实际前向路径与零更新函数等价证据。父权重保留/冻结/hash一致不是ordinary续训证明。可以复用CPU反例定位语义，不以玩具测试认证实际Qwen已修复。此纠偏步骤不加载真实Qwen补跑、不重训旧R/E；§6资格通过后可加载既有获准研究模型执行唯一小探针。
2. **模型/工具责任**：模型预测有语义的有限选择或动作，canonicalization、SHA-256、版本与完整性验证由工具计算。不得让新任务要求学生凭空生成目标hash；输入中没有提供的schema常量也不能只靠测试函数已实现来认证模型合同。旧applier保持冻结历史。
3. **监督语义**：只有5条/3-family合格集合纠正，不是256个独立训练样本。39/256纠正呈现、217/256 no-op/未决及全prompt+target loss均须披露；这些可能解释训练失败，但不能未经消融宣称已识别原因。
4. **完整目标**：训练参考可以合法提供正确的程序、方向或单位标签；“部署不能看gold”不等于“训练不能用标签”。若部署可见信息足够，不能为了禁用训练gold而固定已知错误操作数顺序，再把反号目标叫正确修复；若可见信息确实不足则UNRESOLVED。集合代理任务可以研究，但须以其本名和分母报告。
5. **停止的含义**：当前实现失败/无增量，不是反馈学习或局部编辑原理被证伪。C的数值复算正确，但其父模型前提和R方法级负结果叙事需要补充审查。

## 5. 第二动作：只找一个可检验的决策残差

D从既有自然失败、冻结输出、公共来源快照及复用地图出发，最多筛两个候选，再只推进一个。保持总问题和金融验证资产，不要求继续R/E、Memory、planner或SFT名称。优先级是能用现有完整语义参考回答、强简单基线有盲点且能得到可执行反馈的问题。

可优先查两类，亦允许有证据的更好替代：

- **条件化证据适用性**：期间、主体、口径或单位改变时，哪些证据仍可用于当前答案？必须有自然变化和可核实参考，比较精确缓存/metadata规则/普通检索。若已被简单规则解释，与旧scope面板一起收口，不给旧结果换名。
- **可核验的证据获取**：当前可见表不足以完成答案时，能否通过合法、有限的报告段落/表头/来源查找恢复必要信息？同报回答与行动效用、正确覆盖、错误风险和实测成本。自然缺信息和人工遮挡分开；更大top-k或固定查找已足够就停止新策略。

每个候选用少量真实样例说明：具体失败输入→可见信号→合法动作→新证据→完整答案参考，标出什么实验会推翻必要性。缺gold/不可观察/动作无效的样例不能靠oracle或合成标签凑数。Oracle只估上界，并不构成可部署候选。

A交任务资格、强简单对照、来源曝光身份和3—5个机制近邻差异；不泛读热点。开发样例一旦用于选题也进入曝光并集，不再称未来确认集。同数据集新表不冒称跨源泛化。

优先复用普通SFT、计算器、当前检索与语义工具，把既有训练失败转成约束。不先设计复杂算法，再找只能让它成功的题。若两个候选都没有独立残差，给出有证据的NO_GO与一个缺失条件，继续Paper E和中文正文；不要循环追加新菜单。

## 6. 第三动作：资格通过才做一个小探针

2. D独立核对可观测性、参考、强基线和余量后，选择唯一候选；不合格则不释放模型预算。
3. A执行：最多48个物理generation attempts、240,000 generation tokens，包含采错、对照、失败和重试；本轮训练0次。优先用2—4个必要臂做配对开发比较，不强凑样本量。
4. C在冻结准备件和探针raw均存在后，一次独立审计实验前提、标签、评分、成本与结论；D复算后裁决。
