## 2. 历史近邻风险与创新边界

以下为本轮压力测试已核对的一手研究；包括预印本。它们支持主题/通用机制已有覆盖，不证明所有结论普遍成立，也不证明尚未定义的具体方法已被完全覆盖。后续只按候选机制精读，不追加泛热点路线。

| 已有研究 | 已覆盖内容 | 本项目不能直接认领的创新 |
|---|---|---|
| [ACE](https://arxiv.org/abs/2510.04618)、[MemRL](https://arxiv.org/abs/2601.03192) | 执行反馈驱动经验整理、上下文更新或记忆效用学习 | 经验→反馈→Memory→未来收益这个通用闭环 |
| [TRUSTMEM](https://arxiv.org/abs/2606.25161)、[Memory Reward Inflation](https://arxiv.org/abs/2608.00017) | 可信记忆转换、错误评分与相关评判误差 | 终点分数不够、加入 verifier、可靠反馈再学习这些原则本身 |
| [Procedural Memory Distillation](https://arxiv.org/abs/2607.01480) | 跨任务程序经验形成记忆并进入策略参数 | Memory→参数或两者共同更新这个方向本身 |
| [Useful Memories Become Faulty](https://arxiv.org/abs/2605.12978) | 在受控任务流中比较持续归纳、原始经验保留及退化 | 首次发现更新可能失败、遗忘或保留原始轨迹有用 |

更换数值问答场景、增加 SFT 对照、观察到回归、拥有可复算 harness，都不自动构成新颖性。方法候选必须说明相对最近邻改变了哪个具体决策、要解释哪个尚未解释的残差，以及什么结果会否定其必要性。发现残差只说明有待解释；不等于已经识别创新或证明方法优越。

## 3. 历史推进门：先裁决必要性，再申请执行

两门是 2026-10-12 历史任务卡中的科学裁决，不另建 registry、自动审批器或治理平台。执行 Agent 可整理证据和提出判定；导师/owner 决定正式 claim。**旧门仅作科学裁决参考；本轮执行以唯一现役指令的当前阶段为准。**

### G-RQ：研究问题成立门

在 WP-0 中明确并接受：

- 一个受限、可证伪的问题；区分反馈资格与未来效用，明确独立目标、相关行为、结果与失败解释。
- 精确任务/来源及经验复用的合理依据；真实工具执行会影响被消费的结果，来源独立性与许可可核验。
- 静态规则、朴素经验、更多上下文、更多计算及答案泄漏等主要替代解释；缺来源或精度不足不能被写成学习无效。

只有问题值得检验且所需任务资格成立，才可记 `G-RQ=PASS`，并注明适用任务。抽象问题合理不等于具体任务已过门；`TASK_QUALIFIED` 不等于实验获准。

### G-M：研究与方法必要性、创新识别门

同一个门必须注明获准研究的范围，不能用一次通过授权后面全部工作：

| 裁决范围 | 开始该范围前必须已有的判断 | 不能推出什么 |
|---|---|---|
| **最小验证/既有基线比较** | 近邻覆盖已核对；明确本任务仍未知的具体问题、为何必须做最小验证、比较与退出条件。WP-1/2，以及 WP-3 中必要的既有基线比较，均须逐项绑定允许范围。 | 不认证新算法必要性；`METHOD_NOVELTY` 仍可为 `NOT_IDENTIFIED`。 |
| **候选方法研究** | 有效经验复用机会与强简单/合适已有方法仍未解释的残差；具体机制差异、最近邻比较、可证伪假设与预算替代解释清楚。 | 只允许检验该候选机制，不认证其优越性、新颖性成立或顶会贡献。 |

G-M 的结果写为“允许哪个范围 / 未定 / 停止”，附证据位置。两门须在相应执行前完成；首个 pilot 也不能豁免。**不能要求先做未获准实验才能取得最小验证资格，也不能把最小验证资格偷换成方法研究资格。**

pilot 的 `CONTINUE_EXPLORATORY` 只支持申请必要性审查。若还缺合适已有方法比较，只可先在既定工作包范围内申请基线诊断，不能直接实施候选新算法。若已有方法足够，停止新算法；精度不足则保留未定。最终方法贡献仍须由独立行为与结果、强基线比较、机制必要性及 claim 范围共同支持。
