## 1. 决策、理由与当前事实

**决定：有条件采用三个 TH3-RQ 和 Evaluation → Evidence → Learning → Adaptation；不认证当前已有新方法。**

选择这条受限研究路线，放弃两种默认：不恢复强制 EDR，不把已有环节的组合认作创新。核心科学问题仍是：对过去执行有事实支持的信息，何种条件下能产生对未来任务有净收益的行为更新？反馈真实与反馈有用不是同一结论。

| 项目 | 当前可签署的状态 |
|---|---|
| Paper E | 已有受限测量审计证据；作者级科学纠偏未执行。只提供反例与测量约束，不认证新任务反馈资格或学习效用。 |
| TH3-RQ1 | 检验候选反馈的事实支持、测量对象与使用条件；资格成立不推出未来学习有效。 |
| TH3-RQ2 | **待验证科学假设；具体方法差异与 exact novelty 尚待识别。** 新任务 `QUALIFICATION_PENDING / NOT_RUN`。 |
| TH3-RQ3 | 对存活学习机制的有限适应边界检验；不是预设独立创新或持续改进贡献。 |
| Memory / SFT / Adaptation | 分别是候选主要载体、有界参数对照与边界研究对象；实现它们不等于形成贡献。 |
| 推进门 | `G-RQ=PENDING`；`G-M=PENDING`；`METHOD_NOVELTY=NOT_IDENTIFIED`。本轮未签发任何运行许可。 |

硕士目标仍是纠偏后的 Paper E、一项完整经验学习研究及有条件的有限适应检验。核心方法论文是争取的出口，不是已确定成果；第二篇扩展不是毕业前置。若新方法无必要，是否完成有解释力的经验比较及是否满足学位要求，由导师决定，不能由执行 Agent 自动降级认证。

## 2. 已有工作风险与创新边界

以下为本轮压力测试已核对的一手研究；包括预印本。它们支持主题/通用机制已有覆盖，不证明所有结论普遍成立，也不证明尚未定义的具体方法已被完全覆盖。后续只按候选机制精读，不追加泛热点路线。

| 已有研究 | 已覆盖内容 | 本项目不能直接认领的创新 |
|---|---|---|
| [ACE](https://arxiv.org/abs/2510.04618)、[MemRL](https://arxiv.org/abs/2601.03192) | 执行反馈驱动经验整理、上下文更新或记忆效用学习 | 经验→反馈→Memory→未来收益这个通用闭环 |
| [TRUSTMEM](https://arxiv.org/abs/2606.25161)、[Memory Reward Inflation](https://arxiv.org/abs/2608.00017) | 可信记忆转换、错误评分与相关评判误差 | 终点分数不够、加入 verifier、可靠反馈再学习这些原则本身 |
| [Procedural Memory Distillation](https://arxiv.org/abs/2607.01480) | 跨任务程序经验形成记忆并进入策略参数 | Memory→参数或两者共同更新这个方向本身 |
| [Useful Memories Become Faulty](https://arxiv.org/abs/2605.12978) | 在受控任务流中比较持续归纳、原始经验保留及退化 | 首次发现更新可能失败、遗忘或保留原始轨迹有用 |

更换数值问答场景、增加 SFT 对照、观察到回归、拥有可复算 harness，都不自动构成新颖性。方法候选必须说明相对最近邻改变了哪个具体决策、要解释哪个尚未解释的残差，以及什么结果会否定其必要性。发现残差只说明有待解释；不等于已经识别创新或证明方法优越。

## 3. 历史推进门：先裁决必要性，再申请执行

两门是 2026-10-12 历史任务卡中的科学裁决，不另建 registry、自动审批器或治理平台。执行 Agent 可整理证据和提出判定；导师/owner 决定正式 claim。**“当前仅只读”已被 V2 Goal 取代；旧门仍可作为经验学习路线的停止条件。**

### G-RQ：研究问题成立门

在 WP-0 中明确并接受：

- 一个受限、可证伪的问题；区分反馈资格与未来效用，明确独立目标、相关行为、结果与失败解释。
- 精确任务/来源及经验复用的合理依据；真实工具执行会影响被消费的结果，来源独立性与许可可核验。
- 静态规则、朴素经验、更多上下文、更多计算及答案泄漏等主要替代解释；缺来源或精度不足不能被写成学习无效。

只有问题值得检验且所需任务资格成立，才可记 `G-RQ=PASS`，并注明适用任务。抽象问题合理不等于具体任务已过门；`TASK_QUALIFIED` 不等于实验获准。

### G-M：研究与方法必要性、创新识别门

同一个门必须注明获准研究的范围，不能用一次通过授权后面全部工作：

| 裁决范围 | 开始该范围前必须已有的判断 | 不能推出什么 |
|---|---|---|
| **最小验证/既有基线比较** | 近邻覆盖已核对；明确本任务仍未知的具体问题、为何必须做最小验证、比较与退出条件。WP-1/2，以及 WP-3 中必要的既有基线比较，均须逐项绑定允许范围。 | 不认证新算法必要性；`METHOD_NOVELTY` 仍可为 `NOT_IDENTIFIED`。 |
| **候选方法研究** | 有效经验复用机会与强简单/合适已有方法仍未解释的残差；具体机制差异、最近邻比较、可证伪假设与预算替代解释清楚。 | 只允许检验该候选机制，不认证其优越性、新颖性成立或顶会贡献。 |

G-M 的结果写为“允许哪个范围 / 未定 / 停止”，附证据位置。两门须在相应执行前完成；首个 pilot 也不能豁免。**不能要求先做未获准实验才能取得最小验证资格，也不能把最小验证资格偷换成方法研究资格。**

pilot 的 `CONTINUE_EXPLORATORY` 只支持申请必要性审查。若还缺合适已有方法比较，只可先在既定工作包范围内申请基线诊断，不能直接实施候选新算法。若已有方法足够，停止新算法；精度不足则保留未定。最终方法贡献仍须由独立行为与结果、强基线比较、机制必要性及 claim 范围共同支持。

## 4. 后续唯一入口与权限

最短路径：仓库规则与近期状态 → 本基线 → 架构 v3 的相关 RQ → 蓝图当前工作包。下一项是 **WP-0 只读核验 G-RQ/G-M 与任务资格**；不创建 runner，不采集经验，不加载模型。所需裁决记录在蓝图拟定的同一任务卡，不另建平行排期。

后续每次启动先检查两门对该范围的裁决，再检查数据/模型/训练/运行窗口等具体许可。`SOFTWARE_PASS`、已有权重校验、旧任务许可和本轮文档授权都不能替代这些条件。Paper E 收尾按作者级科学裁决另行处理，不依赖 pilot 正向结果，也不阻止只读核验。

导师/owner 保留：研究投入与停止、题目和学位范围、是否接受经验研究替代方法出口、资源/数据/运行许可、最终贡献与投稿决定。执行 Agent 不得自动认定文献空白、学位达标，或因结果未定扩充领域、模型、样本与训练阶段。

## 5. 冻结的 claim 与明确禁止事项

- Paper E 不能充当新任务 gold、反馈资格证书、行动归因方法或学习有效性证据；其与后续工作的连接是测量约束继承。
- 不能把研究链、Memory/SFT 模块完成、真实更新、repair 数量或版本增长写成科学贡献。
- 外部记忆收益不等于参数能力提升；一次 Memory/SFT 比较不识别一般知识分工，去检索后的行为保留不单独解释内部知识机制。
- 多轮更新不等于持续净收益；继续禁止通用 Agent、long-horizon、自主/递归进化及已识别因果信用分配等经验外推。
- 禁止未过对应推进门或未获具体许可就实现/运行后续研究；禁止为过门改判据、重复试到正向、隐去回归、用工程 PASS 认证科学结论。
- 旧 `DATA_NO_GO / RQ2 NOT_IDENTIFIED`、PR-03、旧 causal MVP、FinQA 失配载体与 TAT-DQA 闭线不解除、不换名恢复；原始数字、冻结证据、受保护政策与历史权限不回改。
- 本轮不执行实验、模型/judge/训练/GB10/服务调用、下载、改稿、代码修改、提交或公开。
