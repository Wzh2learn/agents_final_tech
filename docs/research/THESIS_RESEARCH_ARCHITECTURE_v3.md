## 1. 最终题目与范围

| 排名 | 题目 | 采用原则 |
|---|---|---|
| **1** | **《面向智能体的证据引导经验学习与持续适应研究》** | 推荐开题题目。英文：*Evidence-Guided Experience Learning and Continual Adaptation for AI Agents*。研究领域保持开放，硕士实证范围仍限定于所选工具型 Agent。 |
| 2 | 《面向工具型智能体的证据引导经验学习研究》 | 若最终只有单轮/有限适应证据，作为收窄定稿题目。 |
| 3 | 《面向长程任务智能体的经验学习与持续适应研究》 | 不作为当前路线。只有真实长流程、明确 horizon 变化及相应行为证据成立后才可考虑。 |

“持续适应”是待研究的问题，允许结论为更新无增量或产生回归，不预设持续提高。若只能完成单轮更新，就同步收窄题目与贡献。宽领域标题不授权同时开发推荐、搜索、Coding、Web 等 Agent，也不把一个任务的结果外推为通用能力。

**核心科学问题：什么执行经验值得转化为知识，进入什么载体才对未来任务有用，以及这种知识何时失效？**

[P] 有条件采用的硕士目标为：**纠偏后的 Paper E + 一项完整经验学习研究 + 对存活机制的有限持续适应边界检验**。它不保证新方法或正向结果。争取一篇强的后续核心论文；第二篇扩展论文不作为毕业前置。只有 Paper E、小规模 pilot 与一次 SFT 横比不能自动兑现完整学习研究或当前题目；是否满足学校方法创新与论文要求，须由导师明确。

## 2. 保留科学依赖，退出强制 EDR

保留 **Evaluation → Evidence → Learning → Adaptation**：

```text
评价观测实际测到了什么
  → 哪些实际执行证据足以支持反馈
  → 反馈能否改善未来任务上的行为
  → 多轮更新后收益、回归与成本如何变化
```

它是需要逐段证明的依赖，不是四模块框架或四篇论文，也不作为新框架贡献。独立任务目标、真实执行与事实支持是候选反馈资格的必要检查，不能由 checkpoint 分数循环认证，更不充分保证学习效用。一次执行正确不证明行动归因正确；修复成功不证明经验可推广；记忆有效不证明参数内化有效；单轮收益不证明持续收益。

[P] 不再要求完成 Evaluate–Distill–Evolve，不预设评估有学习价值、蒸馏有优势或演化必然发生。原 Distill 保留下来的问题是 **evidence-guided feedback construction / experience learning**；原 Evolution 收窄为具有明确反馈权限、更新空间和任务范围的 **agent adaptation**。

## 3. 最终三个 RQ

| RQ | 科学问题与身份 | 硕士最低证据 |
|---|---|---|
| **TH3-RQ1：Evidence Qualification** | 候选执行反馈是否具有事实支持、正确测量对象与获准使用条件？资格检验；不判断未来效用。 | Paper E 的受限诊断落实科学裁决，只提供测量约束；新任务独立检验目标、真实执行和反馈权限，区分错误、合理不变性与 UNKNOWN。行动级反馈须有行动级支持。 |
| **TH3-RQ2：Evidence → Learning** | 合格候选反馈能否改善未来任务的相关行为与结果？**核心待验证假设，方法创新尚待识别。** | 先证明复用机会与研究必要性；若进入方法研究，限一种机制，须有最近邻差异、强基线、合理预算与独立行为/结果证据。Memory 为候选主载体，参数更新为有界对照。 |
| **TH3-RQ3：Adaptation Boundary** | 多轮经验更新何时积累收益，何时放大错误或遗忘？边界研究，不预设独立创新。 | 对存活机制进行有限任务流真实更新，各臂维护独立状态；冻结、一次更新与持续更新对照；未来效果、旧能力和全生命周期成本共同报告。 |

TH3-RQ2 合并 v2 的反馈构造与学习载体问题；TH3-RQ3 对应 v2 的 RQ4。三问不要求三篇论文。Paper E 只提供与 TH3-RQ1 相关的测量反例和约束，不认证新任务 gold、反馈资格、行动归因或学习收益；反馈资格与未来效用分属不同待验证判断。

**命名边界：** `TH3-RQ*` 是新规划命名空间。旧 `RQ2 NOT_IDENTIFIED / DATA_NO_GO` 及各闭线状态继续保留；新的规划不解除旧门，也不能把旧 exploratory 数据改称新确认性训练集。新任务目前是 `QUALIFICATION_PENDING / NOT_RUN`。

## 4. 唯一核心研究范围：方法创新尚待识别

[P] 默认主任务仍为具有独立可复核答案的文档/表格数值问答 Agent：选择证据、解释单位与时期、调用计算工具、检查并回答。先核验经验确有复用机会，再开发学习方法。

第一优先级不是 Memory 系统或 SFT，而是：**来自历史任务的经验，能否在不泄漏答案、合理控制预算的条件下，改变未来任务的相关行为并产生有用增量？** 首个验证使用朴素经验复用，不先训练模型或记忆管理器。相关经验只改变行为但没有改善结果，仍不足以进入“有用经验学习”的方法主张。

[H] 核心候选假设仍是：具有真实执行支持和适用条件的反馈，可能比仅终点标签或自由反思更有学习价值。**该假设不代表已有方法创新；具体机制与 exact novelty 尚待识别。** 方法贡献不能只凭胜过这些弱对照认定，还须面对朴素经验和合适已有方法。

ACE/MemRL 已覆盖执行反馈与记忆适应，TRUSTMEM/Memory Reward Inflation 覆盖可信更新与错误反馈，PMD 覆盖程序经验到参数，Useful Memories Become Faulty 覆盖持续更新退化。主题与若干通用机制已有直接覆盖，尚不能断言具体未定义方法已被覆盖，也不能声称文献空白。近邻和 claim 约束统一见 [治理基线 §2](THESIS_RESEARCH_GOVERNANCE_BASELINE_v1.md#2-已有工作风险与创新边界)；[v2 §2](../archive/2026-10-19_THESIS_RESEARCH_ARCHITECTURE_v2.md#2-热点判断进入已有研究的核心问题而不是重新命名闭环) 保留为历史检索记录。

后续先在 WP-0 完成 [G-RQ/G-M 推进裁决](THESIS_RESEARCH_GOVERNANCE_BASELINE_v1.md#3-两个推进门先裁决必要性再申请执行)。最小验证必要性不等于新方法必要性；pilot 正向不等于创新成立。只有复用机会、强基线残差和具体机制差异清楚，才申请候选方法研究。限于**哪些经验可变成可复用反馈、应保留哪些适用条件**，一个主任务、一种主 backbone 和一个主要可训练决策；不同时训练 judge、writer、retriever 与 actor。

```text
同源、获准使用的执行经验
          ↓
证据支持的反馈构造/选择
          ↓
  外部记忆（主要载体）    参数更新（有界对照）
          ↓                    ↓
       未见任务上的行为、正确性、回归与成本
```

两种载体服务同一个问题，属于研究对象而非预设贡献。比较应分别区分反馈内容的收益和载体的收益；同源经验不保证信息访问或预算等价，不用额外教师、更多 token 或更多经验解释全部增量后仍归功于方法。一次有界比较不识别一般知识分工；去检索后的行为保留不单独解释内部知识机制。

[P] 保留一次小规模 SFT/adapter 对照，资源与数据资格在前三个月内作明确决定；不要求其取得正结果。它检验同一反馈能否脱离检索保留行为能力。若不可行就正式取消参数 claim，不将动态 Memory 结果冒充参数学习。不因已有 SFT/DPO/reward model 经验而默认启动 DPO、RL 或联合训练。

用户提供的推荐系统、用户建模、Memory、长序列与后训练背景，可以帮助研究经验表示和学习载体，但不构成方法优越性证据，也不改变唯一主任务的范围。

## 6. 热点词与 claim 边界

| 词语 | 当前定位 | 进入贡献所需证据 |
|---|---|---|
| Agent | 可进入题目；实证限定所选任务 | 真实工具选择和执行后果，经验实际影响后续行为。 |
| Memory | 候选主要载体与研究对象；不预设贡献 | 跨 episode 复用；优势须排除答案缓存、静态规则、简单检索与额外上下文。 |
| Post-training | 有界对照与研究对象；暂不放总标题 | 真实参数更新、去掉记忆后的独立验证；一个训练对照不自动构成后训练新方法。 |
| Continual Adaptation | 边界研究对象，可进入工作题目 | 多轮真实交互，收益和回归共同测量；只有单轮证据则收窄定稿。观察到退化不自动构成新发现。 |
| Self-improvement | 暂不作为主要贡献或标题 | 相对冻结/一次更新的未来净收益，并明确外部反馈、预算和更新范围。 |

当前避免作为既成贡献：自主/递归自我进化、开放式演化、通用 Agent、终身学习、long-horizon 能力、已识别的因果信用分配、记忆—参数共同演化。背景可以讨论，博士展望可以条件性保留，硕士不预支这些 claim。

## 8. 必须保留的退出路径

- 无独立目标或真实执行桥：停止该任务，最多一次有证据的收缩，不借旧 DATA_NO_GO 载体拼接。
- 经验未改变相关行为：先区分能力不足、呈现失败和任务不需要经验；不能直接宣布经验学习普遍无效。
- 只有行为变化、重复答案命中或更多计算收益：停止对应学习优势 claim。
- 精度不足：判证据未定，不将 null 写成等价；不自动无限扩样。
- 强简单基线或已有方法已足够：停止新算法，判断精度充分的机制比较是否值得完成。
- 单轮有效而持续更新无益：保留有限适应结论，撤回持续改进 claim。
- 核心方法没有独立增量：不转向博士扩展救叙事；由导师判断收缩成果是否满足学位要求。

## 9. 永久退出本主线的旧主张

旧 PR-03、causal MVP、FinQA 失配载体及 TAT-DQA 闭线不换名恢复。历史代码和结果保留，只供审计与复现参照；“永久冻结”指本主线不再调参、续跑或用于新训练，不是删除文件。

当前 `G-RQ=PENDING / G-M=PENDING / METHOD_NOVELTY=NOT_IDENTIFIED`，新工作包仍未运行、未授权。资源、数据许可、正式运行窗口、科学 claim、学位要求及外发仍由导师/owner 决定。每个 GB10 工作包先满足治理基线对该范围的推进裁决，再核对具体许可；不能按月份或蓝图箭头自动启动。
