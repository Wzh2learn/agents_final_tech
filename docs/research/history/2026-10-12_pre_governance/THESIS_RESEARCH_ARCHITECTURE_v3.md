## 1. 最终题目与范围

| 排名 | 题目 | 采用原则 |
|---|---|---|
| **1** | **《面向智能体的证据引导经验学习与持续适应研究》** | 推荐开题题目。英文：*Evidence-Guided Experience Learning and Continual Adaptation for AI Agents*。研究领域保持开放，硕士实证范围仍限定于所选工具型 Agent。 |
| 2 | 《面向工具型智能体的证据引导经验学习研究》 | 若最终只有单轮/有限适应证据，作为收窄定稿题目。 |
| 3 | 《面向长程任务智能体的经验学习与持续适应研究》 | 不作为当前路线。只有真实长流程、明确 horizon 变化及相应行为证据成立后才可考虑。 |

“持续适应”是待研究的问题，允许结论为更新无增量或产生回归，不预设持续提高。若只能完成单轮更新，就同步收窄题目与贡献。宽领域标题不授权同时开发推荐、搜索、Coding、Web 等 Agent，也不把一个任务的结果外推为通用能力。

**核心科学问题：什么执行经验值得转化为知识，进入什么载体才对未来任务有用，以及这种知识何时失效？**

[P] 硕士交付配置固定为：**纠偏后的 Paper E + 一项完整经验学习研究 + 有限持续适应边界检验**。争取一篇强的后续核心论文；第二篇扩展论文不作为毕业前置。是否满足学校方法创新与论文要求，须由导师尽早明确。

## 2. 保留科学依赖，退出强制 EDR

保留 **Evaluation → Evidence → Learning → Adaptation**：

```text
评价观测实际测到了什么
  → 哪些实际执行证据足以支持反馈
  → 反馈能否改善未来任务上的行为
  → 多轮更新后收益、回归与成本如何变化
```

它是需要逐段证明的依赖，不是四模块框架或四篇论文。独立任务目标和真实执行决定反馈资格，不能由 checkpoint 分数循环认证。一次执行正确不证明行动归因正确；修复成功不证明经验可推广；记忆有效不证明参数内化有效；单轮收益不证明持续收益。

[P] 不再要求完成 Evaluate–Distill–Evolve，不预设评估有学习价值、蒸馏有优势或演化必然发生。原 Distill 保留下来的问题是 **evidence-guided feedback construction / experience learning**；原 Evolution 收窄为具有明确反馈权限、更新空间和任务范围的 **agent adaptation**。

## 3. 最终三个 RQ

| RQ | 科学问题与身份 | 硕士最低证据 |
|---|---|---|
| **TH3-RQ1：Evidence Qualification** | 什么执行反馈足以支持智能体学习？经验基础与资格检验。 | Paper E 的受限诊断落实科学裁决；新任务具备独立目标、真实工具执行和反馈权限，区分错误、合理不变性与 UNKNOWN。行动级反馈须有行动级支持。 |
| **TH3-RQ2：Evidence → Learning** | 如何把执行证据转化为未来有效的经验与行为能力？**核心方法问题。** | 一种主要反馈构造/选择机制；同源经验、强基线及合理预算对照；未见任务上的行为与结果验证；主要载体为 Memory，参数后训练为有界对照。 |
| **TH3-RQ3：Adaptation Boundary** | 多轮经验更新何时积累收益，何时放大错误或遗忘？边界研究。 | 有限任务流中真实更新，各臂维护独立状态；冻结、一次更新与持续更新对照；未来效果、旧能力和全生命周期成本共同报告。 |

TH3-RQ2 合并 v2 的反馈构造与学习载体问题；TH3-RQ3 对应 v2 的 RQ4。三问不要求三篇论文。Paper E 只回答 TH3-RQ1 的已有部分，不能被改写成“已证明哪些反馈适合训练 Agent”。

**命名边界：** `TH3-RQ*` 是新规划命名空间。旧 `RQ2 NOT_IDENTIFIED / DATA_NO_GO` 及各闭线状态继续保留；新的规划不解除旧门，也不能把旧 exploratory 数据改称新确认性训练集。新任务目前是 `QUALIFICATION_PENDING / NOT_RUN`。

## 4. 唯一核心方法范围

[P] 默认主任务仍为具有独立可复核答案的文档/表格数值问答 Agent：选择证据、解释单位与时期、调用计算工具、检查并回答。先核验经验确有复用机会，再开发学习方法。

第一优先级不是 Memory 系统或 SFT，而是：**来自历史任务的经验，能否在不泄漏答案、合理控制预算的条件下，改变未来任务的相关行为并产生有用增量？** 首个验证使用朴素经验复用，不先训练模型或记忆管理器。相关经验只改变行为但没有改善结果，仍不足以进入“有用经验学习”的方法主张。

[H] 核心候选假设保持不变：具有真实执行支持和适用条件的反馈，比仅终点标签或自由反思更有学习价值。它既不是已有项目结果，也不是已证明的文献空白。现有近邻覆盖和新颖性约束继承 [v2 §2](D:/AIRcommend/JinRongAgents/agents_final_tech/docs/research/THESIS_RESEARCH_ARCHITECTURE_v2.md:26)，不再新增热点路线。

通过必要性检验后，仅围绕**哪些经验可变成可复用反馈、应保留哪些适用条件**选择一个主要方法机制。控制为一个主任务、一种主 backbone 和一个主要可训练决策，不同时训练 judge、writer、retriever 与 actor。

```text
同源、获准使用的执行经验
          ↓
证据支持的反馈构造/选择
          ↓
  外部记忆（主要载体）    参数更新（有界对照）
          ↓                    ↓
       未见任务上的行为、正确性、回归与成本
```

两种载体服务同一个问题。比较应分别区分反馈内容的收益和载体的收益，不用额外教师、更多 token 或更多经验解释全部增量后仍归功于方法。

[P] 保留一次小规模 SFT/adapter 对照，资源与数据资格在前三个月内作明确决定；不要求其取得正结果。它检验同一反馈能否脱离检索保留行为能力。若不可行就正式取消参数 claim，不将动态 Memory 结果冒充参数学习。不因已有 SFT/DPO/reward model 经验而默认启动 DPO、RL 或联合训练。

用户提供的推荐系统、用户建模、Memory、长序列与后训练背景，可以帮助研究经验表示和学习载体，但不构成方法优越性证据，也不改变唯一主任务的范围。

## 6. 热点词与 claim 边界

| 词语 | 当前定位 | 进入贡献所需证据 |
|---|---|---|
| Agent | 可进入题目；实证限定所选任务 | 真实工具选择和执行后果，经验实际影响后续行为。 |
| Memory | 主要学习载体；可进入方法描述 | 跨 episode 复用；优势须排除答案缓存、静态规则、简单检索与额外上下文。 |
| Post-training | 有界对照；暂不放总标题 | 真实参数更新、去掉记忆后的独立验证；一个训练对照不自动构成后训练新方法。 |
| Continual Adaptation | 研究问题，可进入工作题目 | 多轮真实交互，收益和回归共同测量；只有单轮证据则收窄定稿。 |
| Self-improvement | 暂不作为主要贡献或标题 | 相对冻结/一次更新的未来净收益，并明确外部反馈、预算和更新范围。 |

当前避免作为既成贡献：自主/递归自我进化、开放式演化、通用 Agent、终身学习、long-horizon 能力、已识别的因果信用分配、记忆—参数共同演化。背景可以讨论，博士展望可以条件性保留，硕士不预支这些 claim。

博士延展仅沿同一问题深化：什么知识适合留在可检索记忆，什么适合进入参数；两种载体共同变化时如何纠正失效经验。它们不成为硕士的隐藏毕业条件。

## 8. 必须保留的退出路径

- 无独立目标或真实执行桥：停止该任务，最多一次有证据的收缩，不借旧 DATA_NO_GO 载体拼接。
- 经验未改变相关行为：先区分能力不足、呈现失败和任务不需要经验；不能直接宣布经验学习普遍无效。
- 只有行为变化、重复答案命中或更多计算收益：停止对应学习优势 claim。
- 精度不足：判证据未定，不将 null 写成等价；不自动无限扩样。
- 强简单基线或已有方法已足够：停止新算法，判断精度充分的机制比较是否值得完成。
- 单轮有效而持续更新无益：保留有限适应结论，撤回持续改进 claim。
- 核心方法没有独立增量：不转向博士扩展救叙事；由导师判断收缩成果是否满足学位要求。
