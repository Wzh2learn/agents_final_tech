## 2 三线框架：评估 + 改进 + 自学习

导师的三段式与系统已建成的三条链一一对应，缺的只是数学形式化与公开数据实验。

### 2.1 评估线

**现成资产**：run_eval.sh 一键 eval（确定性 16 问 + 数值忠实度 NF + 四维 judge 防泄漏）+ scenario1 回归门禁 + B4 灰度仪表（route/latency/fallback 结构化日志）。

**升级目标**：面向金融文档智能体的分层测评协议——
- 解析任务检查点树：文档级（解析成功/页数/耗时）→ 表级（表边界/表头识别）→ 字段级（映射命中）→ 勾稽级（恒等式通过），每级带权，按 GTA-2 Algorithm 1 聚合
- QA 任务：RAGAS 五件套（Faithfulness / Answer Relevance / Context Precision / Context Recall / Answer Correctness）+ 拒答恰当性 + 数值忠实度（本项目特色，公开文献少见）
- Agent 链路：长流程可靠性指标（passk 重复成功率、RDC/RDS 衰减、GDS 部分完成、MOP 工具调用熵崩溃检测）——B4 日志与 opencode 轨迹是现成数据源

### 2.2 改进线

**现成资产**：双链路架构（直连 ~2s vs agent 验证 ~30s，M2_OPENCODE_ROUTE 灰度）、检索透明面板（top_k/score/route meta）、compare 模糊匹配、别名表确定性解析。

**升级目标**：记忆感知路由（memory-conditioned routing）——规则记忆覆盖到的查询走确定性直连，未覆盖走 LLM 推理；bandit/轻量 router 决策；指标 = quality-cost Pareto + Score/Cost。

### 2.3 自学习线（= docs/30 VGMC 主线，不变）

**现成资产**：schema 自学习闭环（LLM 建议→置信过滤→回归门禁→规则落库→--no-llm 确定性复现）；门控数据 apply 5 / reject 14 / hold 6；学习曲线活例：华泰紫金 35.7%→100% 且 LLM 调用归零；WaveFax 85.7%→100%、TraFax 同义词沉淀递进。

**差异化（M0 文献调研已确认成立）**：semantic memory 落成确定性可执行规则工件 + 固化前必过回归验证门；对照 Mem0/RecMem/CAIS 的自然语言记忆路线。

## 4 数学形式化清单

**可直接引用（hbkeyan 已有公式）**：GTA-2 递归聚合（Algorithm 1）、Root SR / Leaf SR / Tool SR、Score/Cost、RAGAS 五件套、passk/RDC/RDS/VAF/GDS/MOP、TSR/ARS/ATS、ECE/Brier。

**本项目需自定义（论文方法章核心）**：
- 命中率：$H = |\text{matched fields}| / |\text{all target fields}|$（按表加权）
- 固化门：建议 $s$ 被接受当且仅当 $\Delta H(s) \geq \tau_{acc}$ 且基线无退化（$\Delta H_{baseline} \geq -\varepsilon$）；reject/hold 的置信判据
- 学习曲线：第 $t$ 轮样本集上 LLM 介入次数 $\lambda(t)$ 的衰减率 vs $H(t)$ 上升率，收敛条件
- 路由：期望质量-成本 Pareto $\max E[Q]$ s.t. $E[C] \leq b$，覆盖度 $c$ 作为状态变量
- PSO 适配：粒子编码 = 检查点权重向量 / 题集选择向量，适应度 = 判别力正则化目标
