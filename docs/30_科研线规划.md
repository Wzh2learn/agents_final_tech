# 30 科研线规划：验证门控的记忆固化（VGMC）

学硕小论文科研线规划。由辅助线起草于 2026-08-13，基于 JinRong 项目工程经验的学术抽象。
核心原则：**不用甲方数据**。甲方经验仅以匿名化、抽象化表述进入论文 motivation；全部实验使用公开学术数据集 + 合成 schema 漂移。

## 1 定位

- 目标：从本项目的工程经验中提炼可发表的科学问题，产出一篇 agent/LLM 方向的小论文
- 学科靠拢方向：agent 算法 + 记忆机制（作者有深度学习与小模型训练背景，算法侧可承接）
- 科研与生产隔离：科研代码独立目录、独立 venv，不碰生产链路与冻结节点

## 2 主线：Verification-Gated Memory Consolidation（验证门控的记忆固化）

一句话问题定义：**LLM agent 如何把一次性推理产出的 episodic 经验，安全地固化为确定性、可执行、可复用的语义记忆（规则），并让 LLM 介入随记忆库增长而衰减？**

2026 年 agent memory 文献已收敛到 episodic / semantic / procedural 三层分类。现有工作的 semantic memory 几乎全部停留在"LLM 可读的自然语言"（Mem0、Letta、ExpRAG）。本方向的差异点：**把 semantic memory 落成确定性可执行的规则工件（schema/synonyms），且固化前必须通过回归验证门**。验证门是防漂移（anti-misevolution）机制。

### 2.1 三线重组：工程经验 → 算法贡献

**A 主线·验证门控固化机制**
- 项目原型：LLM 产出映射建议 → 置信过滤 → 回归门禁验证 → 规则落库 → --no-llm 纯确定性复现
- 真实门控数据：schema_suggestions apply 5 / reject 14 / hold 6；命中率曲线 华泰 35.7→100 且 LLM 调用归零（学习曲线活例）
- 贡献表述：executable semantic memory + verification gating；对照无门控固化量化漂移率

**B 模块·记忆感知路由**
- 项目原型：直连 2s vs agent 复核双链路 + B4 灰度观测（修复后 agent 路 best 13.5s，2026-08-13 S2 实测）
- 升级：memory-conditioned routing——规则记忆覆盖到的 schema 走确定性直连，未覆盖走 LLM episodic 推理；bandit 或轻量 router 决策
- "记忆覆盖度"这一变量把 A 与 B 统一进同一框架

**C 模块·忠实度评测协议**
- 项目原型：四维 judge（忠实度/数值/引用/拒答）+ 防泄漏设计（judge 不看期望答案）+ 确定性数值校验 + judge 一致性审计
- 定位：论文评测方法章 + 可复用评测工具

### 2.2 小模型插入点（作者 DL 背景主场）

1. **固化门控小模型**（主线心脏）：用"建议 × 是否通过回归验证"的历史记录训小分类器，预测建议能否固化，替代昂贵全量回归跑。产出 learned consolidation policy，指标 precision/recall/验证成本下降
2. **记忆感知 router 轻量模型**：contextual bandit（cf. ParetoBandit）或小分类器，指标 quality-cost Pareto
3. judge 蒸馏（35B → 小 judge，可选，最省力）

推荐组合：1 + 2 为主，3 视时间。

**差异化策略（related work 必须对比透）**
- vs RecMem：固化发生在 LLM 内部（自然语言记忆） vs 本方向固化到外部确定性规则 + 验证门
- vs CAIS 论文：semantic memory 仍是自然语言提示 vs 可执行规则 + 回归验证门
- vs ExpRAG / Mem0：检索式 episodic 复用 vs 结构性固化 + LLM 调用衰减曲线

## 4 实验设计

**数据集（全部开源，零授权）**
- 金融 QA / 表格：TAT-QA（16552 问，真实财报）、FinQA、ConvFinQA（多轮）、FinTabNet、PubTabNet
- RAG 评测：RGB、MultiHop-RAG、FinanceBench
- 记忆定位：MemoryAgentBench、STATE-Bench；LoCoMo / LongMemEval 作对话记忆参照

**核心构造：schema 漂移注入**
在 TAT-QA / FinTabNet 表上注入列名扰动、别名变体、跨文档异构 schema，模拟金融文档格式漂移——即本项目 15 源异构问题的抽象。注入脚本本身是科研资产。

**实验 1（贡献 1）固化机制闭环**
闭环：LLM 建议 → 门控 → 规则落库 → 重跑。基线：无门控直接固化 / 自然语言记忆（Mem0 式）/ ExpRAG 检索复用 / 纯 few-shot。
指标：命中率 vs LLM 调用次数衰减曲线、固化率、退化率（无门控 vs 有门控的漂移对比）、跨文档规则迁移率。

**实验 2（贡献 2）门控小模型 + router**
训练数据：建议 × 验证结果（项目真实 25 条门控记录作种子，合成扩充）。
指标：门控 precision/recall、验证成本下降幅度；router 的 quality-cost Pareto AUC vs RouteLLM 基线。

**实验 3（贡献 3）评测协议**
四维 judge + 防泄漏；小样本人工标注算 judge 一致率；judge 重复打分一致性审计。
