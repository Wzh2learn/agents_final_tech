## 1 路线裁定

近期会议小论文只回答一个主问题：**如何评价长流程文档智能系统，并验证评测协议本身是否具有发现缺陷的能力。** 论文以多层检查点树组织中间态评测，以受控缺陷注入测量缺陷可见性与静默吸收，再以 PSO 优化评测权重和题集，在成本约束下提高判别力。

VGRM 不作为近期会议稿主贡献，只说明“评测发现如何反馈系统”：评测发现未映射或错误规则后，候选修复经门控、确定性固化与回归验证，再重新进入评测。现有 VGRM 表级主效应置信区间含 0，不得承担“显著提升下游效果”的主张。

研究生毕业论文形成完整研究链：

1. 如何低成本、可复现地评价长流程系统，并使评测本身具有判别力；
2. 哪些缺陷会被中间层静默吸收，以及不可见性如何形式化和测量；
3. 评测发现缺陷后，如何把修复安全固化为可审计规则并控制回归；
4. 若跨层视觉补盲在治理错位后稳定成立，再升为条件性第四创新点。

若以现有材料今天直接投 AAAI 主会，模拟评价约 **Overall 4/10（Weak Reject），置信度 4/5**，更可能前期被拒而非进入讨论（2026-08-29 路线评审输入）。现有优点: 科学诚实度较高（探索性结果不覆盖冻结 null）、实验与规则固化过程高度可审计、缺陷注入与静默吸收现象清晰、预注册/冻结/种子/审计链/工件复现能力较强。

主要拒稿风险六类: ① VGRM 主效应不足（表级 ΔV(ACC)=0.05 但 CI 含 0；列级 7/40 vs 4/40，McNemar p=0.375——只能证明"门控机制工作"，不能证明"门控在真实任务上带来稳定显著收益"）② 理论保证偏弱（"有界回归"主要约束固化集，不覆盖未知 holdout；mε 随写入次数线性增长，更接近固化集上的回归记账而非未知分布上的安全保证）③ "盲锥"数学结构不足（无严格向量空间/缩放闭包/锥结构；不可证时改用 Defect Visibility Profile / Evaluation Blind Region / Silent Absorption Profile）④ 外部效度不足（单一公开底座、金融表格为主、合成注入较多、有效碰撞表约 15 张、单强度点、多数基线单次运行、视觉探针约 33% 错位/读串）⑤ 基线不够强（few-shot/Mem0 式/AWM 式只在 ungated 单臂；缺 no gate / gain-only / collateral-only / confidence gate / holdout-validation gate / rollback-versioning / 更强匹配器与全局分配对照）⑥ 主线过多（VGRM/盲区/视觉补盲/匹配竞争四条塞进 7 页会变成"两篇半论文"）。

重新结合专利后，完整技术链统一为: 长流程系统 → 分层检查点测评 → 缺陷注入检验评测是否有判别力 → 缺陷可见性分析定位"测不到的错误" → PSO 优化权重与题集 → VGRM 将评测发现安全固化为规则 → 再进入评测。这也是毕业大论文的总逻辑；小论文与专利不是两条线，而是同一套技术从工程实现向学术问题的抽象。

## 3 会议小论文

### 3.1 暂定题目

中文：**面向长流程文档智能系统的判别力感知分层评测：缺陷可见性诊断与评测协议优化**

英文：*Discriminability-Aware Evaluation of Long-Horizon Document AI Pipelines via Hierarchical Checkpoints and Defect Visibility Analysis*

### 3.2 唯一主张

最终结果正确不代表中间步骤可靠，也不保证评测协议能够发现被匹配层静默吸收的缺陷。本文构建分层检查点评测框架，用缺陷注入测量评测可见性，并在成本约束下优化评测协议的判别力。

主张分解为三个研究问题: ① 长流程系统最终结果正确，是否代表中间每一步都可靠？② 传统评测能否识别被中间匹配层静默吸收的缺陷？③ 在评测成本受限时，如何自动优化评测协议，使其更容易区分正常系统与缺陷系统？

### 3.3 三项贡献

1. **长流程分层评测框架**：将解析、映射、检索/推理、输出质量以及时延与模型调用成本维度组织为检查点树；确定性契约与防泄漏 Judge 分工，并保留逐检查项证据链。
2. **缺陷可见性诊断**：区分缺陷注入、检查点发现、中间层静默吸收和下游显形，报告缺陷可见性谱，而不是把所有失败压成单一端到端分数。
3. **判别力感知协议优化**：PSO 收紧为两个任务——检查点权重优化（最大化正常-缺陷系统评分分离度）与最小判别题集选择（题量/调用成本预算下保持高缺陷检出能力），与均匀、专家、随机/贪心对照，联合报告平均判别力、最坏类型检出率和评测成本，形成"设计评测 → 检验评测 → 发现盲区 → 优化评测"闭环。

VGRM 最多占一个闭环小节或一张流程图，只承担四种角色之一: 被测系统、风险产生场景、评测发现后的简单反馈案例、Discussion 闭环示例；闭环描述为"评测发现问题 → 生成候选修复 → gain/collateral 门控 → 回归验证 → 固化为确定性规则 → 再进入评测"。会议稿删除 DPO、RL、学习门等未闭环钩子，不展开当前非显著的 VGRM 净收益，也不得将其作为核心结论。

## 4 大论文创新点

> 收敛原则（路线评审输入）: 大论文不把专利创新点逐条展开，压缩为三个独立、清楚的学术创新；条件性第四点仅在视觉跨层补盲结果稳定后增列，否则降为创新点二的扩展实验。

### 创新点一：判别力感知的长流程分层评测

建立检查点树、确定性契约、防泄漏 Judge、证据链和缺陷注入组成的评测框架，并以 PSO 搜索权重/题集，研究成本—判别力 Pareto。该点继承专利主体，但学术论文必须补齐强基线、多次种子、不确定性和第二类长流程验证。

### 创新点二：缺陷可见性与静默吸收理论

定义注入、可见、吸收和下游显形，形成按缺陷类型与强度组织的可见性谱。近期正文优先使用 `Defect Visibility Profile`、`Evaluation Blind Region` 或 `Silent Absorption Profile`；只有证明缩放或闭包等严格结构后，才把“盲锥”作为理论主名。

该点需补阈值敏感性、强度梯度、等价变异校正、第二公开数据流和匹配竞争控制。oracle ACC 0.597 对比 plain 0.952 是机制发现，但不能把共同天花板误写成方法收益。

### 创新点三：评测驱动的门控规则自学习

把评测失败转成结构化候选修复，经 gain—collateral 双门控、确定性规则固化、回归验证与回滚形成持续改进。研究重点是建议可靠性、碰撞暴露和单次碰撞危害如何共同决定门控价值。

“有界回归”当前仅是固化集逐步记账性质；若不能给出未知样本高概率保证，则在大论文中降级命名。VGRM 经事前功效分析、强门控基线（缺口清单: no gate / gain-only / collateral-only / confidence gate / holdout-validation gate / rollback-versioning）、跨数据流和匹配竞争控制后，才具备单独投稿条件。

### 条件性创新点四：跨层互补的盲区修复

当文本匹配层对 OCR 形近扰动失明时，利用视觉或其他检查层提供互补信号，并按可见性与成本选择校验路径。只有视觉错位治理后结果稳定、跨层增益超过预注册阈值，才升格为独立创新点；否则并入创新点二扩展实验。

## 6 知识产权与公开边界

仓库只证明交底书已发导师，尚无正式申请日或受理通知书确认。因此可以内部写作、离线实验和匿名复现包准备，但不得上传 arXiv、公开完整技术报告或核心流程代码。任何会议投稿前，用户须向导师或代理机构确认申请状态，并做权利要求覆盖核对。论文新增的学术内容单列为增量，不反向修改冻结专利终态件。

边界内正常进行: 写论文、补实验、Graph Loop、审计、准备匿名稿；公开披露（arXiv/完整技术报告/核心流程代码/投稿）一律等专利申请状态确认后。
