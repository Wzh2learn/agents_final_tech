## 1. 当前最终基线

有条件保留 Evaluation → Evidence → Learning → Adaptation 及三个 TH3-RQ；它是逐段待证的科学依赖，不是新框架贡献。Paper E 是第一项测量审计章节的资产来源；后续独立研究候选反馈资格、经验未来效用与存活机制的有限适应边界。

**眼下只判断受限经验复用问题是否值得投入。** 最小问题是固定模型、工具与预算时，其他来源的相关真实经验能否改善新来源两期表格计算的结果与相关执行。不是开发完整方法，也不恢复强制 EDR。

当前 `G-RQ=PENDING / G-M=PENDING / METHOD_NOVELTY=NOT_IDENTIFIED`。任务卡设计完成不代表确切来源、许可、真实经验、模型 revision 或运行窗口已核验；首验尚未运行。

## 2. Paper E 与大论文：继承资产，不继承未证明的能力

| 可以继承的资产 | 必须同时继承的边界 |
|---|---|
| visibility/detection/contract-relative harmfulness 的测量区分、受限 evaluator 的观测审计 | 作为反例和设计约束；不认证新任务反馈资格、gold 或效用。Paper E 文字仍须落实 [投稿门禁](PAPER_E_SUBMISSION_READINESS_GATE_v1.md)。 |
| 单响应叶的结构诊断、显式 M/R/N codebook 与 non-direct 碰撞解释 | 构造内成立；没有 hierarchy 超出 direct 的增量，不是自然故障分布或行动归因方法。 |
| FinQA accepted autopsy、失败迁移与数值复算记录 | 继承“检测对象要沿实际执行生成”的检查；不继承旧正迁移解释或将失配载体用于新训练。 |
| origin/谱系、近重复隔离、独立目标、真实工具消费、UNKNOWN/回归/成本的记录经验 | 复用检查方式；新任务仍需重新验证资格。旧数据与预算不自动迁移。 |
| 已有代码、原始工件、验证器、图表/引用链与历史协议 | 按问题只读参考；只有经过新契约核验的必要组件才考虑复用，不整套导入生产/反思/PG 链。 |

**以下证据迁移永久禁止：**

- 从 Paper E 推出 Agent 学习、Memory/SFT/DPO 有效，或候选反馈“值得学”；从一次 repair 推出可迁移知识、因果信用分配或自主进化。
- 从 non-direct 0.3333 推出零信息；从 full=direct=1.0 推出 hierarchy superiority；从退化 clean 校准推出所有对应检测比较不可识别。
- 从 OCR-like 0/13 推出有害漏检或通用盲点；从单 judge 13/13 equivalent 推出独立无害 gold。
- 从 FinQA V/D/O、numerical PASS 推出有效迁移、执行后无害或 protocol blindness；从旧 pooled `[0,0]` 推出已证等价/零效应。
- 从当前 E 推出 long-horizon 实证；从版本数、更新次数或工程 PASS 推出持续改进；把旧 exploratory 数据重新命名为新确认面板。

“永久禁止”针对用这些旧证据作上述推论；不是断言相关科学问题永远不能由独立新证据研究。新证据与新 claim 必须另行资格、必要性和范围裁决，不能解除本主线已冻结分支。

## 3. 未来空间的身份：对象与假设，不是已有贡献

| 对象 | 已验证或已记录 | 待验证 / 探索边界 |
|---|---|---|

| **Memory / experience** | 当前没有 TH3 经验复用收益证据。 | 相关经验包是否有用是首验假设；Memory 是候选载体。四臂不能识别反馈资格、记忆更新算法或新方法贡献。 |
| **SFT / post-training** | 旧权重/环境验收不等于 MODEL_GO 或学习收益。 | 只有经验机会和必要性成立、资源另获许可后，才考虑既定有界参数对照；不预设参数内化或载体分工。 |
| **DPO / reward model** | 没有本路线效果或方法必要性证据。 | 保留研究空间，不列为现役必做包；需要合格比较反馈与具体必要性，未来另由导师裁决。不能自动在 SFT 后追加训练阶段或平行流水线。 |
| **Adaptation / self-improvement** | 当前没有 TH3 多轮更新净收益证据。 | 对存活机制研究有限收益/回归/遗忘/成本；单轮不推出持续收益，self-improvement 不是已成立贡献。 |

相关闭环已有直接近邻，覆盖依据在治理基线 §2；不另搜热点清单。题目中的“持续适应”是待研究对象，若仅有单轮证据，题目与贡献随之收窄；是否满足毕业要求由导师决定。

## 4. Loop A/D 从哪里开始

共同最短路径：`AGENTS.md` → `memory/CORE.md` / `STATE.md` / `THREADS.md` 相关当前条目 → 本入口 → 治理基线 → 当前 task card。具体任务再读蓝图相应包和确切源材料；不机械遍历旧实验。

| 下一任务 | Loop A 允许的后续工作范围 | Loop D / 导师 / owner 的裁决 |
|---|---|---|
| **WP-0，只读材料资格核验** | 按任务卡只读绑定来源/revision/许可/IDs/origin、目标与经验可得性、近邻覆盖；在同卡写资格附录与建议。无 runner、无经验采样、无模型、无自动下载。 | 判断 G-RQ、G-M 对最小验证及必要实现的范围；绑定具体访问/写入权限。Loop D 整理和派活，不代导师签署研究投入或贡献。 |
| **WP-E，独立的 Paper E 收尾** | 仅在另获改稿授权后，按投稿门禁落实 claim 与派生包；不补实验。 | 作者签署窄贡献；owner 决定外发、venue、署名与公开。它不等待 pilot 正向，也不证明 RQ2 成立。 |
| **WP-1，条件性软件实现** | 两门对该范围通过且实现获准后，按任务卡建一个薄执行器与必要软件检查。 | 软件 PASS 只认证合同；不授权历史经验采集或模型 pilot。 |
| **WP-2 及以后** | 仅读取已获准的当前包；两门、数据/模型/预算/窗口成立后才执行。 | CONTINUE 只申请必要性/已有基线比较；残差、具体近邻差异与可否证假设清楚后，才裁决候选方法范围。 |

Loop A 必须回执实际读取/修改范围、证据位置、PASS 的级别、调用与未核验依赖；不因月份、箭头、文档完整或旧权限自动推进。派活沿用 [执行约束](../../scripts/graph/loop_a_exec_constraints.md)，独立复核沿用既有 B/C 责任，不增建审批平台。

## 5. 不可自动做出的决定

导师/owner 决定：RQ2 是否值得投入、是否开发方法、是否接受经验研究替代方法出口、毕业范围/题目、SFT 或 DPO 必要性、适应扩展、数据/资源/运行窗口与发表。Agent 可提出建议，不能认证学位达标、新颖性、永久科学否定或无限补样。

来源不足停在资格核验；无效结果先判无效；精度不足保持未定；简单规则/合适已有方法足够则停止新算法。完整停止标准沿用 task card 与蓝图，不在本入口重设数值。当前可以准备下一张只读核验指令，**不能把本轮治理文档当作任何实验、训练或改稿授权。**
