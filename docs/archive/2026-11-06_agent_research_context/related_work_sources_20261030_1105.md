# 第二篇：反馈、记忆和技能进化的近邻核查

2026-10-30，基于公开摘要和页面元数据的针对性检索，**不是系统综述或论文全文复现**。目标是给下一步方法实验设置强参照，而不是根据标题宣称研究空白。

| 近邻 | 已覆盖的机制和证据（依作者摘要） | 对我们的约束与可借鉴实验 |
|---|---|---|
| [Skill-V](https://arxiv.org/abs/2610.11781)，2026-10 预印本 | 已把 skill 视为可证伪、可版本化合同；使用环境结果更新边界、历史回放检查非回归、过滤不适用技能，在 ALFWorld/WebShop 测试。 | **不能声称首创**技能适用条件、合同修订或历史非回归。比较其具体可用观察、回放成本、模型和规则过滤。 |
| [SkillShift-Bench](https://aclanthology.org/2026.emnlp-main.1952/)，EMNLP 2026 | 三个自托管 Web 系统、情境/感知/执行变化，并提供可执行性与测试时适配方法，报告成功率和交互成本。 | 不能把“环境变化下技能失效和适配”作为新问题；进一步核查源码和模型调用后，选择可比较的自然变化或反馈信任维度。 |
| [CFOE: Self-Evolving Agents Can Repair Failures but Struggle to Generalize](https://arxiv.org/abs/2610.22984)，2026-10 预印本 | 已研究只从失败学习，指出已见任务修复与未见任务迁移的差距，并分析误解失败及外部 verifier。 | 我们的单任务修复结果不构成新理论；须以真正未见任务/来源评估已有经验是否可迁移，包含成功轨迹、失败轨迹及无反馈对照。 |
| [Self-Authored Verification Is Unreliable](https://arxiv.org/abs/2607.24300)，2026-07 预印本 | 研究自写测试与部署表现的偏差；其 SEAL 用 Agent 不可见的固定审计和历史回滚减少退化。 | 不能只提出“用隐藏测试和回滚”；对照可见测试、外部审计、成本、不可见标签可得性以及不同参考缺陷。 |
| [EvoClawBench](https://arxiv.org/abs/2607.09711)，2026-06 预印本 | 比较无技能、任务前生成技能与任务后从轨迹总结技能，并计入创建成本；跨 coding、data、office 等任务。 | 不能只比较有没有生成 skill；可借其可执行工作流和 authoring 成本口径，核查环境和训练来源再决定能否复现。 |
| [Learning by Doing / Zep Agent Skills](https://arxiv.org/abs/2611.01386)，2026-11 预印本 | 从已验证轨迹编译带字段级证据的技能，管理准入、版本及检索；在多个基准上报告不同模型与任务设置，ALFWorld 使用训练游戏和 `valid_unseen` 场景。 | 不能仅以“经验附证据、分条件、版本化或跨场景”主张独创；应对齐其经验形成所用验证、持有任务、推理时检索和总成本。 |
| [SkillApt](https://arxiv.org/abs/2609.26863)，v3 2026-10 预印本 | 使用同一任务加载与不加载 skill 的配对执行反馈，学习是否复用 skill；区分任务质量与调用代价等情形。作者将如何获取配对反馈的成本列为进一步问题。 | “选择使用 skill”与“用有无 skill 的配对结果学习选择”已有直接先例；可检验何时值得获取额外证据，但需与无额外验证、固定预算、随机和同信息选择策略比较。论文链接的代码仓库本次未能访问，原因及可用状态未核实；基于论文自行实现须明确标注近似。 |
| [SelfEvoSkill](https://arxiv.org/abs/2606.14239)，v2 2026-10 预印本 | 比较有无技能的同起点执行轨迹，依据任务编译的验证器审查，再按失败模式选择 refine/repair 修订；论文也比较额外候选等基线。 | 不能仅把“配对轨迹、验证反馈、选择性局部修复”包装为新方法；需要核对两种执行的反馈访问、修订预算、任务可验证性和未见任务表现。 |
| [Agent Skills Can Be Harmful](https://arxiv.org/abs/2608.11888)，2026-08 预印本 | 在公开 skill 评测轨迹上研究与 skill 使用相关的功能失败及效率退化，并分析失效模式。 | 不能仅以“skill 可能有害或带来额外开销”为贡献；我们的具体日志可作为后续可复现归因和适用条件实验材料。 |
| [Repo2Skill-Evo](https://arxiv.org/abs/2608.21964)，2026-08 预印本 | 以旧版 skill 和真实版本补丁为输入，在 57 个项目、105 个有已确认过时内容的 release 变化上比较保留与修订；报告过度删除和漏改。 | “软件发布后 skill 过时、按补丁更新并保留有效内容”已有直接先例。其样本是选取了已过时的变化，不能推断所有发布都会导致 skill 过时；文中描述的材料公开位置本次尚未找到。 |
| [SWE-Skills-Bench](https://arxiv.org/abs/2603.15401)，v2 2026-10 预印本 | 在 98 个 skill 与真实固定提交 GitHub 项目上，用同任务无 skill/有 skill、隐藏执行检查和多种 Agent 配对比较；分析 context interference 与成本。 | 不能仅主张真实仓库上评估 skill 的作用；其 [MIT 仓库](https://github.com/ControllableModel/SWE-Skills-Bench)已在 GB10 取得固定快照，具体项目自身许可另核查。先核验选定任务的运行环境和测试，再考虑与真实历史/反馈形成的经验比较。 |
| [SWE-ContextBench](https://arxiv.org/abs/2602.08316)，v3 2026-05 预印本 | 在真实 GitHub issue 的相关任务上比较无历史、历史轨迹、摘要及自由/已知相关关系检索；作者还比较 Mem0、OpenViking、LangMem 和 Supermemory，报告任务成功、回归、时间与 token 成本。Lite 包含 300 个经验任务与 99 个目标任务。 | “从相关问题复用历史、摘要和记忆检索，并比较效果与成本”已有直接对标，须核对可见信息、提取及搜索总成本；优先选择具有可执行反馈和受控适用条件的连续问题。GB10 已完成固定来源与历史时间边界筛查，见[现役计划](../../../research/agent_frontier_portfolio_20261029/STAGE2_AGENT_RESEARCH_PLAN_20261102.md)；尚未复现作者的任务结果，公开轨迹中发现一例包含目标修复的后续 Git 记录，不能直接充当严格历史经验。 |
| [Useful Memories Become Faulty When Continuously Updated by LLMs](https://arxiv.org/abs/2605.12978)，v2 2026-08 预印本 | 研究同一经验经不同顺序及持续抽象后出现的记忆退化，比较原始情节、抽象记忆和是否进行合并，并分析适用条件丢失等机制。 | “压缩经验可能损失条件、原始历史可能优于总结、决定何时合并”已有直接研究。我们的读取截断是可观测的工具接口问题，可在同内容改变顺序的受控比较中考察其与反馈传递的关系；仍需区分模型生成错误、工具截断及下游效果。 |
| [SkillCAT](https://arxiv.org/abs/2606.13317)，v2 2026-07 预印本 | 对同题成功/失败轨迹做对比抽取，用源任务复跑评估 skill patch，再组织技能并按任务路由；作者在表格和文档任务上报告迁移实验。 | 对比成功与失败、验证后更新和按任务选择 skill 已有方法先例；若验证本项目的反馈保真度候选，应对齐其源任务验证信息、候选次数与总成本，优先尝试可复现实现或明确标注近似。 |
| [From Raw Experience to Skill Consumption](https://arxiv.org/abs/2605.23899)，2026-05 预印本 | 系统比较经验生成、skill 抽取与消费的完整过程，分析负迁移，并提出指导抽取的 meta-skill；作者覆盖多个任务域和模型。 | “发现压缩遗漏并用提示约束抽取”不能直接作为独立方法主张。应把其 meta-skill 或等信息抽取提示列入候选强基线，比较来源结果状态是否保留、实际任务表现与完整形成成本。 |
| [Trajectory-Informed Memory Generation](https://arxiv.org/abs/2603.10600)，2026-03 预印本 | 从轨迹提取成功策略、失败恢复和效率建议，带来源信息检索，并在 AppWorld 的未见任务上报告结果。 | 来源记录、失败归因和可检索经验均已有研究；本项目需明确在线可见的反馈是什么，以及额外结构化/验证是否超过同信息普通历史和已有方法。 |
| [Agent Skill Evolution: How Revisions Affect Coding Agents](https://arxiv.org/abs/2610.04832)，2026-10 预印本 | 作者从 856 个仓库重建 3,159 份 skill 的版本记录；针对可机器检查的新增／删除指令，区分回答中规则遵循、沙箱中实际动作和最终产物质量，并比较旧／新版、强制／按需读取及 token 成本。作者报告约 80 个可执行沙箱任务及配套材料。 | “版本变化影响 skill 行为”“按需读取”和“指令有效但最终产物仍可能失败”已有直接近邻；建议沿三个层次记录我们的真实轨迹，并补入等信息与读取成本对照。论文提供 [Figshare 复现包](https://figshare.com/s/1fd1668be2b3b5081ad6)，2026-11-04 GB10 请求返回 403，能否获取与复用暂未确认；作者结果尚未被本项目复现。 |

| [How Agent Skills Evolve](https://arxiv.org/abs/2611.04456)，2026-11-03 预印本 | 作者报告对 GitHub 中 84,200 份 skills 和 750,898 个相关提交的结构、变更模式和动机进行观察性分析。 | 可借真实历史构造变更候选，但仓库样本与动作效果不是现成的可执行金标准。作者列出的 [SkillEMP 代码与数据](https://github.com/ZJU-CTAG/SkillEMP)本次网页返回 404、GB10 匿名 `ls-remote` 无法取得；公开状态、许可与适用性待核实。 |
