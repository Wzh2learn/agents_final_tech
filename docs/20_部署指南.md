## 环境要求

| 组件 | 最低版本 | 说明 |
|------|----------|------|
| Python | 3.11+ | 推荐 3.12 |
| PostgreSQL | 14+ | 需安装 pgvector 扩展 |
| Docker | 20.10+ | 用于容器化部署 |
| 内存 | 8GB+ | 不含模型服务 |
| 磁盘 | 2GB+ | 不含模型文件 |

### 模型服务（可选，独立部署）

| 模型 | 用途 | 端口 | 显存/内存 |
|------|------|------|-----------|
| Qwen3.6-35B-A3B Q4_K_M | 解析 + 生成 + 视觉 OCR | :8004 | 6.5GB RAM + GPU |
| Qwen3-14B Q4_K_M | 辅助生成 | :8005 | 8GB RAM |
| Qwen3-Embedding-0.6B | 向量嵌入 | CPU | 1GB RAM |

模型服务通过 llama.cpp / LM Studio 独立部署，本系统通过 HTTP API 调用。

## 快速启动（开发环境）

### 1. 克隆仓库

```bash
git clone https://github.com/Wzh2learn/agents_final_tech.git
cd agents_final_tech
```

### 2. 创建虚拟环境

```bash
python -m venv venv
source venv/bin/activate  # Linux/macOS
pip install -r requirements.txt
```

### 3. 启动 PostgreSQL + PGVector

```bash
docker run -d --name pgvector \
  -e POSTGRES_PASSWORD=postgres \
  -e POSTGRES_DB=vector_db \
  -p 15432:5432 \
  pgvector/pgvector:pg16
```

### 4. 配置环境变量

```bash
export PGDATABASE_URL="postgresql://postgres:postgres@localhost:15432/vector_db"
export OPENAI_API_KEY="your-token-plan-key"
export M1_LLM_FALLBACK="1"
export M2_LLM_ENDPOINT="http://127.0.0.1:8004/v1/chat/completions"
# 可选: 本地 embedding 模型目录; 未设置时回退 SILICONFLOW_BASE_URL/SILICONFLOW_API_KEY 云端
export LOCAL_EMBEDDING_MODEL_PATH="/path/to/local/embedding/model"
```

### 5. 启动服务

```bash
bash scripts/m1_serve.sh
# 或手动:
PYTHONPATH=src python -m uvicorn main:app --host 0.0.0.0 --port 5050 --workers 2
```

### 6. 验证

```bash
curl http://localhost:5050/health
curl http://localhost:5050/api/m1/sample
```

## 环境变量清单

| 变量 | 默认值 | 说明 |

| `M1_LLM_FALLBACK` | `1` | 是否启用 LLM 兜底映射 |
| `PROXY_PORT` | `8100` | Responses->Chat 代理端口 |

## 常见问题

### Q: 启动报 "pgvector extension not found"
确保使用 `pgvector/pgvector:pg16` 镜像。

### Q: /api/m2/ask 返回空答案
检查: 嵌入模型运行? PGVector 有数据? LLM 服务运行?

### Q: OCR 解析超时
视觉模型处理扫描件需 30-70s，确保超时 >= 120s。

### Q: 端口被占用
```bash
lsof -i :5050
```

## 生产部署建议

1. **反向代理**: Nginx/Caddy 做 TLS 终止
2. **模型服务**: 独立 GPU 服务器
3. **数据库**: 托管 PostgreSQL + pgvector
4. **监控**: Prometheus + Grafana
5. **日志**: 结构化 JSON，接入 ELK/Loki
6. **密钥管理**: Vault 或 AWS Secrets Manager

## 认证配置

```bash
# API 访问令牌（保护所有 /api/* 端点）
export M1_API_TOKEN="your_secure_token_here"

# Schema 编辑令牌（保护 schema 写操作）
export M1_ADMIN_TOKEN="your_admin_token_here"
```

未设置时服务仍可运行，但会 log WARNING 提示无保护。

## 进程守护

### systemd
```bash
# 复制 unit 文件
sudo cp deploy/m1-harness.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable m1-harness
sudo systemctl start m1-harness
```

### supervisord
```bash
# 在 supervisord.conf 中添加
[include]
files = /path/to/deploy/supervisord.conf
```

## 环境变量完整清单

| 变量 | 必填 | 说明 |
|------|------|------|
| OPENAI_API_KEY | 是 | 千问 Token Plan Key |
| PGDATABASE_URL | 是 | PGVector 连接串 |
| M1_API_TOKEN | 推荐 | API 访问令牌 |
| M1_ADMIN_TOKEN | 推荐 | Schema 编辑令牌 |
| M1_LLM_ENDPOINT | 否 | M1 独立脚本 scripts/m1_statement_parser.py 的 LLM 端点 |
| M2_LLM_ENDPOINT | 否 | M2 生成端点 (默认 http://127.0.0.1:8004/v1/chat/completions) |
| LOCAL_EMBEDDING_MODEL_PATH | 否 | 本地 embedding 模型目录 |
| SILICONFLOW_BASE_URL | 否 | 云端 embedding 端点 (默认 https://api.siliconflow.cn/v1) |
| SILICONFLOW_API_KEY | 否 | 云端 embedding Key (本地 embedding 未设时必填) |
