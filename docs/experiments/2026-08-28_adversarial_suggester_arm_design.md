## 0 定位与机制锚点（为何这一臂是决定性的）

两次噪声体制 null 联合给出: 门控的终值级价值需碰撞暴露才显形（经验命题 1a）。噪声实验（L0-L3）证明可靠性轴只平行移动两臂（多余规则恒惰性）; 段 A 扩语料碰撞首次让两臂在 ACC 层面分离。**对抗建议器臂直接制造"碰撞暴露 × 单次碰撞危害"的最强形态**——主动产出高置信错误建议（模拟"自信且错"的建议源, 对照噪声实验的低置信强制注入）, 检验门控在最坏输入分布下能否拦住伤害。这是门控"价值"（而非仅"选择性"）的决定性验证, 也是 ε 维（回归约束分量）首次可能被实质激活的场景。

机制锚（代码实查, 非推测）: 门判据 G(r) = 1[ gain ≥ τ ∧ collateral ≥ −ε ]。对抗建议的 target 为"貌似合理的错列", 其在源表的 gain 可能 ≥ τ（错列仍被计入映射）, 但因碰撞语料中该表头在多表复现, 错误别名会在其他固化表造成命中率下降 → collateral < −ε → 门拦截。**无碰撞则无 collateral 信号, 门无法拦**——这正是预测 ③ 失效分支的机制来源。
