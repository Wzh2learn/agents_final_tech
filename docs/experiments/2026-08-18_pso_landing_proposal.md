## 1 两个 PSO 落点定义（三要素: 粒子编码 / fitness / 约束）

### 落点 ① 检查点权重分配（对应 K1 SOP Step 3 开放设计点）

- **粒子编码**: 权重向量 `w ∈ R^N`（N=20 叶 + 中间节点同父归一化, 与 config/eval_checkpoint_trees.json 结构对齐）。染色体维度 = 树上的"可权重化兄弟组"数（当前 20 叶 + 6 个同父组）。
- **候选约束**（二选一）:
  - 离散: `w_i ∈ {1,2,3}`（GTA-2 原文约束, 直接离散 PSO / 取整映射, 与专利步骤 5"连续值映射到最近离散取值"一致）;
  - 连续松弛 + 取整: 搜连续 `w ∈ [1,3]`, 评估时取 `round(w)` 并做兄弟组内归一化（保证 S_total 仍落在 [0,10], Algorithm 1 幂等性质不破坏）。
- **fitness（最大化判别力）**: 对正常样本集 Z 与注入缺陷样本集 D（K3 漂移表 + 配套构造的解析/数值缺陷问题）:
  `Sep(w) = (mean Root Score_D - mean Root Score_Z) 的 gap 方向取负` → 最小化
  `J1(w) = -|ΔSR(w)|` 或 `J1(w) = -(μ_Z(w) - μ_D(w)) - ε·σ_ratio`（σ_ratio 正则化防单样本主导）。
  简化可执行版（可直接实现）:
  `J1(w) = -(mean(RootScore_Z, w) - mean(RootScore_D, w))`，要求 `ΔSR(leaf) ≥ τ`（判别力底线）否则罚。
- **输出**: 判别力最优的权重配置（与 K2 基线 1-3 草案对照, 报告 ΔRoot Score 分离度提升）。

### 落点 ② 最小判别题集选择（对应 K2 "k 阈值无区分度 → 需要判别力目标"）

- **粒子编码**: 二值指示向量 `z ∈ {0,1}^M`（M = 候选题数, 当前确定性 16 问 + judge 抽样 + 可程序化扩充的对抗题集; 每维 = 是否入选评测集）。
- **约束**: 题数预算 `Σ z_i ≤ B`（如 B=12/16/20 档）; 类型覆盖约束（每类契约题 ≥1: source_required / exact_numeric / NF / judge 四维 / refusal）。
- **fitness（评判力保持率 × 题数惩罚）**: 对每个代表性子集用固定权重跑全量题, 计算子集 Root Score 与全量 Root Score 的相关/分离, 惩罚题量:
  `J2(z) = -keep_rate(z) + λ2·(|z|/M)`（keep_rate = 子集判别力 / 全量判别力, 用同 K2 的 Root SR 三档 k 统计）。
  可执行简化: `J2(z) = (1 - corr(RootScore_subset, RootScore_full)) + λ2·|z|/M`。
- **输出**: 最小判别题集（参与评测同时压缩评估成本）。

## 3 所需数据与前提（K2/K3 现状核实）

- K3 漂移样本: `data/research/drift_v0/sample_injected_tables.json`（95 表, 注入率 ≈3.8%, sha256 已存）。**前提**: 注入表须先走 VGMC 门控闭环（LLM 建议→过滤→规则落库→--no-llm 复测）才能成为"已知缺陷样本集 D"; 未过门控的原始注入表只作负例候选。

- 运行前提: 固定 eval 集（确定性 16 问 + NF + judge 抽样 + 视觉样张）+ 固定树定义; 每轮 fitness 需重算 Root Score（不占 :8004 生产推理, 用 :8006 空闲窗口或离线缓存）。

## 4 工作量估算与风险

- **优化器选型**: 优先手写 ~≤200 行（numpy, 标准 PSO 5 步, 附离散化/取整 + 0-1 编码映射）— 理由: 无第三方依赖、可审计、与专利 §3.2.6 逐行对应; pyswarm 备选（约束支持弱, 需包装）。工作量: 落点① ~1d, 落点② ~1d, 共享框架 ~0.5d。
- **过拟合风险（主要）**: 样本少（95 注入表 + 16-20 问题集）时 PSO 易拟合噪声 → 对策: (a) fitness 用留出交叉验证的判别力（split D 为 train/val）; (b) 连续松弛 + 取整减少搜索爆炸; (c) 题集选择加类型覆盖硬约束 + 题数惩罚 λ2; (d) 敏感度审计: 最终权重与 K2 草案差距 >1 档的节点单列说明。
- **与学术诚信边界**: 专利实施例（§5.3, 30 粒子/50 迭代/λ=0.3）必须作为"专利实施例复现"单独标注, 论文实验不得冒充专利实施例结果; 权重搜索只为评测协议服务, 不反向调优被评测模型; 注入样本为公开数据构造（甲方数据零进入）。
- **不占生产**: 满足 docs/33 §9 红线（独立 venv/目录; 错峰用 :8006; 模型准入预算门）。
