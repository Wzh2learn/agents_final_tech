# A15 bandit 奖励再设计稿（对抗臂数据已解锁, 只设计不执行）

> 状态: 设计稿（待窗执行） | 更新: 2026-08-29 | 依据: backlog A15 + 前瞻验证结论（奖励无分辨力）+ 对抗臂/扩碰撞数据
> 红线: 离线纯计算执行, 零端点; 判定只记不拍

## 1 问题（前瞻验证坐实）

v0 奖励 R = safe × gain_rate（safe = 批内接受建议全非负回归, gain_rate = 增益达标率）:
- 可靠体制: 全批 R=1（TS 4 决策点无分辨, 2026-08-28 前瞻验证）
- 碰撞体制: 固定门与 bandit 门终值逐位相同（奖励对体制不敏感）
- 根因: 奖励只含**收益分量**（gain/collateral 均为固化集局部量）, 无**伤害分量**
  ——伤害在 holdout（meas）经共享表头显形, 局部量看不见

## 2 再设计候选（三案, 伤害分量注入）

### 案 a · 反事实伤害惩罚（推荐）
R_batch = safe × gain_rate − λ_h · harm_batch
harm_batch = 批内接受建议直法应用到碰撞语料（overlay 系）后,
**碰撞列正确率的反事实变化**（ΔACC_collision, 直法可算, 零端点）。
λ_h 预注册网格 {0.5, 1.0, 2.0}; 伤害分量使对抗批的宽门（τ=0.05）得分系统性低于窄门。

### 案 b · 后见门一致性
以"知情 oracle 门"（用全知未来伤害标注每条建议该不该收）为教师,
奖励 = 批决策与 oracle 门的一致率。相当于把对抗臂的门拒 100% 蒸馏进奖励信号。

### 案 c · 双层时标
短期分量 = 现 v0（批内）; 长期分量 = 每 k 批重算 holdout ACC 差分。
实现最重, 留作案 a/b 均不满足分辨力时的后备。

## 3 预注册验证判据（执行时照抄）

1. **分辨力**: 对抗体制下（EXP/ADV 数据）六格奖励不再全同, 且宽门组均值 < 窄门组（方向正确）
2. **一致性**: 离线评估中奖励最优臂 ∈ {τ=0.1/0.2 组}; 若最优臂为 τ=0.05 = 再设计失败, 如实记账
3. **稳健性**: 案 a 的 λ_h 网格内结论一致（不随 λ 翻转）; 翻转则报案 b
