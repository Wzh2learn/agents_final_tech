## 3 机械判定（预注册判据当场对数）

- 判据: |ΔH| < 0.005 且 CI 跨 0 → 不可分; ΔH ≥ 0.02 → 有效需与 VGRM 对比; 其间 → 弱信号
- **三基线全部"与 no-gate 不可分"**（ΔH 逐位为 0, 非仅小于阈值）→ 按设计稿 §4 预注册结论入账: **替代记忆机制在本任务（可靠建议器 + 表头唯一语料）无增量, VGRM 显式规则库是充分机制**
- 结构解读（与噪声实验/碰撞实验同根）: 表头逐表唯一 → 记忆的价值通路（跨表经验迁移）无作用对象; mem0/awm 记忆虽正常累积（29/32 条）且读侧注入生效（建议数 54 = 有 1 条响应被记忆改变）, 终值 H 不动 = 覆盖度计数的天花板效应
- 效度注记（诚实优先）: ① H 为覆盖度指标非正确性指标（碰撞实验已证 ACC 更敏感——基线在碰撞语料下的 ACC 未测, 候补后续）② 每基线单次执行（未多 seed）③ 语料约束与噪声实验相同
