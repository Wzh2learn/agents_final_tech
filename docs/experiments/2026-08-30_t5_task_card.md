### 2.1 交互假设检查

| 变更对 | 共享资源/假设 | 冲突验证方式 |
|---|---|---|
| 渲染改动 × 探针改动 | 同一脚本族 + 工件目录 | 全表模式保留不删（首批基线点）, 裁剪为增量模式; 一分钟证伪 = 全表模式冒烟一表仍出图 |

### 2.2 预注册预测

错位率 33%→≤5%（残余=裁剪边界切字）; ocr_similar ≥50%（首批 61.5% 为含噪估计, 谱可能整体移动）; 全表×单列对照差 = 定位噪声量化。

## 3. 动作序

0. 前提证伪 + 全表模式冒烟（一表）。
1. 阶段 A: render_c4_tables.py 增裁剪模式（案 b: 该列+相邻 1 列+表头行）→ 渲染 c4_rendered_cols/（GB10 仓外）→ 零端点自证。
2. 阶段 B: 启 :8007（记录启动时刻+内存门）→ c4_visual_probe.py 逐列模式跑 118 注入（预算 ~118×2 调用 <10min）→ 停 :8007（记录停止时刻, 断言 DOWN）。
3. 汇总: 错位率 + 按类型判别率 + 跨层增益 + 全表对照 → 工件 + `git add research/render_c4_tables.py research/c4_visual_probe.py logs/graph/eval/t5_visual_crosslayer_validation.json` → commit `feat(research): T5 视觉跨层补盲（C4 案 b 单列裁剪 + :8007 复跑）`。
4. 判据落点: 双达 → 协议采纳声明入工件; 任一不达 → 整节删除声明入工件（不返工）。
