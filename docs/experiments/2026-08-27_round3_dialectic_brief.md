## §3 三个解释假说（H1 已证伪）

**H1 输入端假说（噪声没真正增加垃圾输入）: 已证伪。** L3 门见到了垃圾（拒 31/58）, 无门控吃下了垃圾（52/58）——垃圾进了记忆, 但终值不动。问题不在输入端。

**H2 惰性垃圾/碰撞匮乏假说（领先）**: 坏规则进入无门控记忆, 但度量集上没有它们的碰撞对象（注入表头逐表唯一）→ 不被检索、不生效、对 H 不可见。三条证据:
1. L3 无门控多吃 25 条规则, h_meas 零代价——垃圾确系惰性
2. transfer_rate = 0.1143——连好规则也大多到不了度量集, 瓶颈是碰撞暴露而非规则质量
3. 结构性论证（表头唯一 → 无碰撞）与预注册处置方向一致
证伪方法: 今晚段 A 扩语料碰撞——制造碰撞体制后若两臂分离, H2 坐实; 仍不分离 → 转 H3。

**H3 任务冗余假说（规则记忆本身无贡献）: 未约束。** 两臂 +0.031 的改善可能来自 episode 内学习而非规则记忆。裁决 = 今晚段 D 小 A 基线（Mem0/AWM/few-shot, 判据 |ΔH|<0.005 且 CI 跨 0 = 不可分）: 基线 ≈ 0.589 → H3 成立, 威胁根主张, 须升级上报; 基线 ≈ 0.558 → 记忆贡献 +0.031 坐实, H3 排除。

## §4 I1 口径修正提案（决策点 D1）

- 现口径: 门控价值 = f(建议器可靠性)
- 提案修正: **门控价值 = f(建议器可靠性, 碰撞暴露, 单次碰撞危害)**; 良性体制下表现为有界回归保证按设计工作, 终值级价值只在碰撞暴露下显形
- 证据支持: 可靠性操纵了垃圾输入（已证）; 碰撞暴露决定生效与否（transfer_rate + H2 证据链）; 门是过滤器不是生成器——L3 全池降级时门的筛选仍留下 −0.0095 对称残留（有界但不免疫）, 这是 I1 的诚实上限
- 推荐: 采纳修正。段 A 结果只决定碰撞项的测量值, 不改变口径方向

## §5 决定性实验设计（决策点 D2）

- 第一腿（已批, 今晚执行）: 扩语料碰撞——扩充度量集使注入表头拥有碰撞对象, 检验 H2
- 第二腿（提案新增, 需批）: **对抗建议器臂**——对未来碰撞目标表头故意产出高置信错误规则。预测: 无门控臂在碰撞目标子集单调退化, 门控臂 |Δ|≤ε; 若门控接受高置信对抗建议 = 过度自信利用失效模式（同样可发表, 且给出 ε 维下界）。预算: 复用现有流水, 单臂约 60 次 :8004 调用 ≈ 8min, 零新基建。此臂是"有界回归命题"最干净的实证
- 第三腿（挂账, 可选）: oracle 上限臂（全对建议）, 测记忆价值天花板

## §6 null 叙事（决策点 D3）

推荐叙事: 两次 null = "良性体制下保证按设计工作（无任何臂退化超 ε）+ 机制响应性在验收层面证明（L3 缺口 +25 单调放大）; 终值分离需要碰撞暴露"。以 transfer_rate 与 H2 证据链正面回应"机制无效"质疑, 并把 null 转为决定性实验的设计依据。禁止叙事: 把两次 null 讲成"机制验证失败"或静默不提。
