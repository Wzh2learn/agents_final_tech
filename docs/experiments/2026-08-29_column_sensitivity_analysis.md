## 1. 问题与边界

本分析复用 ρ=1.0 扩碰撞窗的既有 gated/ungated 检查点，对 15 张碰撞表中的 40 个碰撞列逐列配对，估计门控臂相对无门控臂的正确率差。它是用户在表级 E3 冻结后的补充敏感性分析，不是新的预注册主分析。

冻结结论保持不变：表级 ΔV(ACC)=0.05，配对 bootstrap CI95 `[0, 0.1056]` 含 0，E3 不触发，版本 B 维持。列级结果不得替换该口径，也不得据此切换版本 A。

## 2. 方法

- 分析单位：40 个碰撞列；每列同时计算 gated 与 ungated 是否映射到原标准列。
- 配对效应：`gated_correct - ungated_correct`，取值为 −1/0/+1。
- 朴素列级 bootstrap：对 40 个配对差重采样 10,000 次；该区间忽略同表列相关性，仅作敏感性观察。
- 表簇 bootstrap：重采样 15 张表，并保留每张表内全部碰撞列，以检查同表相关性下的稳健性。
- 离散配对检验：对改善/受损的 discordant 列使用双侧 exact McNemar 检验。

## 3. 结果

| 指标 | 结果 |
|---|---:|
| gated 正确列 | 7/40 = 0.175 |
| ungated 正确列 | 4/40 = 0.100 |
| pooled 配对差 | +0.075 |
| 改善 / 受损 / 同值 | 4 / 1 / 35 |
| exact McNemar 双侧 p | 0.375 |
| 朴素列 bootstrap CI95 | [−0.025, 0.175] |
| 表簇 bootstrap CI95 | [0, 0.1429] |

方向上，门控臂多正确 3 列；但 discordant 列仅 5 个，两种 bootstrap 区间均触及或跨过 0，exact McNemar 亦不显著。列级重判提高了观测粒度，没有把功效不足转化为统计闭环。

## 4. 解释与论文用法

1. 可写：探索性列级分析与主分析方向一致，gated 0.175、ungated 0.100，差 +0.075。
2. 必须同句携带：朴素 CI 跨 0、表簇 CI 触 0、McNemar p=0.375，证据仍不足以主张显著价值增益。
3. 不可写：列级分析“证明 E3 成立”“替代表级结论”或“触发版本 A”。
4. 对版本 B 的作用：补足透明度，说明方向性信号在更细粒度下仍存在，但当前数据主要支持条件性机制叙事，而非确定性效果声明。
