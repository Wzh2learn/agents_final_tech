# 演示脚本（2026-08-09 版）— 双链路"快与准"菜单叙事

> 状态: 活跃 | 更新: 2026-08-09 | 用途: 甲方演示/视频录制的标准脚本
> 核心叙事: 直连路约 2 秒/轮，适合快速交互；多 agent 验证链路 15-20 秒/轮，答案经独立 agent 复核、溯源遵从度更高，适合关键数字场景。快与准是**菜单**，由甲方按场景选。

## 录制模式说明

- 分段录制：段 A（直连）录制时临时关 `M2_OPENCODE_ROUTE`，**录完立即恢复 on 并验证 health**；段 B 起 route=on。
- 现场演示：全程 route=on，段 A 的"快"由等待期讲解覆盖（或提前说明两条链路差异）。

## 段落清单

### 段 A｜直连路快问快答（~2s/轮 × 2）
1. 打开 http://:5050/m1，展示三面板首页（10s）
2. 问答面板输入「复熙混合25号的资产总值是多少？」→ ~2s 出答，强调来源标注（看点：快 + 溯源）
3. 追问「嘉兴民安的对账日期是哪天？」→ ~2s 出答（看点：连续快问）

### 段 B｜agent 验证链路（关键数字场景）
4. 切到关键数字问题「嘉兴民安持有的证券市值是多少？」→ 走 agent 路（15-20s）
5. 等待期口播：独立 agent 正在复核检索证据，逐条比对来源；适合关键数字场景
6. 出答后展示 sources 明细（看点：溯源遵从度——每个数字都有出处）

### 段 C｜双链路一致性对照
7. 展示段 A/段 B 同一数据点的两条答案对照：数字一致、来源一致（看点：快与准不矛盾，准是快的超集）

### 段 D｜上传嘉合 PDF（电子件，毫秒级）
8. 上传嘉合客户对账单 → 解析完成，命中率 93.8%（看点：同版式 8 份一致性 + 字段映射）

### 段 E｜上传 WaveFax 传真（OCR 故事）
9. 上传 WaveFax 传真 PDF → OCR 进行中（等待期口播/字幕：视觉模型看图识字，全本地推理，数据不出域）
10. 解析完成，表格结构还原（看点：扫描件也能结构化，命中率 85.7%）

### 段 F｜复核面板
11. 展示勾稽校验四项结果 + 未映射列清单（看点：数据不足标"跳过"不造假）

### 段 G｜多轮追问
12. 「嘉兴民安的总资产是多少？」→「其中证券市值占多少？」（看点：追问自动关联上文）

### 段 H｜诚实拒答
13. 故意问「复熙混合25号的基金经理是谁？」（库中无此数据）→ 系统明确回答未找到（看点：不编造）

## 时间预算

- 段 A-C（问答双链路）: ~90s
- 段 D-E（上传解析，OCR 等待配讲解）: ~90s
- 段 F-H: ~60s
- 合计: ~4 分钟（目标 3-5 分钟）
