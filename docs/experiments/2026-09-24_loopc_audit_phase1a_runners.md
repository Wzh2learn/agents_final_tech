If artifact ids are not literally the role strings, every receipt fails `parser_input_hash_mismatch` unconditionally. Direction is fail-closed (no false PASS possible), but it would render the artifact gate-dead. Verify artifact-id convention or key by artifact_id.
2. **[MEDIUM] UID iteration domain deviates from the frozen excerpt.** Frozen t2 iterates `sorted(ent)` (injection-map uids); the runner iterates `sorted(by_uid)` (source-table uids). Consequences: (a) injection entries whose uid is absent from source_tables are **silently ignored** — t2 would KeyError (fail-closed), and without `--reference` the omission is invisible in a PASS receipt; (b) zero-injection table records are emitted that the frozen tables list would not contain (harmless for reconciled counts: such tables always have drop10 = 0, never discriminated). Recommend raising `invalid_injection_entry` on unknown uid. The drop caliber formulas themselves are unaffected.
