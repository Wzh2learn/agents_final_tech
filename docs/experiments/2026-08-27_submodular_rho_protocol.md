## 1 问题
VGRM 固化策略的理论支撑需要规则价值函数 f(S) = H_pool(S) 的次模性证据（边际递减）: 成立 → 贪心固化序有 (1−1/e) 近似保证 + 样本复杂度界（#1）的依赖项; 不成立（互补性显著）→ 门控需批级联合判定而非逐建议独立判定。

## 2 协议（复用实验 1, 三步纯计算）

1. **前缀曲线**: 取 gated 臂接受序（sugg_log accepted=True 按轮次序, n=38 规则）, 对 k=0..38 计算 H_pool(R*[0:k])（固化集全 60 表, 纯匹配器）→ 边际序列 Δ_k
2. **递减比**: 每规则 r_i = Δ_i / g_i（g_i = 接受时录得的独立增益 gain）; r_i ≤ 1 = 递减（次模方向）, r_i > 1 = 互补
3. **序敏感性**: 接受序 + 10 个种子打乱序, 各算前缀曲线 → 终值一致性与路径方差

## 3 ρ 定义（预注册）
- ρ_curv = 1 − min_i r_i（曲率, 0 = 完全次模无互补）
- ρ_order = 10 序终值 H 的极差（序敏感性, 0 = 路径无关）
- 判读: ρ_curv ≤ 0.2 且 ρ_order ≤ 0.01 → "近似次模" 入论文; 否则报告互补结构并分析哪些规则对互补（规则交互图 = 副产物）
