> 状态: 设计稿（只设计不写码） | 更新: 2026-08-27 | 依据: 骨架 v2.3 §5 基线清单 + #T7-GATE-HOLD 模板
> 范围: 三基线 × （记忆形态 / 读写接口 / 评测协议 / 预算估计）; 实验 1 与噪声实验已覆盖 no-gate 与 VGRM, 不在本稿
> 红线: 建议与写侧 LLM 仅 :8004（断言零 :8006）; 全合成语料（甲方零进入）; 生产配置零写; 本稿零执行

## 1 目的

骨架 §5 主图 = 门控价值曲线 + 基线对照。VGRM（gated）与 no-gate（ungated）已有完整数据
（实验 1 / 噪声实验四腿）。Mem0 式 / AWM 式 / few-shot 三条基线是"记忆机制替代方案"的
对照组，本稿把每条基线在本管线（表头映射闭环）中的记忆形态、读写接口、评测协议与预算
全部预注册，后续窗口照稿执行不再设计。

**对照设计**: 基线一律 ungated 单臂跑（记忆机制即其全部机制，不与门控交叉；
"基线+门控"交叉项记后续不排）。对照组 = 实验 1 ungated 臂（H 终值 0.589048）
与 VGRM gated 臂。

## 2 公共协议（与 VGRM 同批可比）

- 语料/切分: 95 注入表, seed=20260826, 60 fix / 35 meas（split_digest 4764938... 复用, 开场 1 命令核验）
- 轮次结构: 4 轮 × 15 表课程式, 每表每列只问一次（同 vgmc_exp1.py 主干）
- 端点: 建议/写侧 LLM 仅 :8004, temp=0（确定性）; 检索一律确定性词法（表头归一化重叠）, 不用 embedding/:15432（零生产依赖, 零新变量）
- 指标轴: H(t)（holdout 命中率）× λ(t)（LLM 调用数）+ 固化/记忆侧指标（见 §3）
- 工件命名空间: vgmc_baseline_{fewshot,mem0,awm}_{checkpoint,results}.json（与实验 1/噪声工件零交互）
- 预算门/中止: 同实验 1 先例（canary 争用改期 ≤2 禁 SKIP; :8006 p95 异常停）

## 3 三基线规格

### 3.1 few-shot（示例记忆, 最廉价, Phase 1）

| 维 | 规格 |
|---|---|
| 记忆形态 | 静态示例三元组列表 [（注入表头, 上下文提示, canonical）]; 初始池 = 固化集前 10 张表的已解决案例（holdout 零泄漏, 种子固定抽取） |
| 读 | 每次 llm_suggest 注入 top-k=6 示例（确定性词法重叠排序, 同分按池序） |
| 写 | 无（只读记忆, 不随流程增长——经典 few-shot 设定） |
| 专属指标 | 每调用 prompt 示例段 token 开销（均值） |
| 预算 | λ ≈ 41 调用/臂, 0 写调用; 单臂 ≈ 3-4min |
| 预注册预期 | H 曲线贴近 no-gate（示例不改规则库, 收益受 prompt 上下界约束）; 若显著高于 no-gate → 示例选择本身即弱规则, 记账重审 |

### 3.2 Mem0 式（事实记忆, Phase 2）

| 维 | 规格 |
|---|---|
| 记忆形态 | 自由文本事实条目（"『收八』是『收入』的 OCR 形近变体" 类）, 每条带来源表 uid 与轮次 |
| 读 | 每次 llm_suggest 检索 top-k=8 相关事实（确定性词法）注入 prompt |
| 写 | 每轮末 1 次 LLM 调用（temp=0）: 从本轮成功映射抽取事实条目; 精确串去重; **不做 LLM 合并**（Mem0 原版合并步昂贵, 简化点显式记账） |
| 专属指标 | 记忆条目数增长曲线 / 检索命中率（读到的条目被输出引用的比例, 判分宽松: target 匹配即算） |
| 预算 | λ ≈ 41 建议 + 4 写 ≈ 45 调用/臂 |
| 预注册预期 | H ≤ VGRM（自由文本记忆读时需 LLM 重新推理, 无确定性规则应用）; 条目数随轮次线性增 |

### 3.3 AWM 式（工作流记忆, Phase 3）

| 维 | 规格 |
|---|---|
| 记忆形态 | 过程性启发式片段（"遇单位后缀（元/万元）先剥离再匹配金额字段" 类）, 每条带适用条件 |
| 读 | 全量注入（过程性记忆预期 ≤10 条, 全量避免引入检索噪声; 超 15 条触发截断告警记账） |
| 写 | 每轮末 1 次 LLM 调用（temp=0）: 从本轮成败归纳新过程; 精确串去重 |
| 专属指标 | 过程条目数 / 跨表复用度（同一条目被 ≥2 张表引用的比例） |
| 预算 | λ ≈ 41 + 4 ≈ 45 调用/臂 |
| 预注册预期 | 三基线中最可能接近 VGRM（过程是唯一能跨表迁移经验的机制）; 若仍平 → 本任务收益主要来自确定性规则应用而非经验迁移, 直接支撑 I1 主张 |

## 4 判定与统计

- 每基线终值 vs no-gate 对照差 + 配对 bootstrap 95% CI（方法复用 research/k2_ms_bootstrap.py 口径, 重采样单元=表）
- 机械判据（预注册）: |ΔH| < 0.005 且 CI 跨 0 → 记"与 no-gate 不可分"; ΔH ≥ 0.02 → 记"基线有效, 需与 VGRM 直接对比"; 其间 → 记"弱信号"
- 三基线全部"不可分" → 骨架 §5 基线节结论 = "替代记忆机制在本任务无增量, VGRM 显式规则库是充分机制", 如实入账

## 5 交互假设检查（同窗多变更教训条款）

- 写侧 LLM 每轮 1 次, payload ≤2k token, temp=0, 与快路生产负载错峰（预算门同先例）
- 确定性词法检索零外部依赖（不触 :15432 / MCP / 生产检索路径）
- 工件命名空间隔离 → 与实验 1 / 噪声实验 / K2 / PSO 工件零交互
- 实现层: 复用 vgmc_exp1.py --noise 参数族先例, 预期新增 `--baseline {none,fewshot,mem0,awm}` 参数族 ≤80 行（执行窗口预批范围, 本稿不写码）
