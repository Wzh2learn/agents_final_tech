## 3 主图 schema 与 caption（侧线画图用）

**图 · 门控价值曲线（可靠性 × 碰撞暴露）**
- 类型: 散点+参考线（对数或分类横轴）
- x = 碰撞暴露量（分类轴: 无 → 67 移植列 → 对抗高危害靶; 对抗臂落地后可换连续量 = 每注入变体碰撞靶数 × 单次碰撞危害估计）
- y = ΔV（主）: 臂间差; 双面板或双系列 = ΔV(H) 与 ΔV(ACC)
- 系列 = 可靠性档（可靠 / temp / prompt / force / 对抗）, 点注体制名
- 参考线: y=0（命题 1a: 无碰撞体制全落其上）
- 数据点: §2 五行 + 对抗臂空位（虚线框占位）
- caption（草）: 门控价值 ΔV 在"可靠性 × 碰撞暴露"双因子坐标下的分布。无碰撞体制（左列, 含四档可靠性退化）ΔV 恒为 0（命题 1a 空转区）; 碰撞暴露引入后 ΔV>0 且由碰撞暴露 × 单次碰撞危害驱动（C0/C1, H 临界 + ACC 明确）; 可靠性退化只移动两臂水平（L3 对称抑制 −0.0095）不改变 ΔV。对抗建议器臂（高危害碰撞靶）待执行（台账 #13）, 预期补全曲线右端。数据表 = 2026-08-28_gate_value_curve_data.md §1-§2（全数字工件可溯源）。
