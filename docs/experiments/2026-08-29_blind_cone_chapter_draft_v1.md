## 1 问题定义

长流程文档管线的评测依赖端到端分数，而端到端分数在两个方向上失能：分数下降时无法定位
"系统看不见哪一类缺陷"；分数尚可时无法排除"某类缺陷只是尚未在评测样本中显形"。对金融
对账单这类高风险文档，后一方向更关键——被静默吸收的错误（系统照单全收一个错误列名）不会
触发任何端到端告警。

变异测试给出方法论原型：向被测对象注入受控变异，以变异是否被杀死度量充分性
（demillo1978hints; jia2011mutation）。将其移植到多阶段文档管线需要解决两个问题：变异
算子必须作用于真实数据结构（表头、版式、数值格式）而非代码语句；判别信号必须来自管线自身
的可观测响应而非外部断言。

本章提出**盲锥测度**：以受控注入 × 分层判别为构造，在缺陷类型空间上刻画系统判别能力的
下包络。缺陷类型空间中的每个方向对应一族缺陷；系统沿某方向的判别率塌缩至零，则该方向落入
盲锥——结构性失明。盲区由此从修辞变为可测对象：盲区方向、盲区质量（盲注入占比）与吸收
机制均可由工件复算。实例化域为金融对账单表头漂移；语料以公开数据集 TAT-QA 为底座全合成
构造（注入算子确定性、种子可复现），**甲方数据零进入**，该声明对全章有效。

## 2 盲锥测度（命题 2）

**缺陷空间与注入算子。** 缺陷空间 D = {缺陷类型 φ × 强度 s}。注入算子 δ: 表 → 表′ 为确定性
函数：给定表、缺陷类型与种子，注入结果逐字节可复现（实现 `scripts/research/drift_inject.py`，
确定性契约 sha256 `ebefc6f1…`）。确定性是判别率统计推断的前提。

**判别函数。** 管线在 δ 下的判别以可观测响应差度量。本章检查点取映射层：以表头映射命中率
H 的落差为信号，判据 drop10 = (H_orig − H_inj)×10 ≥ 2（量纲对齐 08-19 检查点树叶片的判据，
跨臂可比）。该定义可推广至任意检查点叶。

**命题 2（盲锥）。** 对缺陷族 Φ = {φ₁,…,φ_k}，判别率谱 {vis(φᵢ)} 的下确界方向定义为盲锥
方向；类型加权下的盲锥质量 BC(δ, D) = Σ_φ w_φ · blind_rate(φ)，w_φ 取注入分布频率权重。
等价变异对映——注入不改变语义、不应被判别的变体——构成假阳性校正项（承变异测试的等价变异
概念，jia2011mutation），本章留白（§5）。

**实证闭包。** δ=1（编辑距离 ≤1 邻域）处，BC 注入侧估计为 **22/118 = 0.1864**
（工件 `k2_ms_bc_analysis.json`）。逐类盲率极端不均匀：ocr_similar 1.0（13/13 全盲，锥尖）、
prefix_noise 0.1875、date_variant 0.1176、alias_variant 0.0851、mixed_lang 与 unit_suffix 0。
判别率点估计的统计闭包：表级主口径 **75/95 = 78.95%，bootstrap 95% CI [70.53%, 86.32%]**；
注入级 96/118 = 81.36%，CI [74.58%, 88.14%]（配对 bootstrap，seed=20260827，n=2000，Efron
百分位法）。缺陷族间配对检验：别名型−列名型 +0.492，CI [0.239, 0.647]（显著）；别名型−类型型
+0.031，CI [−0.127, 0.061]（不显著）；列名型−类型型 −0.461，CI [−0.675, −0.275]（显著）——
盲区方向集中于列名型（OCR 形近主导），别名型与类型型统计不可分（图 4）。

## 2.5 盲集族形式化（v1.1 增节）

本节把 §2 的直观定义固化为可计算对象。设表的全集为 𝒯，缺陷类型集 Φ，
注入算子族 {δ_φ : φ ∈ Φ}（每个 δ_φ 将表映射为含 φ 型缺陷的变体，确定性、种子可复现）。

**定义 1（判别函数）.** 给定判据阈值 γ（本文 γ=2，即 drop10 ≥ 2），
d_δ : 𝒯 × Φ → {0,1}，d_δ(t, φ) = 1 ⟺ 管线在 δ_φ(t) 上的响应差达到判据。

**定义 2（可见性）.** 对类型 φ 的注入实例集 D_φ（本文 = 95 表上该型注入的全集，有限），
vis(φ) = |{i ∈ D_φ : d_δ(i) = 1}| / |D_φ|。

**定义 3（η-盲集）.** B_η = {φ ∈ Φ : vis(φ) < η}，η ∈ [0,1]。
族 {B_η}_η 具嵌套性：η₁ ≤ η₂ ⟹ B_{η₁} ⊆ B_{η₂}（由定义直接得到）。

**定义 4（盲锥方向与全盲）.** 缺陷方向 = 按强度排序的类型族 {φ(s)}_{s∈S}；
若 vis(φ(s)) = 0 对某强度段恒成立，称该方向落入盲锥；vis(φ) = 0 称 φ 全盲。
本文实证：φ = ocr_similar 在 δ=1 全盲（13/13），为锥尖方向。

**定义 5（盲质量, 实例级主口径）.** BC(δ, D) = |{i ∈ D : i 被吸收（判别失败且静默通过）}| / |D|，
D = ⊔_φ D_φ 为全部注入实例。类型加权变体 BC_type = Σ_φ w_φ · 1[φ ∈ B_0]
（w_φ = |D_φ|/|D|）为衍生口径。本文实证主口径 = 实例级: 22/118 = 0.1864
（吸收实例跨四类型: ocr 13 / prefix 3 / date 2 / alias 4）; BC_type 在同数据下 = 13/118
（仅 ocr_similar 全盲）。两口径并记, 引用时须注明。等价变异对映修正：以剔除等价变异后的
判别重算两口径，本文未实现，均记注入侧上界（§5 局限⑤）。

**性质（可计算性）.** Φ 有限、D 有限、d_δ 由确定性匹配器给出 ⇒ 全部上述量可由工件
逐位复算（本文全部数值见 §2 实证闭包所引工件）；盲集族不依赖任何模型推断，
故跨模型可比（小模型臂/视觉臂可沿用同一判别函数，见 §5 衔接）。

**命名裁定.** 形式化成立，保留"盲锥"命名（盲锥方向 = 定义 4）；"盲区"作通俗同义词保留。

## 4 K2 v2 实证（核心数据节）

**协议。** 95 表 × 118 注入，判别器为管线实际使用的离线确定性匹配器
（`scripts/m1_statement_parser.py::map_headers`，纯规则、零端点），schema 为 canonical
（标准字段名）自含构造——度量敏感度而非绝对命中率。三性质判据承 08-19 树臂协议移植。

**主结果**（工件同上）：表级判别 **75/95（78.95%）**、注入级可见 96/118（81.36%）、
局部性 **95/95**、零漂移 **95/95**、重建核对 **0/95 不一致**。

**六类判别谱（图 1、图 2）。** 判别率沿缺陷类型单调分化；OCR 形近类判别率为 0%（13/13
全部被静默吸收）。机制分解（图 2）显示吸收全部发生在确定性匹配子层（编辑距离 ≤1 兜底与
归一化包含），盲区不是模型能力问题，而是规则匹配层的容错设计在形近字上失去判别力：容错
本为吸收无害变体而设，却对有害的单字形近漂移同等放行。

**盲区发现（本节头条）。** 漂移是否停留在匹配层？忠实度小臂（12 条分层抽样，端点 :8004）：
**9/12 模型忠实照读注入表头、0 条自动改写回原列名**——漂移穿透匹配层后，语言模型层既不
报警也不纠正，盲区的两层贯穿成立。含义：形近校验门（对编辑距离 ≤1 命中附加显式核验）成为
改进线候选机制（实现与评估属改进线，本章只引结论）。交叉印证：对抗建议器臂（#13, 08-28）
在碰撞体制下门拒高置信错列 100%，说明显式判据层可以拦截形近漂移的下游后果——盲锥发现的
盲区与门控的价值面在同一缺陷族上互补（详见 2026-08-28_adversarial_arm_experiment.md）。

**与 08-19 树臂对照（图 3）。** 臂规模（9 叶片 → 95 表 × 118 注入，+1 数量级）；三性质判据
框架同一且两臂分别成立；判别谱、crosswalk、MS bootstrap CI 与 BC 注入侧估计为表臂首次给出。

## 5 局限与衔接

局限（效度威胁清单，诚实优先）：① 单域（表头层），数值层与版式层未入锥；② canonical
自含度量敏感度而非绝对命中率；③ 忠实度小臂 n=12 只作机制证据不作率估计；④ 结构型缺陷无
注入；⑤ 等价变异对映未实现，BC 为注入侧上界口径。

局限追加（08-29 伴生问题入账）：⑥ 碰撞体制存在匹配竞争天花板（oracle 规则全在, meas 注入级正确率上限 0.597 < plain 0.952, 方法章 §5.5）——盲锥度量本身不受影响（判别函数与匹配器同构, 天花板为两臂共有项）, 但涉及碰撞体制的跨体制正确率比较须声明该共有项。

衔接：C4 视觉臂（2026-08-26_c4_visual_prep.md + 08-28 首批 61.5%）将视觉层判别力纳入同协议，
合成渲染题库为 BC 提供真实 OCR 错误分布侧估计（甲方红线禁入）；小 A（VGRM，第 2 章）——
盲锥是门控规则记忆的评测工具：门控判据的 ΔH 信号与本章判别谱共用同一注入底座。
