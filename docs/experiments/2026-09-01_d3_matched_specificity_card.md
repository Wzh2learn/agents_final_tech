> 窗口类型声明（§8 规则）: 阶段 A = 零端点窗（不限时段）; 阶段 B = 端点窗（仅白天错峰）。

## 1. 目标

在同假阳率（matched-specificity）档内公平比较扁平与分层协议的注入检出率与定位收益; 同步完成嵌入打分基弱门控定标诊断（决定嵌入臂引用方式）与阈值稀释救援通道。阶段 A 全零端点。

## 2. 预注册（冻结, 执行后不溯及; 推导门/经验预测分列——常备纪律）

### 2.1 推导门（一致性检查, 失配 = 实现/口径问题 → 查实现或停报）

- **G-1 冻结输入复现**: D1 三分类 85/7/26 + HI 机制 15/11; D2 阶段 A 迁移（翻转 0, 稀释先验 11）; D2 阶段 B 稀释先验 7/4 + 定标 0.5439 / margin −0.13278 / 同串对 74/286; W2 两臂基线计数（自 W2 冻结工件与报告复现, 与主线程抽验口径一致）。任一失配 → 停报。
- **G-2 零端点自证（阶段 A）**: ports=[] / model_calls=0 / AST 作用域检索零 http 客户端 / 冻结件只读（inputs sha 前后核对, 含 D1、D2-A、D2-B、W2 工件）。
- **G-3 端点窗条件（阶段 B, 若开）**: 预算计数器 ≤200 / :8004 主 / :8006 五条件 / canary 快照先行。

### 2.2 经验预测（真会被数据反驳; 两方向皆合法答案）

- **E-1 定标诊断（三态穷尽, 引用方式 = 结论的确定性映射）**: 对弱门控三项证据（margin −0.13278 / 负控 p75 0.5568>阈值 / 正控含 74/286 同串对）重诊断——剔除同串对后重算正控分布 + 备选分位（p10/p15）重定标:
  - (a) 校准恢复（margin>0 且负控 p75<新阈值）→ 嵌入臂**校准后引用**;
  - (b) 部分改善但正负控仍重叠 → 嵌入臂**降为敏感性分析**;
  - (c) 无实质改变 → 嵌入臂**不引用并记录理由**。
  三态写入工件 `embedding_citation_decision` 字段（由结果确定性映射, 禁止事后解释）。
- **E-2 clean controls 可行性（分支规则冻结于结构数, 与 FPR 结果值无关）**: n_clean = 未注入表计数。分支: n_clean≥40 → FPR≤0.05 与 ≤0.10 两档; 15≤n_clean<40 → 仅 0.10 档做匹配比较, 0.05 档报点估计 + 精确区间; n_clean<15 → 仅点估计 + Clopper-Pearson 区间, 不做匹配检验。估计一律精确二项（不硬套渐近公式, Phase C §3.5）。
- **E-3 matched-FPR 比较**: 匹配档内分层 vs 扁平检出率差为两方向合法; 报表级聚类 CI（Phase C §2.1）+ 表内配对检验; CI 含 0 → 如实报 null, 不造数据救轴（F-A5 教训）。
- **E-4 救援通道**: 11 例阈值稀释（生产打分基）经定标阈值/分层证据的救援数与机制; 先验（D2 阶段 B）: 嵌入基下 8 例 HI(dilution)→E。不设过判阈值, 如实报告。

## 3. 动作序（阶段 A, 零端点）

0. 前提一分钟证伪（P1-P5）; 任一证伪 → 按 §4 处置。
1. **A1 定标诊断段**: 读 D2 嵌入定标块 → 剔除 74 同串对重算正控分布 → 备选分位（p10/p15）重定标 → 按 E-1 三态出结论 → `embedding_citation_decision` 落工件。
2. **A2 clean controls**: 枚举未注入表（语料 − 注入集）→ n_clean → E-2 分支 → 扁平/分层两协议确定性部分跑 false-positive 谱 → 按目标档选阈值 → 定标表（阈值 × 协议 × FPR 档）落工件。
3. **A3 救援通道**: 11 稀释例过定标阈值 + 分层证据 → 逐例救援状态 + 机制（E-4）。
4. **A4 matched-FPR 比较（确定性部分）**: 匹配档内检出率差 + 表级聚类 CI + 配对检验（E-3 初步）; 若某协议判定需 judge 重打分 → 需求清单（表 × 协议 × 调用数估计）落工件作阶段 B 输入, 本阶段不跑。
5. 门判定（G-1/G-2 + E-1..E-4 状态）+ digest_self_consistency + 工件 `logs/graph/eval/d3_matched_fpr_stage_a.json` + 报告 + SUMMARY-GUARD 收据 + commit（逐路径）+ 汇报。

**阶段 B（另行派发, 端点窗, 白天错峰）**: judge 重打分（按阶段 A 需求清单）, :8004 主; 预算 ≤200 硬门（计数器入工件）; canary 快照先行, 异常即停 + 记账; 完成后 :8006 恢复零触碰态。阶段 B 卡内不新增判据, 只执行阶段 A 冻结的需求清单。

**执行纪律（承 D2 教训）**: 脚本增量写（A1 先独立写通交付, 再扩展）; 大工件按需读键段不全量复读; 段间不互锁, 闸失败改期 ≤2 次, 禁止静默跳过。

## 4. 中止与退出

- 中止: G-1 失配 → 停报; 执行中认为需要端点（阶段 A 内）→ 停报禁止静默; clean controls 枚举失败（语料不可访问）→ 停报（不得自造对照集）。
- 成功退出: 阶段 A 工件 + 报告 + 收据 + commit + §5 汇报。
- 失败退出: 两协议无法自冻结工件复现（G-1 不可完成）→ 方向关闭, 如实记账报主线程。
- pivot: 若 n_clean 落入最低分支且两协议 false-positive 谱全零（无可定标空间）→ 改报「零误报观测 + 检出率原始比较 + 效度注记」, 不硬造阈值。
