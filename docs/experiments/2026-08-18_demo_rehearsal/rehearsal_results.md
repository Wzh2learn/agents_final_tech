## GO/NO-GO 判定: **条件 GO**
- 条件 1（演示前必做）: 演示前 5 分钟内打 2 发 warm-up ask（curl 两轮题型），
  确认第 2 发 route=agent fell_back=false 且 ≤45s。
- 条件 2（现场）: agent 段只问两轮题型（嘉兴民安资金余额/总资产）; 三轮重题
  （OCR meta/跨文档）不上场。
- 条件 3（兜底）: >60s 未出答 → §3 预案切 route=off, 口头讲菜单。
- 若 warm-up 第 2 发仍回落 → **NO-GO: 全程 route=off 纯直连**, 验证链路口头讲 +
  docs/31 截图/视频 v2 佐证。
