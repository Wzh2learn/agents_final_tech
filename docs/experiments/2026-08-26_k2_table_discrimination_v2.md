## 2 协议与口径

- 输入: K3 漂移注入器 v0（49a4ec2, seed=42）的 95 张注入表 / 118 条注入（全部位于 row 0 表头行）
- 重建: 注入列换回原值重建 original 表头, 与 `sample_injected_tables.json` 原件逐表交叉核对（**0 不一致**）
- matcher: `scripts/m1_statement_parser.py` 的 `map_headers`（纯规则零端点; 精确=4/同义=3/包含=2/编辑距离≤1=1, 贪心占用）
- canonical schema: 每表以 original 表头去重后自含构造（唯一标准字段集, 合成闭环, 不依赖真实 schema）
- H = 命中 canonical 字段占比; **leaf drop = (H_orig − H_inj) × 10, 判据 ≥2.0**（对齐 08-19 叶片量纲）
- 三性质: 判别（drop≥2）/ 局部（非注入列映射零移动）/ 零漂移（双跑一致）
- 口径注记（携带专利 §5.3.3, 2026-08-21_patent_full_revised.md L509 已有同文）: **本 95 表注入样本集（列名/别名/类型/结构四类缺陷口径）与判别力测试床 9 类预构造缺陷场景是两个口径, 不混同**; 专利文本冻结未动
- B4 窗口: 22:3x 起登记（#K2-DISC-WINDOW）; 窗口流量不经 :5050 agent 路（确定性臂零端点 + 小臂直连 :8004）, 干净段实际零污染

## 5 盲区发现（本臂核心增量）

schema 映射层对 OCR 形近漂移**完全失明**: 编辑距离≤1 兜底（设计用于容忍轻微变体）将 13/13 单字形近错认全部静默吸收为合法映射, 零告警零降分。对照: 混合语言/单位后缀/日期语义漂移可见率 88-100%。含义:
1. 判别力测试床首次给出**按缺陷类型的判别谱**, 暴露层级化盲区——这是 08-19 检查点树臂（工件级 mutant）给不出的维度;
2. 改进线候选（只记账不动手）: 编辑距离层匹配加"形近可疑"标记（不静默接受）或引入形近校验门; 与减 step/上下文瘦身并列进论文改进线菜单。

## 6 第三层小臂（:8004 表忠实度 QA, n=12, temp=0）

每类型 2 条（确定性选取）, 端点 `:8004/v1/chat/completions` + `enable_thinking=False`（judge 同源约定; 缺此参数时 A3B 默认 thinking 会把 content 吃空——首次运行 12 条全空即此因, 修复后复跑）:

- **忠实照读注入表头 9/12**（漂移原样存活到 LLM 层, 模型不纠正）
- **自动改写回原列名 0/12**（无 LLM 层静默归一化）
- 列错位 3/12（答了相邻列名, 属 LLM 列计数错位, 与归一化无关, 另记账）
- 延迟 0.17-0.37s/条; 运行时断言零 :8006 调用
