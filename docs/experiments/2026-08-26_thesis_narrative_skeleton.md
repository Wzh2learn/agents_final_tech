## §1 核心主张（三创新点, I1 经 Round 2 收窄）

根主张: 面向长流程金融文档处理智能体, 提出**验证门控规则记忆**（VGRM, Verification-Gated Rule Memory）及其参数化内化扩展: 智能体将概率推理经验经验证门转化为确定性规则工件, 不更新权重即能力单调增长（training-free 自进化）; 再经 RL 将规则知识内化进小模型权重, 完成"外部记忆 → 参数记忆"迁移。

三创新点（声明 → 创新点以 §4 台账证据回填为准）:
- I1（算法+理论）: 门控固化算法 G(τ, ε) + 命题 1 有界回归保证 + 固化样本复杂度界; 固定门可升级为学习门（RL 钩子①）。**Round 2 口径收窄**: 保证部分（命题 1/2）成立不变; 实证价值部分为体制依赖——VGMC 实验 1（08-26, ce85736）在可靠建议器体制下门控臂与无门控臂 holdout 终值相同（0.589048）, null result 如实入账; I1 实证主张改写为"门控终值级价值需碰撞暴露才显形——建议器可靠性只移动两臂水平（多余规则恒惰性）, 碰撞暴露才制造臂间差"（经验命题 1a: 碰撞暴露 C=0 → 门控收益 ΔV=0）。噪声体制已证明（08-27, #12: 臂间差零 + 剂量响应成立, 固化率 0.717→0.466, L3 拒 31/58）。这不是坏消息: "门控何时值得"本身成为研究问题, 且实验 1 已给出一条完整贸易曲线端点（可靠体制: 固化率代价 4/42, 收益 0; 建议总数 53 含 no_map 11 未经门, 08-27 T4 裁定）。

- I3（泛化）: 机制不依赖模型规模——多小模型矩阵（4B/8B/14B/27B）复现 + 内化后知识迁移率。

## §3 公式骨架（承 v2.1 + 实验 1 实证注记）

对象与状态:
- M_t = t 时刻规则工件集; π = LLM 策略 + 规则执行器; V(M; D) = 记忆库在评测集 D 的检查点树聚合分
- 任务流 x_1..x_T; 轨迹 τ_i; 候选规则 r = Extract(τ_i)

固化门（小 A 核心算法, 正文伪代码）:
- G(r) = 1[ V_new(r) ≥ τ ∧ V_hold(M_t ∪ {r}) ≥ V_hold(M_t) − ε ]; append-only
- 样本复杂度界: n ≥ ln(2/α)/(2ε²)（Hoeffding 1963）——实验 1 已给出 ε 维实证: collateral 全 ≥0, ε 不活跃（零有害建议, 可靠建议器体制）
- 经验次模性（猜想+实证）: 边际增益比 ρ; 消融实验待排
- 概念锚: 规则库+验证门 ≈ 版本空间维护（Mitchell 1982 candidate elimination）

命题 1（有界回归）: 门控条件下 V(M_t; D_hold) ≥ V(M_0; D_hold) − Σε_i 且单次准入回归 ≤ ε; 证明 = 归纳。注: 实验 1 中该保证空转（无有害建议触发）, 恰是"保证先行、价值体制依赖"的证据。
命题 2（容差盲锥, 加固）:
- 定理: 接受编辑距离 ≤ δ 变体的匹配器, 对 d_edit ≤ δ 的变异可见率为 0
- 度量: BC(δ, D) = P_{μ∼D}[d_edit(μ) ≤ δ], 用 118 注入 + 真实 OCR 错误分布计算
- 等价变异对映: 全吸收 17 表（drop=0）↔ 等价变异问题

经验签名（小 A 主图, Round 2 注记）:
- H(t), λ(t) 定义不变; 实验 1 首曲线在位: 基线 H_meas=0.558 → 终值 0.589（两臂同）, λ 合计 41/臂, 轮 3 仅 7/15 表需问 = 跨表迁移真信号
- 曲线粒度限制（实验 1 §6.2 入账）: 每表每轮只问一次, 4 轮批粒度粗 → 幂律拟合（Newell & Rosenbloom 1981）暂不适用, v2 小批多轮后再拟

变异判别（小 B）: MS + bootstrap CI（Efron 1979）; 数据 = 联跑 v2 工件。

路由（章 3）: max_π E[Q] s.t. E[C] ≤ b; s_t = (x, c_t); LinUCB（Li 2010）/ CMDP Lagrangian。

RL 两钩子:
- 钩子① 学习门: v0 = (τ,ε) 网格 Thompson 采样 bandit → v1 = DPO → v2 = GRPO 可选; 样本审计（Round 2 完成）: 生产门控日志 23 条 + 实验 1 建议 53 条（含全量 ΔH/collateral; 其中 42 条带门评估结果, 08-27 裁定）+ 网格重放可机械扩格 → bandit v0 样本充足, DPO 仍偏薄
- 钩子② 知识内化: 门控后轨迹 DPO/GRPO; 门纪律 = 只有门控过的轨迹可入训练; 评估 = 知识迁移率 + 回归零容忍
