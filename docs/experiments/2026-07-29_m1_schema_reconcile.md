### 勾稽抓到的错配/异常

**jiaxing.pdf — 市值勾稽 FAIL**:
- expected: sum(明细市值) ≈ 总资产 = 4,013,8xx.xx
- actual: sum(市值) = 8,027,5xx.xx（≈2× 总资产），diff = 4,013,7xx.xx > tol = 2,006,9xx.xx
- 原因: p0_table_3 含 2 行明细，市值合计约为总资产的 2 倍；疑似同一证券在两张子表重复计入，或明细表含非持仓行。

**jiaxing.pdf — 静默错配嫌疑 FAIL（2 项）**:
1. `持仓数量←配号数量(含'配号')`: p1_table_7 中"配号数量"被映射到"持仓数量"，语义不等价（配号 ≠ 持仓）。扩 schema 前此错配不可见（在途数量/配号数量 均通过"数量"子串匹配静默命中）。
2. `市值勾稽失败→明细/汇总映射可能错配`: 市值勾稽 FAIL 联动标记。

**关键改进**: 扩 schema 后 p0_table_3 的 `持仓数量←在途数量` 静默错配被消除——新增的"股份余额"近义词优先级更高，在途数量 正确落入 unmapped，从"不可见错配"变为"可见的未映射"。

## 5. 对北极星指标的贡献

### 5.1 列对齐覆盖率

- 可解析样本 headline 表加权命中率: **52.4% → 66.7%**（+14.3pp）
- 核心持仓/汇总表: xinxizha 100%、fuxi table_2 90%、jiaxing p0_table_3 88.9%
- 新增"资金资产汇总"表使 fuxi table_1 和 jiaxing p0_table_2 从误匹配（持仓明细/交易对账单）归位到正确 schema

### 5.2 错配率

- 扩 schema 前: 至少 2 处静默错配不可见（持仓数量←在途数量、持仓数量←配号数量）
- 扩 schema 后: 在途数量 正确 unmapped（错配消除）；配号数量 仍映射但被勾稽标记为嫌疑（错配可见化）
- 勾稽校验使"映射成功但语义错误"从 0 可检测 → 2 项可证伪

### 5.3 未知表头冷启动

- header_meta_fields 6 → 14（+133%），boshi KV 报告体从 0 提取 → 2 KV
- 新增"资金资产汇总"表覆盖资金余额/资金可用/总资产等此前无 schema 归属的表头
- 仍 unmapped 的表头（基金净值、登记机构、累计净值、在途数量等）为下一轮扩 schema 提供明确候选
