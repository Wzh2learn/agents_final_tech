## 1 问题设定

长流程文档管线的表头映射依赖规则库 R = {标准字段 → 同义词集}。新版式文档持续引入未映射
表头；建议器（LLM）对未映射列给出候选映射。问题：**在建议器可靠性不可保证的前提下，如何
把建议沉淀为规则而不引入回归？** 免训练约束：不更新任何模型参数（training-free，
zhang2024selfevolution 谱系第一级）；参数内化（RL）为预留钩子（§6）。

记号：表集按课程序引入；H(S, R) = 表集 S 在规则库 R 下的表头映射命中率（覆盖度口径）；
建议 r = (表, 列, 目标字段, 注入表头)。

## 2 算法 G(τ, ε)：门控固化

```
算法 1  G(τ, ε) 门控规则记忆
输入: 课程表序 {T_1..T_n}, 建议器 S(·), 阈值 τ>0, 容差 ε≥0, 初始规则库 R_0
输出: 规则库 R
1: R ← R_0
2: for t = 1..n:                          # 课程引入
3:   C ← T_t 中未被 R 映射的注入列        # 未解析列
4:   if C = ∅: continue
5:   for r in S(T_t, C, R):              # 建议流（含置信度, 门不可见）
6:     gain(r)      ← H({T_t}, R ∪ r) − H({T_t}, R)        # 源表增益
7:     collateral(r)← H(F_t, R ∪ r) − H(F_t, R)            # 固化集回归（F_t = 已引入表）
8:     if gain(r) ≥ τ and collateral(r) ≥ −ε:              # 门判据
9:       R ← R ∪ r                       # 固化
10: 记录 (r, gain, collateral, 判定) 供审计与偏好学习（§6）
```

实现 = `research/vgmc_exp1.py`（run_arm gated 分支, 逐字对应第 6-9 行）；对照臂 = 无门控直固
（第 8 行恒真）。门只看 gain/collateral 两个实数——置信度、来源标记对门不可见，这是对抗臂
（§4）设计的前提。

## 3 命题 1（有界回归）与实证

**命题 1.** 设 G(τ,ε) 依次固化建议序列 r_1..r_m，且每个被接受建议满足
collateral(r_i) ≥ −ε。则固化集上的累积回归有界：
H(F, R_0) − H(F, R_m) ≤ Σ_{i=1..m} max(0, −collateral_i)，且当所有被接受建议
collateral ≥ 0 时回归为 0。

**证明梗概.** 每步固化对固化集命中率的改变量恰为 collateral(r_i)（第 7 行定义）；对序列
伸缩求和即得。单步回归不超过 ε（接受条件），故累积回归 ≤ m·ε；当被接受集全非负时为 0。∎

**实证对照（工件在案）.**
- 可靠体制（实验 1 + 噪声四腿）：门拒均为增益型（collateral=0 域），回归 0，但臂间差亦 0
  （经验命题 1a 的空转区：C=0 → ΔV=0）；
- 碰撞体制（C0/C1）：ε 维首次实质激活（门拒含负 collateral 建议），回归 0 保持；
- **对抗体制（#13, 08-28）：高置信错列 7/7 全被门拒（100%），Σε=0，回归 0——命题 1 在
  最坏输入分布下成立**；同时暴露命题 1 的边界：有界性依赖碰撞暴露提供 collateral 信号，
  无碰撞则门无法拦（设计稿机制锚）。

## 4 门控价值曲线（主图）

门控价值 ΔV = 门控臂终值 − 无门控臂终值（双指标：H 与碰撞列正确率 ACC）。坐标 =
可靠性 × 碰撞暴露（数据表 = 2026-08-28_gate_value_curve_data.md §1-§2，全数字工件可溯源）：

| 体制 | 可靠性 | 碰撞暴露 | ΔV(H) | ΔV(ACC) |
|---|---|---|---|---|
| exp1 / 噪声四腿 | 可靠→三档退化 | 无 | 0 | — |
| 碰撞 C0/C1 | 可靠 / force | 有（67 移植列） | +0.005715 | +0.16 / +0.08 |
| 对抗臂（#13） | 对抗建议器 | 有（k=16 对抗靶） | +0.005715 | +0.16 |

主张（Round 3 D1 裁定）：臂间差只由**碰撞暴露 × 单次碰撞危害**驱动；可靠性只平行移动两臂
水平（命题 1a，噪声四腿 + 对抗臂逐位同值实证）。曲线右端伤害显形仍欠（fix↔meas 表头共享
不足）→ 扩碰撞复跑（设计稿 2026-08-29 在案）补危害梯度。

## 5 与记忆机制基线的对照（充分性主张）

三基线（静态示例 / Mem0 式事实记忆 mem0_2025 / AWM 式过程记忆 wang2024awm；经验检索族
锚点 zhao2024expel）在可靠体制单臂对照：**与 no-gate 全部不可分（ΔH 逐位 0，配对
bootstrap CI [0,0]，08-28 基线窗）**；记忆正常累积（29/32 条）而终值不动——表头映射任务的
跨表经验迁移价值让位于显式规则库的确定性应用。该 null 是实证贡献：training-free 自进化的
价值载体是显式规则而非隐式记忆（在本任务族上）。效度注记承基线执行记录（H=覆盖度、单
seed、语料约束）。
