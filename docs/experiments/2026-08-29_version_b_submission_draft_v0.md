## 1. 暂定题目

**门控规则记忆何时值得：碰撞暴露驱动的免训练规则固化机制与盲锥评测**

英文题目工作稿：*When Is Gated Rule Memory Worthwhile? Collision-Exposure-Driven Training-Free Rule Consolidation with Blind-Cone Evaluation*

## 2. 摘要工作稿

长流程文档处理系统依赖规则持续沉淀，但由模型生成的规则建议可能把局部错误固化为跨样本回归。本文提出门控规则记忆（VGRM），以增益与旁损伤约束决定建议是否进入规则库，并将规则固化价值分解为建议可靠性、碰撞暴露与单次碰撞危害的共同作用。为识别传统覆盖率指标难以显露的失败，我们进一步构造盲锥评测，将可注入扰动、匹配层吸收与下游错误区分开来。在 95 张公开表格构成的合成注入语料上，门控臂在对抗建议器条件下拒绝 7/7 个目标建议；扩碰撞实验首次观察到无门控臂覆盖度伤害 ΔH=−0.0057，而门控臂维持零伤害并保持 100% 对抗建议门拒。预注册的表级价值差为 ΔV(ACC)=0.05，但 CI95 `[0, 0.1056]` 含 0，未达到版本切换条件。补充的探索性列级分析得到 gated 7/40、ungated 4/40、差 +0.075，但朴素 CI95 `[−0.025, 0.175]`、表簇 CI95 `[0, 0.1429]` 与 exact McNemar `p=0.375` 均表明不确定性仍高。结果支持一个条件性结论：门控选择性已得到机制证据，但其可量化价值依赖充分的碰撞暴露；本文据此报告方向性收益、两次 null 与功效边界，而不把探索性分析包装为确认性闭环。

## 3. 贡献组织（2+1）

1. **门控规则记忆机制**：提出增益—旁损伤双判据的规则准入机制，并以有界回归命题约束免训练固化风险。
2. **盲锥评测方法**：区分“扰动存在、匹配层吸收、下游是否显形”，给出跨扰动类型的判别力与盲率测量框架。
3. **条件性实证与生产边界**：系统测量可靠性×碰撞暴露条件下的门控价值；多模型泛化仅作 pilot，全部研究数字来自公开/合成语料，甲方数据零进入。
