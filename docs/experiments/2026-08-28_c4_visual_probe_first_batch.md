## 3 头条发现（供一页纸）

1. **跨层互补成立（首批信号）**: OCR 形近类 = 文本匹配层盲锥锥尖（判别 0%, 13/13 静默吸收, K2）, 却是视觉层判别率最高的方向（refined 61.5%）——匹配层的盲区恰是视觉层的明区。C4 臂的论文价值（视觉层补盲）获首批数据支持。
2. **视觉层自身噪声不可忽略**: 118 注入中 39（33%）判为错位/读串（VLM 读了邻列或数据行）, alias 类最重（25/47, 短中文注入列邻长英文表头 → 读邻格）。视觉臂协议需列对齐校验或裁剪渲染, 否则错位噪声淹没判别信号——后续批次前置项。
3. 探针吞吐: 95 表 ~2.5min, 全量跑批无预算压力; 瓶颈在渲染质量与判定细化, 不在算力。
