## 二、彩排驱动的选题变更记录（护栏执行证据）

- 护栏: 演示不用对抗性测试题（当前完成率低, 44% 卡第一步, 进不了预算）; 用快路问题 + 确定性评测题集选题。
- 实测发现: route=on 生产态下, 确定性/快路三问类问题全部被路由进深度验证通道（30-50s/问）——"快问快答 2 秒"在现行路由下仅对结构化查询（compare 意图/持仓对比）成立。
- 终选: 快路段 = 持仓对比面板（实测 11ms）; 深度验证段 = 确定性题集"复熙混合25号的资产总值"（彩排实测 52.4s, 完成）; 多轮段 = 确定性题集"嘉兴民安总资产→其中证券市值"; 拒答段 = "星辰私募1号"（v2 沿用, 非对抗题集）。
- 等待时长: 深度验证段实测值已烧录进字幕与解说（52 秒）。

## 四、口头解释条目（备用, 不入配音）

1. 等待期 "thinking..." 为正常状态提示; 回落机制保证最终出答并注明原因。
2. "未找到"是特性: 只回答有出处的数字。
3. 深度通道完成率的诚实披露: 根因已定位（上下文膨胀致每步变慢）, 治理路线 = 步骤精简 + 上下文瘦身。
4. 验证链路等待 = 独立复核进行中, 超时有回落兜底。
5. 数值脱敏: 面板中账号/金额部分脱敏是数据安全措施。
6. "跳过"不是失败: 源数据缺字段时勾稽标注"数据不足, 跳过", 防误报设计。
7. 全片问题来自确定性评测题集与快路三问; 对抗性测试题不入演示。
