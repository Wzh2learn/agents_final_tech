## 3 三预测机械判定

- **③ PASS（头条）**: 门拒对抗建议 7/7 = 100% ≥ 80%——过度自信利用失效模式未出现。**机制更正（08-29 全盘复审, Loop C F1）**: 7 条对抗事件全部 gain=0.0(<τ) 且 collateral=0.0(≥−ε), 拦截发生在 **gain 维**（与实验 1 / C0 / C1 同为增益型拦截）, ε 维未点火（Σε=0）; 设计稿 §0 预期的 collateral<−ε 路径未出现——对抗错列 gain 恰为 0（错列仍计入映射, 同根）, 这本身支持"伤害未显形"并强化 B 扩容动机。判定（预注册机械）不受影响。
- **① 字面失败**: 无门控 ΔH = +0.051428（改善, 非退化）, u05/u10 的 H/ΔH 逐位相同（固化率不同: 0.7619/0.7294, 08-29 审计 F4/F5 限定）, 单调性为弱不等式（≤, 含等号）且 vacuous。机制解读: （a）H 为覆盖度指标, 错配仍计 mapped（设计 §0 已注记）; （b）被无门控接受的对抗规则（9/11 条）其表头在 meas 子集复现不足 → 伤害未显形（对抗列 ACC 0.0667 显示 fix 侧确被污染, 但 meas 未接住）。
- **② 双口径并记**: 字面 |ΔH|=0.057143 > Σε=0 → 不成立; 但 ΔH 为正向转移改善（与 C0 同值）, 对抗来源伤害 = 0（门控零接受对抗建议）, 命题 1 有界回归实质未被破坏。

## 4 结构发现（供一页纸与 B 设计）

1. **门控的选择性在对抗输入下成立**（P3）, 但本语料未提供伤害显形条件 → "门控价值"的 H 级量化仍欠一次伤害显形实验——这正是 B 扩容复跑的设计输入: 扩容需**定向提高 fix↔meas 表头共享度**, 让被接受的错误规则在 holdout 有碰撞靶（危害梯度 = 共享度 × 对抗比例）。
2. 三臂终值 H 与 C0/C1 逐位相同（0.651905/0.646190）——可靠性轴（含对抗档）只平行移动两臂水平的规律再次成立（经验命题 1a 延伸）。
3. u05 与 u10 的 H/ΔH/ACC 逐位相同（固化率除外）: 增量对抗列（0.5→1.0 增量 8 列中 5 列在 u10 有事件, 净新进流 2 列=11−9, 08-29 审计 F4 更正）被接受后仍无 meas 显形——与发现 1 同根。
4. 交接: A15 奖励再设计现具备"门拒 100%"的正样本锚; DPO 对增量可加对抗臂流（全拒轨迹）。
