## 1. 六件尸检（结果 → 机制 → 对主张的含义）

### 1.1 C2 分层 vs 扁平（检出/成本/定位三轴拆开）

结果（臂 B 95 表臂, 工件 logs/graph/eval/t1_eval_baseline_comparison.json + checkpoint_discrimination_report.json）:
- 表级检出: end-to-end 95/95, flat 75/95 (0.7895, 与冻结工件逐位一致), hier(expert) 20/95 (0.2105)。
- E1.6 三 seed: flat 0.7895/0.7835/0.7556, 合并 219/282=0.7766, CI [0.727, 0.8227]（≥3 seeds CI 可算 = C2 唯一 PASS 维）。
- 臂 A 9-mutant 树臂: 检出 2/4/3/9（四协议）, 分离度均值 1.2526/1.2536/1.2526/1.4282; 定位率 E1.1=0 vs 其余 1.0; 成本 2 vs 12 单位。
- 层级稀释机制（T1 supersede 注记）: E1.3 hier 斜率 3.75 vs 预期 10, ΔH≥0.5333, reconcile 排除口径敏感。

机制: 层级聚合把单叶信号稀释到根分（兄弟归一化 + 硬闸门之外的软叶被平均掉）, 检出率天然不是层级评测的强项; 其真实增量在层位归因（哪个检查点吸收/检出）与证据可分解（根分可逐叶拆）, 且确定性契约为主使评测预算更低（2 vs 12 单位口径）。

含义: R2 主张拆为"检出-吸收-传播"（可见性谱, 与分层无关）+"定位-诊断"（分层专属增量）, 检出敏感性不主张任何优势, 连"等效"也不写（§2 句）。

### 1.2 C3 PSO 权重/题集优化（公平对照后证伪原主张）

结果（工件 logs/graph/eval/t4_pso_fair_comparison.json, 抽验 26/26）:
- mean_sep: equal 1.256268 / expert 1.255968 / random30 均值 1.260413（16/30 超 expert, 最优单体 1.367023）/ greedy 1.432574（67 evals）/ PSO 5 seeds 1.432574（7650 evals, 逐 seed 全等, std=0）。
- worst_mutant: PSO 0.092591 < expert 0.208331; minimax 变体 worst 0.35714（均值代价 −0.176524）。
- 题集预算梯度 25/50/75/100% keep_rate 恒 1.0（饱和, 见 1.5）。
- 冻结复现门: abs_err=0.0 且权重逐维全等（原 1.2560→1.4326 结果本身无误, 是缺对照导致的解读错误）。

机制: 该搜索空间下目标函数对坐标上升近似可分, 贪心 67 次评估即达 PSO 7650 次的同值——PSO 的群体探索在此景观零增益; 且均值目标与最坏情形冲突（均值最优 ≠ 最坏缺陷最优）。

含义: PSO 从贡献删除; 论文方法最多一句带过（§2 句）; 原 1.2560→1.4326 (+14.06%) 仅作"权重选择有判别力增益"的附注证据（相对 equal/expert 成立, 相对贪心不成立）。专利交叉核对见 §3。

### 1.3 M7 不可见（突变体保真度 / 可观测性机制发现）

结果（工件 t4_pso_fair_comparison.json payload.findings.F_W2_1 + e1_5 矩阵）: M7_nf_fail_3 在 Full-Judge 口径分离度 = 0.0000（映射口径 0.2083）; NF 工件 9 条中 8 条 number_claims=0, 注入只落在聚合量 n_fail=3。

机制: item 级裁判只能看到逐条证据; 缺陷若只存在于预聚合量（n_fail）而逐条证据无异常, 则对 item 级判分结构性不可见 → 裁判与 control 同分。这是突变体保真度（缺陷是否落在可观测证据层）问题, 不是裁判能力问题。

含义: 入账为 mutation fidelity / observability 机制发现（与变异测试"突变体未杀死测试"的解读风险同族）。**不得用重设计 mutant 偷偷替代原 M7**（J2 附加条件）; 重设计注入属"有效突变体定义"问题, 走 Phase C 预注册 + D1 审计, 原 M7 数据原样保留。

### 1.4 量化地板（一致性判据的量纲失效）

结果（工件同上, endpoint_consistency_note + prereg_predicates）: 逐维 |Δ| = 0.0（citation）/ 0.5（faithfulness）/ 0.0（refusal）; max|Δ| = 0.5 = 容差边界; 0-10 整数叶分 1 单位 = 0-5 尺度 0.5, 恰等于容差宽度。

机制: 容差宽度 ≤ 评分分辨率时, "|Δ|≤容差"恒真或恰在边界, 判据无区分力; "HOLDS(边界)"不构成一致性证据, 只构成"未证伪"。

含义: 论文按 J1=a 写——端点一致性"只能验证到离散评分分辨率", 不写"端点高度一致"; 同口径内判分-映射排序一致性（Spearman 0.9744 / 方向一致 107/108, 抽验侧复算）可引但必须标注"同端点同口径", 不得表述为跨端点证据（J6=a）。

### 1.5 预算饱和（题集轴空转）

结果（工件同上, question_set_budget）: bank 19 题, qa mutants 7 个; B=5（25%）起 keep_rate 即恒 1.0, 3 seeds × 4 预算档全 1.0; per_leaf_bank_support_min=1。

机制: 覆盖约束（每 mutant 目标叶至少被支持）在最小预算即被满足 → 判别力随预算"单调不降"平凡成立, 该轴对协议选择无信息量。

含义: 正文只留一句 observation（J4=a）: "题集预算梯度在当前题库规模下饱和（keep_rate≡1.0）, 不作为结论轴"; 不为救轴造困难集; 公平比较改走 Phase C matched-FPR 方案。

### 1.6 匹配竞争（效度威胁 + 打分层机制）

结果（工件 logs/graph/eval/t6_matching_competition.json）: Hungarian 全局分配 vs 贪心: 分配差 0 / 判定翻转 0; oracle 天花板 plain 0.952381 vs collision 0.597015, 复算误差 0。

机制: overlay 共享表头下同一 canonical 多变体争唯一槽位, 即使真值规则全在, 列间竞争压缩正确性上限; 全局最优分配不改变结果 = 竞争根因在打分层（形近串获得与真值同档打分）, 分配层次优已全局近优。

含义: 入效度威胁节（③ 裁定在案）; 同时是 R3 边界机制的核心证据——盲区属性归于匹配/打分层而非贪心算法伪影; 跨匹配器泛化由 Phase D2 验证（≥2 种匹配器, 嵌入类注明端点与预算）。

## 2. Paper Claim Set v2（冻结）

**R1 可见性谱核心**: 长流程文档智能评测必须按缺陷类型与强度报告可见性谱, 单一聚合分不可区分"检出"与"静默吸收"。证据: 95 表/118 注入六类谱（75/95 表级; 96/118 注入级; OCR 形近 13/13 全盲）[checkpoint_discrimination_tables_v2.json] + γ 网格谱排序稳定（排序非退化全网格成立; 绝对极差按量化机制衰减, ②a 冻结措辞）[t2_visibility_sensitivity.json]。降级: 第二数据流（D4）不复现 → 收窄为"所测金融表头匹配层观察到结构性盲区", 不推广任意长流程管线（蓝图 C1 降级原样）。

**R2 检出-吸收-传播 + 定位-诊断（两轴分列）**: (a) 缺陷注入三态分类（检出/静默吸收/下游显形）可测量 [两臂工件]; (b) 分层检查点提供层位定位与可分解证据, 评测预算更低（2 vs 12 单位口径）, 但**不提高原始缺陷检出敏感性**（J3 二裁定句, 覆盖 ①a）: "Hierarchical checkpoints provide layer-level localization and decomposable evidence under a lower evaluation budget, but do not improve raw defect-detection sensitivity in the current setting." 降级: 定位维若被 D2/D4 削弱 → 只保留证据可分解主张。

**R3 可见性边界机制**: 盲区由匹配/打分层机制决定（形近串同档打分 + 量化分辨率 + 突变体可观测性）, 非分配层或裁判能力伪影。证据: T6 分支 a（差 0/翻转 0）+ 量化地板 + M7 保真度。降级: D2 跨匹配器若谱形显著改变 → 改为"盲区位置匹配器相关, 谱结构（存在全盲类型）匹配器无关"。

**R4 跨数据流泛化 = 研究问题（不作主张）**: TAT-DQA 第二数据流（Phase D4, 解冻条款: 仅 validation split, 完成即恢复冻结）结果以研究问题形式呈现方向一致性, 不作泛化主张, 除非复现达 C1 成功标准。

**PSO 降级**: 出贡献, 方法一句: "A particle-swarm weight search reproduced the same mean separation (1.4326) as greedy coordinate ascent (7650 vs 67 evaluations), so all reported weights use greedy/equal calibers." 不再单列任何 PSO 主张; 专利协同见 §3。

**VGRM 仅案例（P1 不变）**: 门拒 7/7 + 5/5 机制信号, 主效应不显著如实报告（ΔV(ACC)=0.05, CI 含 0; 列级 7/40 vs 4/40, McNemar p=0.375）, 指向大论文线功效分析。

**成功标准/降级表述**: 逐条继承蓝图 §1 C1-C5 对应行的冻结措辞（本文不重述以避免版本漂移）; 本文新增句 = 更保守表述, 依"论文可比降级上限更保守"原则办理, 判据冻结不变。
