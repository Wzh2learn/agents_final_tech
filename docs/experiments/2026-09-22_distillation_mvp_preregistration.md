# 评估引导的小模型蒸馏 MVP 预注册草案

> 状态：待导师/用户确认后执行 | 更新：2026-09-22 | Claim：SP-RQ2 / TH-I3
> 红线：本文件只设计，不启动模型、训练、数据库或生产服务；仅使用公开/合成数据。

## 1. 研究问题

判别力已审计的 checkpoint 信号，能否比未过滤教师数据更有效地把长流程文档能力迁移给低成本学生模型，同时控制未见缺陷家族上的回归？

## 2. 假设

- H1（质量）：checkpoint-filtered SFT 在未见缺陷家族上的宏平均质量不劣于普通 SFT。
- H2（尾部）：checkpoint-filtered SFT 的最坏家族结果优于普通 SFT，或至少减少严重回归事件。
- H3（偏好）：在数据门通过时，SFT + DPO 比 filtered SFT 更少接受门控已判定的有害动作。
- H4（成本）：学生在质量达到非劣标准时，相比教师降低延迟、token 成本或内存中的至少一项。

任何假设失败都保留为 null/adverse result，不更换 holdout 或阈值挽救结果。

## 3. 模型与实验臂

### 学生选择

- 主学生候选：Qwen3-8B。现有训练前矩阵最高 15/16，但逐题原始 JSON 只在 GB10 gitignored 路径，执行前必须归档最小可审计统计。
- 低成本对照候选：Qwen3-4B。现有训练前矩阵 14/16，且出现 thinking 负增益。
- 最终选择条件：训练兼容权重已获准、显存预算通过、训练不会影响生产实例。GGUF 推理权重不能直接视为可训练底座。

### 四个臂

| 臂 | 数据/训练 | 回答的问题 |
|---|---|---|
| A0 | zero-shot student | 学生训练前基线 |
| A1 | 同预算 unfiltered SFT | 普通教师数据是否足够 |
| A2 | checkpoint-filtered SFT | 流程评估信号是否改善迁移 |
| A3 | A2 + gate-derived DPO | 门控偏好是否减少有害动作 |

A3 只有在偏好数据门通过后执行；当前 60 对只够 pipeline pilot，不预先宣称足以支持论文结论。

## 4. 数据构造与防泄漏

1. 先按源表 ID 分 train/dev/test，再生成训练样本；同一表的 clean、mutant 和轨迹不得跨 split。
2. 以六个缺陷家族做 leave-one-family-out；被留出的家族不得参与 SFT、DPO、阈值选择或 early stopping。
3. 正轨迹必须通过指定 hinge checks；负轨迹保留失败 checkpoint 和失败原因，不只保留最终答案。
4. A1 与 A2 使用相同样本上限、训练步数和 token 预算；差异只能来自 checkpoint 过滤。
5. DPO 对从门控通过/拒绝事件构造，保留来源指针；`dpo_pairs_v0.json` 的 60 对先做去重、冲突和 split 泄漏审计。

## 5. 指标与统计

### 主指标

- 未见家族的宏平均 checkpoint pass rate。
- 最坏家族 pass rate。
- 有害动作接受率与严重回归数。

### 次指标

- 最终任务正确率、缺陷可见性、校准误差。
- p50/p95 延迟、生成 token、峰值内存和 Score/Cost。

### 统计单位

- bootstrap 以源表为聚类单位，不把同表多个 mutant 当独立样本。
- 报告效应量与 95% CI；多学生或多家族比较时明确多重比较处理。
- 建议非劣容差 `δ=0.02`，必须在执行前由导师/用户确认并冻结。

## 6. 判定规则

| 结果 | 判定 |
|---|---|
| A2 相对 A1 的未见家族差值 CI 下界 ≥ `-δ`，且成本至少一项下降 | 支持“评估引导蒸馏可行”的收窄主张 |
| A3 显著降低有害动作接受率，且主质量不越过 `-δ` | 支持门控偏好增益 |
| 平均值改善但最坏家族恶化 | PARTIAL，不写稳健性提升 |
| A1/A2/A3 不可分 | NULL，保留并分析数据量或教师信号分辨力 |
| split 泄漏、训练预算不等或证据无法复现 | INVALID，不进入论文 |
