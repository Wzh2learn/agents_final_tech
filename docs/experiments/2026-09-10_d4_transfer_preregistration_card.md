### 2.2 预注册预测（跑前落盘, 不许看结果后补; 逐条标注**推导门** vs **经验预测**）

**推导门**（从既有冻结工件推导的一致性检查; 失配 = 实现/口径问题 → 查实现或停报）

- G-1: A-D4-1 谓词对 D3 阶段 B 8 行独立重建 = **3 agree / 5 disagree / 0 unresolved**（收据 A-10 已实证, 本卡为跨窗回归夹具）。
- G-2: 计数器双恒等式 `counter == canary + calls + retries` 且 `reserve == counter`; JSONL 行数 == counter 终值。
- G-3: 两臂案例集按 `(uid8, col)` 1:1 join, 差异行数 = 0（配对完整性）。
- G-4: FA-3 次级臂跑前后, 主判据工件 raw 与 LF 双口径 sha **均不变**（次级臂不污染主判据）。
- G-5: 端点自证 `ports_observed ⊆ 白名单` 且 `endpoint_violations == []`; 抽验脚本自身 `socket_attempts == []`。
- G-6: test split 读写清单为空（解冻条款零触碰自证）。

**经验预测**（真会被新数据反驳; 两方向皆合法答案, 失配 = 入 findings 不硬修）

- E-1（族级承载迁移）: 若 D3 的「触发由单族承载」是评估器结构属性而非语料偶发, 则在 D4 应观察到**至少一族族内 verdict 高度一致（同向比例 ≥ 该族 n 的 3/4）而其余族不同向**; 若各族 verdict 分布均匀无成块, 则 FA-1 的族条件性**不迁移**, 如实报告并降级为「D3 语料特有」。
- E-2（判据相对性迁移）: 若判据相对性是**判据种类属性**, 则两个 scorer 在同一批输入上的分歧应**沿判据种类轴成块**（同族同向）, 且两 scorer 之间的分歧模式与 D3 的 judge↔DR4 分歧模式**同型**; 若第二 scorer 与第一 scorer 高度一致而与 DR4 仍分歧, 则「相对性」更可能是 **oracle 侧属性**而非 scorer 侧, 该结果同样合法入账。
- E-3（FA-2 对照族分离）: 若「编辑距离 1」不是语义等价的充分条件（FA-2 的边界主张）, 则对照族（单位/年份/正负号类单字符替换）在**两个 scorer 上都应主要判 meaning_changed**, 与 ocr_similar 族的 equivalent 主导形成分离; 若对照族也被判 equivalent, 则暴露 **judge 自身的宽松偏置**, FA-2 的机制解释被削弱——这是本卡最有信息量的可证伪点。
- E-4（词表覆盖单向偏置）: 若 DR4 `lexicon.residue_note` 自证的单向偏置成立, 则 FA-3 次级臂（9 个 residue 原子登记入词表后重算 C2）应使 ocr_similar 族中**至少一部分**从 H 翻转, 且不产生方向异常; 若翻转数为 0, 则该族的 H 归属**不由词表覆盖决定**, FA-3 的解释需收紧。结果**只用于边界披露**。
- E-5（迁移三指标, 承 R4 拆分注记冻结值）: τ_b ≥ 0.6 / macro type-level MAE ≤ 0.15 / OCR 锚 V ≤ 0.20, 另报 reversal V_target > 0.50; 三档 verdict 不二元化。未达 = 按 R4a/R4b 既有降级条款处置, 不修到成功。
