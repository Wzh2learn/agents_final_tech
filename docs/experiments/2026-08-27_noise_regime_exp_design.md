## 1 目的与假设链

实验 1（ce85736）= 可靠性曲线左端点: 可靠建议器体制下门控不改变 holdout 终值（0.589048 vs 0.589048）, 收益 0 代价 4/42。本实验造右端点: **主动降低建议器可靠性（噪声三档）, 测门控收益随噪声档位的响应曲线**。这是"门控何时值得"研究问题的决定性数据（骨架 §5 主图右端点）。

## 2 噪声三档（预注册, 第四档预留）

| 档 | 注入方式 | 操作化 | 预期机制 |
|---|---|---|---|
| L1 temp | 建议器 temperature=0.8（payload 级, 非端点配置） | llm_suggest 仅改 temperature 参数 | 采样方差 → 偶发错误建议 |
| L2 prompt | prompt 退化: 去数据行上下文 + 去已有别名提示 | 退化模板常量, 建议器输入信息量降档 | 上下文缺失 → 猜测率上升 |
| L3 force | 低置信建议强制输出: 每个未映射列以 p=0.5 概率注入合成错误建议（目标=随机其他 canonical, confidence=low, synthetic=true, 种子派生确定性） | 建议流后处理注入层 | 直接模拟"不会说不知道"的弱建议器 |
| （预留）L4 OCR 真实噪声 | K2 盲区衔接臂（13/13 静默吸收类漂移进语料） | 不入首批 | 与 K2 盲区发现合流, 待本批有结论再排 |

档位序 = L1 < L2 < L3（预期严重度升序）; L0 = 无噪声 = 实验 1 已有数据（不重跑, 复用 ce85736 工件为对照）。

## 3 预注册（执行前冻结）

- **切分复用实验 1**: seed=20260826, 60/35, split_digest 必须与 vgmc_exp1_results.json 一致（可比性前提, 开场 1 命令核验）
- 门主档 τ=0.1 ε=0.02（同实验 1）; 网格重放 3×2 同批
- 轮次结构同实验 1（4 轮 × 15 表课程式, 每表只问一次）
- 每档两臂独立流（gated/ungated）; **L1 档 temp>0 非确定 → 预注册 2 seed（42/43）, 其余档 1 次**
- 总调用预算: (2+1+1) 档 × 2 臂 × ≤41 次 ≈ ≤330 次 :8004 调用
- **预注册预测（机械判据, 结果照录不修饰）**:
  - **P1 单调性**: 无门控臂退化率 D(level) = H_meas(基线) − H_meas(终值) 满足 D(L1) ≤ D(L2) ≤ D(L3)（容差: 相邻档逆序 ≤0.005 记噪声, >0.005 记单调性 NO-GO 如实入账）
  - **P2 门控有界**: 各档门控臂 H_meas(终值) ≥ H_meas(基线) − 0.02（ε 单步界）; 且凡无门控臂退化 >0.005 之档, 门控臂退化严格更小
  - **P3 null 分支**: 若三档两臂终值全部再相同（|差| < 0.005）→ 判"噪声档位不足或建议器过强", **转扩语料碰撞（骨架候选①）, 不恋战不加档重试**, 如实记账入一页纸

## 5 改动面（只列不写码, vgmc_exp1.py 主体不动）

1. argparse: `--noise {none,temp,prompt,force}` / `--noise-temp 0.8` / `--force-rate 0.5` / `--noise-seed`（~8 行）
2. `llm_suggest()`: temperature 取参数; prompt 退化分支（退化模板常量: 去数据行 + 去别名提示行）（~12 行）
3. 强制注入层: `llm_suggest` 返回后按 force-rate 以种子派生 rng 注入合成错误建议（目标=随机其他 canonical, synthetic 标记, 流水保留标记位）（~15 行）
4. 检查点/工件命名空间按噪声档隔离（`vgmc_noise_{level}_*.json`, 实验 1 工件零覆盖）+ meta 记噪声配置（~8 行）
5. 新增单测 `tests/test_vgmc_noise_inject.py`: 注入层确定性 + prompt 分支 + 端点断言（测试文件不计入 50 行预算）
- 回滚口径: 噪声层全在参数分支内, `--noise none` = 实验 1 原行为（回归测试守门）; 工件独立命名空间, 删除即净
